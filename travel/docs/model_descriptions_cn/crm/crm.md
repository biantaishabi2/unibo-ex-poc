# 模型业务说明

- 版本：1.0
- 领域：客户关系
- 领域说明：客户关系管理领域模型，涵盖联系人、商机、活动、销售预测
- 实体数量：11

## 实体：联系（聚合根）

- 说明：联系人/合作伙伴，CRM 中所有业务关系的核心实体
- 来源：基于 参与方；来源域 ofbiz/party

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 姓名
- 邮箱：文本，说明 邮箱，变更时自动通过 mail.thread 追踪记录
- 电话：文本，说明 固定电话，变更时自动追踪
- 手机：文本，说明 手机号，变更时自动追踪
- 公司：文本，说明 公司名称
- 岗位标题：文本，说明 职位
- 联系类型：枚举，默认值 个人，可选值：个人 / 公司
- 标签：文本，说明 标签（逗号分隔）
- 备注：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 地址：一对多 -> 联系地址
- 电话：一对多 -> 联系电话
- 线索：一对多 -> 线索
- 公司参与方：多对一 -> 参与方，外键 公司参与方编号，必填关系

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、邮箱、电话、手机、公司、岗位标题、联系类型、标签、备注
- 查询
- 更新，可写字段：名称、邮箱、电话、手机、公司、岗位标题、联系类型、标签、备注
- 删除

#### 校验
- 创建时，名称 不能为空

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 销售代表、管理员 时允许

#### 变更
- 在 更新 时，track_field_change
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：contact_lifecycle：创建 -> 更新 -> 删除（联系人管理流程）

## 实体：线索（聚合根）

- 说明：线索/商机，CRM 核心实体。type=lead 为未筛选线索，type=opportunity 为已进入管道的商机
- 来源：基于 销售商机；来源域 ofbiz/marketing

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 商机名称
- 类型：枚举，默认值 线索，可选值：线索 / 商机，说明 类型：lead（未筛选线索）或 opportunity（已进入管道的商机）
- 伙伴名称：文本，说明 公司名（未创建 Contact 时暂存）
- 联系人：文本，说明 联系人名（未创建 Contact 时暂存）
- 邮箱来源：文本，说明 联系邮箱，含自动清洗(sanitize)
- 电话：文本，说明 固定电话，含自动清洗
- 手机：文本，说明 手机号，含自动清洗
- 预期营收：金额，说明 预计收入（手动填写的交易金额）
- 按比例营收：金额，说明 概率加权营收，计算公式：expected_revenue * probability / 100
- 概率：金额，说明 成交概率（百分比），默认与 automated_probability 同步，手动修改后脱离自动同步
- 自动化概率：金额，说明 PLS 机器学习预测概率（朴素贝叶斯分类器）
- 启用：布尔，默认值 是，说明 活跃状态，active=false 等价于"已丢失"
- 优先级：枚举，默认值 0，可选值：0 / 1 / 2 / 3，说明 优先级（0=普通，1=低，2=中，3=高）
- 标签编号列表：文本，说明 标签列表（逗号分隔）
- 来源：文本，说明 来源渠道
- 丢单原因：文本，说明 丢失原因，标记丢失时记录
- 看板状态：枚举，默认值 灰色，可选值：灰色 / 红色 / 绿色，说明 看板状态，由活动截止日计算：grey(无活动)/red(过期)/green(未过期)
- 线索属性：映射，说明 团队级动态属性
- 日期截止日：日期，说明 截止日期
- 日期打开：日期时间，说明 首次分配销售员时间
- 日期已关闭：日期时间，说明 关闭时间（赢单或丢失）
- 日期换算：日期时间，说明 lead 转为 opportunity 的时间
- 日期最近阶段更新：日期时间，说明 最后一次阶段变更时间
- 备注：长文本，说明 备注/描述（HTML）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 联系：多对一 -> 联系
- 阶段：多对一 -> 线索阶段
- 已分配：多对一 -> 参与方，外键 已分配参与方编号
- 公司参与方：多对一 -> 参与方，外键 公司参与方编号，必填关系
- 团队：多对一 -> 销售团队
- 活动：一对多 -> 活动
- 日历活动：一对多 -> 日历活动

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、类型、伙伴名称、联系人、邮箱来源、电话、手机、预期营收、概率、优先级、标签编号列表、来源、日期截止日、备注、线索属性，参数：联系编号：唯一标识；阶段编号：唯一标识；团队编号：唯一标识
- 查询
- 更新，可写字段：名称、伙伴名称、联系人、邮箱来源、电话、手机、预期营收、概率、优先级、标签编号列表、来源、日期截止日、备注、线索属性
- 转换商机（类型：更新），说明：将 lead 转为 opportunity，记录 date_conversion，可选关联或创建 Contact，参数：联系编号：唯一标识
- 赢单（类型：更新），说明：标记赢单，进入 is_won=True 的阶段，probability 自动置为 100
- 丢失（类型：更新），说明：标记丢失，active 置 false、probability 置 0，记录 lost_reason，可写字段：丢单原因
- 合并（类型：自定义规则），说明：合并多条线索/商机，选置信度最高记录为主体，参数：来源线索编号列表：文本（必填）
- 分配销售人员（类型：更新），说明：分配销售员，支持轮询分配，参数：用户编号：唯一标识；团队编号：唯一标识

#### 校验
- 创建时，名称 不能为空
- 转换商机时，只有 lead 类型才能转为 opportunity
- 赢单时，启用 必须等于 是（只有活跃商机可以赢单）
- 丢失时，启用 必须等于 是（只有活跃商机可以标记丢失）

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 销售代表、管理员 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=已分配 时允许

#### 变更
- 在 转换商机 时，将 类型 设为 商机
- 在 转换商机 时，将 日期换算 设为 当前时间
- 在 赢单 时，将 概率 设为 100
- 在 赢单 时，将 日期已关闭 设为 当前时间
- 在 丢失 时，将 启用 设为 否
- 在 丢失 时，将 概率 设为 0
- 在 丢失 时，将 日期已关闭 设为 当前时间
- 在 更新 时，将 日期最近阶段更新 设为 当前时间
- 在 创建 / 更新 / 赢单 / 丢失 时，计算 按比例营收
- 在 创建 / 更新 时，计算 看板状态
- 在 创建 / 更新 / 转换商机 / 赢单 / 丢失 / 合并 / 分配销售人员 时，将 编号 设为 编号

#### 事件
- 事件：赢单 -> 客户关系.线索.赢单
- 事件：丢失 -> 客户关系.线索.丢单
- 事件：转换商机 -> 客户关系.线索.已转化

#### 工作流
- 流程：lead_lifecycle：创建 -> 转换商机 -> 赢单 -> 丢失 -> 分配销售人员 -> 合并（线索/商机生命周期）
- 流程：lead_stage_progression：更新（商机阶段推进流程）

## 实体：销售团队成员

- 说明：销售团队成员关联，支持单/多团队模式下的成员归属管理
- 来源：基于 参与方关系；来源域 ofbiz/party

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 启用：布尔，默认值 是，说明 活跃状态，单团队模式下自动归档其他成员资格
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 团队：多对一 -> 销售团队，必填关系
- 用户：多对一 -> 参与方，外键 用户参与方编号，必填关系

### Conduct（行为声明）

#### 操作
- 创建，可写字段：启用，参数：团队编号：唯一标识（必填）；用户编号：唯一标识（必填）
- 查询
- 更新，可写字段：启用
- 删除

#### 校验
- 创建时，团队编号 关系必填
- 创建时，用户编号 关系必填
- 创建／更新／删除时，团队编号 belongs_to_exists

#### 策略
- 权限：创建 操作，当 操作者.角色 = 管理员 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 时允许

#### 变更
- 在 创建 时，单团队模式下，创建新成员时自动归档该用户在其他团队的成员资格
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号
