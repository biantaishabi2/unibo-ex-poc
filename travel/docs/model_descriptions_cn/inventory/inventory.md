- 领域：库存

- 地址：长文本，说明 仓库地址
- 说明：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 位置：一对多 -> 库存位置
- 公司参与方：多对一 -> 参与方，外键 公司参与方编号

#### 唯一约束

## 实体：库存拣货（聚合根）

- 说明：拣货/出入库单
- 来源：基于 发货；来源域 ofbiz/shipment

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填、自动生成），说明 自动序列号（拣货单号）
- 来源：文本，说明 来源单据号（如销售订单号、采购订单号）
- 拣货类型：枚举（必填），可选值：入库 / 出库 / 内部，说明 入库/出库/内部调拨
- 凭证类型：枚举（必填），默认值 直接，可选值：直接 / 一，说明 direct=立即发货(按最快move), one=全部就绪后发货(等最慢move)
- 状态：枚举，默认值 草稿，可选值：草稿 / 等待中 / 已确认 / 已分配 / 完成 / 取消，说明 计算字段，由 move_ids 状态聚合计算，不可直接写入
- 优先级：枚举，默认值 0，可选值：0 / 1，说明 0=普通, 1=紧急
- 已排期日期：日期时间，说明 计算字段，按 move_type 策略从 move_ids.date 聚合
- 日期截止日：日期时间，说明 计算字段，按 move_type 策略从 move_ids.date_deadline 聚合
- 日期完成：日期时间，说明 完成时间，完成时自动写入
- 锁定：布尔，默认值 否，说明 完成/取消后锁定，防止修改
- 显示检查可用性：布尔，说明 是否显示检查可用性按钮
- 产品可用性：文本，说明 产品可用性摘要文本
- 备注：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 凭证编号列表：一对多 -> 库存移动，外键 拣货编号，管理模式 直接管理
- 来源位置：多对一 -> 库存位置，必填关系
- 目的位置：多对一 -> 库存位置，必填关系
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号
- 公司参与方：多对一 -> 参与方，外键 公司参与方编号
- 仓库：多对一 -> 仓库，必填关系
- 批次：多对一 -> 拣货批次

#### 唯一约束
- 唯一约束 唯一拣货名称：名称

### Conduct（行为声明）

#### 操作
- 创建，可写字段：来源、拣货类型、凭证类型、优先级、备注、公司参与方编号，参数：凭证编号列表：列表（必填）；仓库编号：唯一标识（必填）；来源位置编号：唯一标识（必填）；目的位置编号：唯一标识（必填）；伙伴编号：唯一标识
- 查询
- 确认操作（类型：更新），说明：确认拣货单，对所有 draft moves 调用 _action_confirm
- 操作分配（类型：更新），说明：检查可用性，预留库存
- 按钮验证（类型：更新），说明：验证/完成拣货
- 操作取消（类型：更新），说明：取消拣货

#### 校验
- 创建时，拣货类型 不能为空
- 确认操作时，只有草稿状态可以确认
- 操作分配时，只有已确认/等待/已分配状态可以检查可用性
- 按钮验证时，只有已分配或已确认状态可以验证
- 按钮验证时，不允许空转单（必须有需求量>0的move）
- 按钮验证时，追踪产品必须填写批次/序列号
- 按钮验证时，序列号产品数量必须为1

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 库存经理、管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=公司参与方 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=公司参与方 时允许

#### 变更
- 在 确认操作 时，invoke，参数 合并=是
- 在 操作分配 时，invoke
- 在 按钮验证 时，invoke
- 在 按钮验证 时，将 日期完成 设为 now()
- 在 按钮验证 时，将 优先级 设为 0
- 在 按钮验证 / 操作取消 时，将 锁定 设为 是
- 在 操作取消 时，invoke
- 在 创建 / 确认操作 / 操作分配 / 按钮验证 / 操作取消 时，将 编号 设为 编号

#### 事件
- 事件：按钮验证 -> 库存.拣货.已完成
- 事件：操作取消 -> 库存.拣货.已取消

#### 工作流
- 流程：stock_picking_lifecycle_flow：创建 -> 确认操作 -> 操作分配 -> 按钮验证（拣货单正常流转流程）
- 流程：stock_picking_cancel_flow：创建 -> 确认操作 -> 操作取消（拣货单取消流程）

- 说明：库存移动行（单个产品的移动记录）
- 来源：基于 发货；来源域 ofbiz/shipment

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 移动描述
- 产品编号：唯一标识（必填），说明 产品ID
- 产品单位数量：金额（必填），说明 需求数量（用户计量单位）
- 产品单位：文本（必填），说明 用户计量单位
- 产品数量：金额，说明 基础UOM数量（自动换算）
- 数量：金额，说明 实际已完成数量（sum of move_line_ids.quantity）
- 已预留数量：金额，默认值 0，说明 已预留数量
- 状态：枚举，默认值 草稿，可选值：草稿 / 等待中 / 已确认 / 部分可用 / 已分配 / 完成 / 取消，说明 移动状态
- 日期：日期时间（必填），说明 计划日期
- 日期截止日：日期时间，说明 截止日期
- 优先级：枚举，默认值 0，可选值：0 / 1，说明 0=普通, 1=紧急
- 采购方法：枚举（必填），默认值 按库存生产，可选值：按库存生产 / 按单生产，说明 make_to_stock=从现有库存, make_to_order=按需采购

- 可用性：金额，说明 当前预留比例
- 预测可用性：金额，说明 预测可用量
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 拣货：多对一 -> 库存拣货
- 来源位置：多对一 -> 库存位置，必填关系
- 目的位置：多对一 -> 库存位置，必填关系
- 移动行编号列表：一对多 -> 库存移动行，外键 凭证编号，管理模式 直接管理
- 移动原始编号列表：多对多 -> 库存移动，中间关系 库存移动依赖链接
- 移动目的编号列表：多对多 -> 库存移动，中间关系 库存移动依赖链接
- valuation_adjustment_lines：一对多 -> ValuationAdjustmentLine，外键 凭证编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、产品编号、产品单位数量、产品单位、日期、日期截止日、优先级、采购方法，参数：拣货编号：唯一标识；来源位置编号：唯一标识（必填）；目的位置编号：唯一标识（必填）
- 查询
- 操作确认（类型：更新），说明：确认移动，可合并同产品/同库位的 moves，参数：合并：布尔
- 操作分配（类型：更新），说明：预留库存
- 操作完成（类型：更新），说明：完成移动，执行双重记账
- 操作取消（类型：更新），说明：取消移动，释放预留
- 触发分配（类型：更新），说明：触发下游 moves 的库存预留

- 创建时，名称 不能为空
- 创建时，产品编号 不能为空
- 创建时，产品单位数量 必须大于 0（需求数量必须大于零）
- 操作确认时，只有草稿状态可以确认
- 操作分配时，只有已确认/部分可用/等待状态可以预留
- 操作完成时，只有已确认/部分可用/已分配状态可以完成

#### 变更
- 在 操作确认 时，将 状态 设为 已确认
- 在 操作确认 时，将 状态 设为 等待中
- 在 操作分配 时，将 状态 设为 已分配
- 在 操作分配 时，将 状态 设为 部分可用
- 在 操作完成 时，将 状态 设为 完成
- 在 操作完成 时，invoke，参数 来源=-qty，目的=+qty
- 在 操作完成 时，invoke
- 在 操作取消 时，将 状态 设为 取消
- 在 操作取消 时，invoke
- 在 创建 / 操作确认 / 操作分配 / 操作完成 / 操作取消 / 触发分配 时，将 编号 设为 编号

#### 事件
- 事件：操作完成 -> 库存移动已完成

#### 工作流
- 流程：stock_move_lifecycle_flow：创建 -> 操作确认 -> 操作分配 -> 操作完成 -> 触发分配（库存移动正常流转流程）
- 流程：stock_move_cancel_flow：创建 -> 操作确认 -> 操作取消（库存移动取消流程）

- 所有者编号：唯一标识，说明 所有者ID
