# 模型业务说明

- 版本：1.0
- 领域：工作室
- 领域说明：低代码应用构建平台，支持自定义模型、字段、视图和自动化规则
- 实体数量：6

## 实体：自定义规则模型（聚合根）

- 说明：用户自定义数据模型，运行时动态建表
- 来源：基于 内容；来源域 ofbiz/content；过滤条件 内容类型编号=自定义规则模型

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成）
- 名称：文本（必填），说明 模型显示名称
- 技术名称：文本（必填），说明 技术名，必须以 x_ 前缀开头
- 说明：长文本，说明 模型说明
- 表名称：文本（必填），说明 自动生成的数据库表名，格式 studio_x_{technical_name}
- 摘要：布尔，默认值 否，说明 抽象模型不创建物理表，仅作为字段继承基础
- 图标：文本，说明 模型图标
- 菜单序列：整数，说明 菜单排序
- 状态：枚举，默认值 草稿，可选值：草稿 / 启用 / 已归档，说明 模型状态
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 继承模型：多对一 -> 自定义规则模型
- 创建人：多对一 -> 参与方，外键 创建参与方编号
- 字段：一对多 -> 自定义规则字段，外键 模型编号
- 视图：一对多 -> 自定义规则视图，外键 模型编号
- 自动化规则：一对多 -> 自动化规则，外键 模型编号

#### 唯一约束
- 唯一约束 唯一技术名称：技术名称

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、技术名称、说明、摘要、图标、菜单序列，参数：继承模型编号：bigint
- 查询
- 更新，可写字段：名称、说明、图标、菜单序列
- 启用（类型：更新），说明：发布模型，执行 DDL 建表
- 归档（类型：更新），说明：停用模型
- 重新激活（类型：更新），说明：重新激活模型
- 删除，说明：删除模型，级联清理字段、视图、自动化规则

#### 校验
- 创建时，技术名称 格式（技术名必须以 x_ 开头，以区分系统模型与用户自定义模型）
- 创建时，名称 不能为空
- 创建时，技术名称 不能为空
- 启用时，只有草稿状态可以发布
- 归档时，只有活跃状态可以停用
- 重新激活时，只有已停用状态可以重新激活

#### 变更
- 在 创建 时，将 表名称 设为 concat(studio_, 技术名称)
- 在 启用 时，将 状态 设为 启用
- 在 归档 时，将 状态 设为 已归档
- 在 重新激活 时，将 状态 设为 启用
- 在 创建 时，将 创建人 设为当前操作人
- 在 创建 / 更新 / 启用 / 归档 / 重新激活 / 删除 时，将 编号 设为 编号

#### 事件
- 事件：启用 -> 工作室.模型.已激活
- 事件：归档 -> 工作室.模型.已归档

#### 工作流
- 流程：custom_model_lifecycle：创建 -> 更新 -> 启用 -> 归档 -> 重新激活 -> 删除（自定义模型生命周期）

## 实体：自定义规则字段

- 说明：用户自定义字段，支持 20 种字段类型和计算字段公式系统
- 来源：基于 内容关联；来源域 ofbiz/content；过滤条件 内容关联类型编号=模型字段

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成）
- 名称：文本（必填），说明 字段技术名，必须以 x_ 前缀开头
- 标签：文本（必填），说明 字段显示标签
- 字段类型：枚举（必填），可选值：文本 / 长文本 / 整数 / 浮点 / 金额 / 布尔 / 日期 / 日期时间 / 选择 / 币种 / 邮箱 / 链接 / 电话 / 多选 / HTML / JSON / 已计算 / many2one / one2many / many2many / 二进制，说明 字段类型，共 20 种
- 必填：布尔，默认值 否，说明 是否必填
- 只读：布尔，默认值 否，说明 是否只读
- 默认值：jsonb，说明 类型安全的默认值
- 选择选项：jsonb，说明 选择项列表，格式 [{"value":"...", "label":"..."}]
- 关联字段名称：文本，说明 反向关联字段名
- 计算公式：长文本，说明 计算公式表达式
- 计算依赖：文本列表，说明 公式依赖字段列表
- 验证规则：jsonb，说明 校验规则配置，如 {"min":0, "max":100, "regex":"..."}
- 控件提示：文本，说明 前端组件提示，映射到 WidgetRegistry
- 序列：整数，说明 字段排序
- 列名称：文本，说明 实际数据库列名
- 已索引：布尔，默认值 否，说明 是否创建数据库索引
- 状态：枚举，默认值 草稿，可选值：草稿 / 启用 / 已归档，说明 字段状态
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 模型：多对一 -> 自定义规则模型，必填关系
- 关联模型：多对一 -> 自定义规则模型

#### 唯一约束

- 查询
- 更新，可写字段：标签、必填、只读、默认值、选择选项、验证规则、控件提示、序列
- 启用（类型：更新），说明：激活字段，执行 DDL
- 归档（类型：更新），说明：停用字段

#### 校验

- 创建时，名称 不能为空
- 创建时，标签 不能为空
- 创建时，字段类型 不能为空

- 归档时，只有活跃状态可以停用

- 在 归档 时，将 状态 设为 已归档

## 实体：自动化规则（聚合根）

- 说明：事件驱动的自动化规则，支持 8 种触发类型和 8 种动作类型

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成）
- 名称：文本（必填），说明 规则名称

- 触发配置：jsonb（必填），说明 触发配置，结构随 trigger_type 变化
- 条件域：jsonb，说明 前置过滤条件（Domain 表达式），触发后、动作前求值
- 操作类型：枚举（必填），可选值：更新记录 / 创建记录 / 发送邮箱 / 发送通知 / 执行代码 / 调用Webhook / 添加关注人 / 链式自动化，说明 动作类型，共 8 种
- 操作配置：jsonb（必填），说明 动作配置，结构随 action_type 变化
- 序列：整数，说明 多规则执行顺序
- 是否启用：布尔，默认值 否，说明 是否启用
- 最近运行：日期时间，说明 最后执行时间
- 运行数量：整数，默认值 0，说明 执行次数
- 错误数量：整数，默认值 0，说明 错误次数
- 最近错误：长文本，说明 最后错误信息
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）
