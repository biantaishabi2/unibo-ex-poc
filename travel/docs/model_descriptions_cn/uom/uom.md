# 模型业务说明

- 版本：1.0
- 领域：单位
- 领域说明：计量单位领域模型，涵盖单位分类、单位定义、同分类内数量和价格换算
- 实体数量：2

## 实体：单位分类（聚合根）

- 说明：计量单位分类，每个分类有且仅有一个参考单位（reference）
- 来源：基于 单位类型；来源域 ofbiz/common

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 分类名称（如：重量、长度、体积）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- uoms：一对多 -> 单位，外键 分类编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称
- 查询
- 更新，可写字段：名称

#### 校验
- 创建时，名称 不能为空

#### 变更
- 在 创建 / 更新 时，将 编号 设为 编号

#### 工作流
- 流程：uom_category_maintain_flow：创建 -> 更新（计量单位分类维护）

## 实体：单位（聚合根）

- 说明：计量单位，以 reference 单位为中心，通过 factor 实现同分类内数量和价格换算
- 来源：基于 单位；来源域 ofbiz/common

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 单位名称（如：千克、克、磅）
- 系数：浮点（必填），默认值 1.0，说明 换算比率（相对于参考单位，不能为 0）
- 四舍五入：浮点，默认值 0.01，必须大于 0（舍入精度必须为正数），说明 舍入精度（必须为正数）
- 单位类型：枚举（必填），默认值 参考号，可选值：bigger / 参考号 / smaller，说明 单位类型（bigger=比参考单位大, reference=参考单位, smaller=比参考单位小）
- 启用：布尔，默认值 是，说明 是否启用
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 分类：多对一 -> 单位分类，必填关系

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、系数、四舍五入、单位类型、启用，参数：分类编号：唯一标识（必填）
- 查询
- 更新，可写字段：名称、系数、四舍五入、单位类型、启用
- 计算数量（类型：查询），说明：数量换算：将 qty 从当前单位换算到目标单位（同分类内）。公式：amount = qty / self.factor * to_unit.factor，参数：数量：金额（必填）；单位编号：唯一标识（必填）；四舍五入：布尔
- 计算价格（类型：查询），说明：价格换算：将 price 从当前单位换算到目标单位（方向与数量换算相反）。公式：amount = price * self.factor / to_unit.factor，参数：价格：金额（必填）；单位编号：唯一标识（必填）

#### 变更
- 在 创建 / 更新 时，将 编号 设为 编号

#### 计算
- 计算字段 系数库存：浮点，规则 1 ÷ 系数
- 计算字段 比率：浮点，规则 情况（条件=单位类型 = 参考号，值=1，条件=单位类型 = bigger，值=1 ÷ 系数，默认=系数）

#### 工作流
- 流程：uom_maintain_flow：创建 -> 更新（计量单位维护）
