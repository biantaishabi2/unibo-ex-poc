# 模型业务说明

- 版本：1.0
- 领域：评级
- 领域说明：通用评价评分领域模型，涵盖评价提交与审核、多维度打分、评价汇总统计
- 实体数量：5

## 实体：评级类型（聚合根）

- 说明：评价类型（产品评价、服务评价、供应商评价等），泛化自 OFBiz SupplierRatingType
- 来源：基于 供应商评级类型；来源域 ofbiz/product

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 编码：文本（必填），说明 类型编码（如 product、service、supplier）
- 名称：文本（必填），说明 类型名称（对齐 SupplierRatingType.description）
- 说明：长文本，说明 类型说明
- 适用的资源类型列表（逗号分隔，如 product,order,supplier）（applicable_resource_types）：文本
- 启用：布尔，默认值 是，说明 是否启用
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- ratings：一对多 -> 评级，外键 评级类型编号
- 条件：一对多 -> 评级条件，外键 评级类型编号

#### 唯一约束
- 唯一约束 唯一编码：编码

### Conduct（行为声明）

#### 操作
- 创建，可写字段：编码、名称、说明、applicable_resource_types、启用
- 查询
- 更新，可写字段：名称、说明、applicable_resource_types、启用
- 删除

#### 校验
- 创建时，编码 不能为空
- 创建时，名称 不能为空

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：rating_type_lifecycle：创建 -> 更新 -> 删除（评价类型维护流程）

## 实体：评级条件（聚合根）

- 说明：评价维度（质量、交期、服务态度等），全新建模

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 维度名称（如：质量、交期、服务态度）
- 说明：长文本，说明 维度说明
- 编码：文本（必填），说明 维度编码（如 quality、delivery、service）
- 重量：金额，默认值 1.0，必须大于 0（权重必须为正数），说明 权重（用于加权平均计算）
- 排序订单：整数，默认值 0，说明 排序序号
- 启用：布尔，默认值 是，说明 是否启用
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 评级类型：多对一 -> 评级类型
- scores：一对多 -> 评级评分，外键 条件编号

#### 唯一约束
- 唯一约束 唯一编码每类型：评级类型编号、编码

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、说明、编码、重量、排序订单、启用，参数：评级类型编号：唯一标识（必填）
- 查询
- 更新，可写字段：名称、说明、重量、排序订单、启用
- 重新排序（类型：更新），说明：调整维度排序，可写字段：排序订单
- 删除

#### 校验
- 创建时，名称 不能为空
- 创建时，编码 不能为空
- 创建时，评级类型编号 不能为空

#### 变更
- 在 创建 / 更新 / 重新排序 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：rating_criteria_lifecycle：创建 -> 更新 -> 重新排序 -> 删除（评价维度维护流程）

## 实体：评级（聚合根）

- 说明：通用评价，泛化自 OFBiz ProductReview，通过 resource_type + resource_id 多态关联任意业务对象
- 来源：基于 产品评审；来源域 ofbiz/product

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 资源类型：文本（必填），说明 被评价对象类型（多态关联，替代 ProductReview.product_id；开放字符串，vertical 层可自由扩展如 product、order、supplier 等）
- 资源编号：唯一标识（必填），说明 被评价对象ID（多态关联，替代 ProductReview.product_id）
- 评分：金额（必填），最小值 1.0，最大值 5.0，必须 ≥ 1.0，且 必须 ≤ 5.0（评分必须在 1.0 到 5.0 之间），说明 综合评分（对齐 ProductReview.product_rating）
- 评论：长文本，说明 评语文本（对齐 ProductReview.product_review）
- 审核人编号：唯一标识（必填），说明 评价人（对齐 ProductReview.user_login_id）
- 匿名：布尔，默认值 否，说明 是否匿名（对齐 ProductReview.posted_anonymous）
- 状态：枚举（必填），默认值 待处理审批，可选值：待处理审批 / 已发布 / 已驳回 / 已标记，说明 审核状态（对齐 ProductReview.status_id）
- 标记原因：文本，说明 举报原因（status 为 flagged 时填写）
- 拒绝原因：文本，说明 拒绝原因（status 为 rejected 时填写）
- 已提交：日期时间，说明 提交时间（对齐 ProductReview.posted_date_time）
- 已发布：日期时间，说明 发布时间
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 评级类型：多对一 -> 评级类型
- scores：一对多 -> 评级评分，外键 评级编号

#### 唯一约束
- 唯一约束 唯一审核人每资源：审核人编号、资源类型、资源编号

### Conduct（行为声明）

#### 操作
- 提交（类型：创建），说明：提交评价，初始状态为 pending_approval，可写字段：资源类型、资源编号、评分、评论、审核人编号、匿名，参数：评级类型编号：唯一标识
- 查询
- 更新，说明：修改评价内容（仅 pending_approval 状态可修改），可写字段：评分、评论、匿名
- 审批（类型：更新），说明：审核通过，status 变为 published
- 驳回（类型：更新），说明：审核拒绝，status 变为 rejected，可写字段：拒绝原因
- 标记（类型：更新），说明：举报评价，status 变为 flagged，可写字段：标记原因

#### 校验
- 提交时，资源类型 不能为空
- 提交时，资源编号 不能为空
- 提交时，评分 不能为空
- 提交时，审核人编号 不能为空
- 更新时，仅待审核状态的评价可修改
- 驳回时，拒绝原因 不能为空（拒绝时必须填写拒绝原因）
- 标记时，标记原因 不能为空（举报时必须填写举报原因）

#### 变更
- 在 提交 时，将 状态 设为 待处理审批
- 在 提交 时，将 已提交 设为 当前时间
- 在 审批 时，将 状态 设为 已发布
- 在 审批 时，将 已发布 设为 当前时间
- 在 驳回 时，将 状态 设为 已驳回
- 在 标记 时，将 状态 设为 已标记
- 在 提交 / 更新 / 审批 / 驳回 / 标记 时，将 编号 设为 编号

#### 事件
- 事件：提交 -> 评级.已提交
- 事件：审批 -> 评级.已审批

#### 工作流
- 流程：rating_review_flow：提交 -> 更新 -> 审批 -> 驳回 -> 标记（评价提交与审核流程）

## 实体：评级评分

- 说明：多维度打分明细，随 Rating 一起提交，支持按维度细分评分

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 评分：金额（必填），最小值 1.0，最大值 5.0，必须 ≥ 1.0，且 必须 ≤ 5.0（评分必须在 1.0 到 5.0 之间），说明 该维度的评分
- 评论：长文本，说明 该维度的评语（可选）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 评级：多对一 -> 评级，必填关系
- 条件：多对一 -> 评级条件，必填关系

#### 唯一约束
- 唯一约束 唯一条件每评级：评级编号、条件编号

### Conduct（行为声明）

#### 操作
- 提交（类型：创建），说明：提交维度打分（随 Rating 一起提交），可写字段：评分、评论，参数：评级编号：唯一标识（必填）；条件编号：唯一标识（必填）
- 查询

#### 校验
- 提交时，评分 不能为空
- 提交时，评级编号 不能为空
- 提交时，条件编号 不能为空

#### 变更
- 在 提交 时，将 编号 设为 编号

## 实体：评级摘要（聚合根）

- 说明：评价汇总统计（某对象的平均分、评价数、各星级分布），只读聚合实体

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 资源类型：文本（必填），说明 被评价对象类型（与 Rating.resource_type 对齐，开放字符串）
- 资源编号：唯一标识（必填），说明 被评价对象ID
- 平均评分：金额，默认值 0.0，说明 平均评分
- 合计数量：整数，默认值 0，说明 评价总数（仅统计 published 状态）
- 1星评价数（star_1_count）：整数，默认值 0
- 2星评价数（star_2_count）：整数，默认值 0
- 3星评价数（star_3_count）：整数，默认值 0
- 4星评价数（star_4_count）：整数，默认值 0
- 5星评价数（star_5_count）：整数，默认值 0
- 最近评级：日期时间，说明 最近一次评价时间
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 唯一约束
- 唯一约束 唯一资源：资源类型、资源编号

### Conduct（行为声明）

#### 操作
- 查询
- recalculate（类型：更新），说明：重新计算汇总数据（由 Rating approve 后自动触发），可写字段：平均评分、合计数量、star_1_count、star_2_count、star_3_count、star_4_count、star_5_count、最近评级

#### 变更
- 在 recalculate 时，将 编号 设为 编号

#### 计算
- 计算字段 满意度费率：金额，规则 计算满意度费率(star_4_count, star_5_count, 合计数量)

#### 事件
- 事件：recalculate -> 评级.摘要.更新
