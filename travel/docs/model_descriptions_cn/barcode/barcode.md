# 模型业务说明

- 版本：1.0
- 领域：条码
- 领域说明：条码管理领域模型，涵盖条码命名法定义、解析规则配置、条码与业务对象映射、GS1应用标识符管理
- 实体数量：4

## 实体：BarcodeNomenclature（聚合根）

- 说明：条码命名法，定义一套解析规则集，支持普通条码和GS1-128模式
- 来源：基于 BarcodeNomenclature；来源域 条码

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 命名法名称
- 说明：长文本，说明 命名法描述
- 是否启用GS1解析模式（对齐Odoo is_gs1_nomenclature）（is_gs1_compliant）：布尔，默认值 否
- UPC/EAN互转模式（upc_ean_conv）：枚举，默认值 无，可选值：无 / ean2upc / upc2ean / always
- GS1 FNC1分隔符替代正则（is_gs1_compliant=true时使用）（gs1_separator_fnc1）：文本，默认值 (Alt029|#|\x1D)
- 启用：布尔，默认值 是，说明 是否启用
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 规则：一对多 -> 条码规则，外键 nomenclature_id

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、说明、is_gs1_compliant、upc_ean_conv、gs1_separator_fnc1、启用
- 查询
- 更新，可写字段：名称、说明、is_gs1_compliant、upc_ean_conv、gs1_separator_fnc1、启用
- 启用（类型：更新），说明：启用命名法
- 停用（类型：更新），说明：停用命名法
- 删除

#### 校验
- 创建时，名称 不能为空

#### 变更
- 在 启用 时，将 启用 设为 literal（是）
- 在 停用 时，将 启用 设为 literal（否）
- 在 创建 / 更新 / 启用 / 停用 时，将 编号 设为 编号

#### 工作流
- 流程：nomenclature_lifecycle：创建 -> 更新 -> 启用 -> 停用 -> 删除（命名法生命周期管理）

## 实体：条码规则

- 说明：条码解析规则，定义条码模式匹配和字段映射，支持普通编码和GS1-128扩展
- 来源：基于 条码规则；来源域 条码

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 规则名称
- 序列：整数（必填），默认值 10，必须大于 0（优先级必须为正整数），说明 匹配优先级（越小越先匹配）
- 条码编码类型（encoding）：枚举（必填），默认值 任意，可选值：任意 / ean13 / ean8 / upca / gs1_128 / gs1_datamatrix
- 条码类型：枚举（必填），默认值 产品，可选值：产品 / 别名 / 数量 / 批号 / 位置 / 位置目的 / 包裹 / 包裹类型 / 使用日期 / 到期日期 / pack_date，说明 匹配后关联的业务类型
- 格式：文本（必填），默认值 .*，说明 匹配正则表达式，支持{NND}数值占位符；GS1模式需含两个捕获组
- 别名：文本，说明 barcode_type=alias时重定向到此条码值
- GS1内容类型（encoding=gs1_128时使用）（gs1_content_type）：枚举，可选值：日期 / 度量 / 标识符 / alpha
- AI末位是否表示小数位数（GS1 measure类型）（gs1_decimal_usage）：布尔，默认值 否
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- nomenclature：多对一 -> BarcodeNomenclature，必填关系
- gs1_ai：多对一 -> GS1ApplicationIdentifier

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、序列、encoding、条码类型、格式、别名、gs1_content_type、gs1_decimal_usage，参数：nomenclature_id：唯一标识（必填）；gs1_ai_id：唯一标识
- 查询
- 更新，可写字段：名称、序列、encoding、条码类型、格式、别名、gs1_content_type、gs1_decimal_usage
- 重新排序（类型：更新），说明：调整规则匹配优先级，可写字段：序列
- 删除

#### 校验
- 创建时，名称 不能为空
- 创建时，nomenclature_id 不能为空
- 创建时，格式 不能为空

#### 变更
- 在 创建 / 更新 / 重新排序 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：rule_lifecycle：创建 -> 更新 -> 重新排序 -> 删除（解析规则维护流程）

## 实体：BarcodeMapping（聚合根）

- 说明：条码与业务对象映射，记录条码值到产品、批次、库位、资产等的关联关系
- 来源：基于 BarcodeMapping；来源域 条码

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 条码值：文本（必填），说明 条码值（如EAN-13编码"6901234567890"）
- 资源类型：文本（必填），说明 关联的业务资源类型（开放式，如 product、lot、location、asset、package、employee 等）
- 资源编号：文本（必填），说明 关联的业务资源ID
- 启用：布尔，默认值 是，说明 是否有效
- 说明：长文本，说明 映射备注
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- nomenclature：多对一 -> BarcodeNomenclature

#### 唯一约束
- 唯一约束 唯一条码值：条码值

### Conduct（行为声明）

#### 操作
- register（类型：创建），可写字段：条码值、资源类型、资源编号、说明，参数：nomenclature_id：唯一标识
- 查询
- 更新，可写字段：资源类型、资源编号、说明、启用
- 停用（类型：更新），说明：停用条码映射
- 删除

#### 校验
- register时，条码值 不能为空
- register时，资源类型 不能为空
- register时，资源编号 不能为空

#### 变更
- 在 停用 时，将 启用 设为 literal（否）
- 在 register / 更新 / 停用 时，将 编号 设为 编号

#### 事件
- 事件：查询 -> 条码.scanned
- 事件：register -> 条码.mapping.registered
- 事件：停用 -> 条码.mapping.deactivated

#### 工作流
- 流程：mapping_lifecycle：register -> 更新 -> 停用 -> 删除（条码映射生命周期）

## 实体：GS1ApplicationIdentifier（聚合根）

- 说明：GS1应用标识符定义，维护AI编号到数据含义的映射关系（通常为预置数据）
- 来源：基于 GS1ApplicationIdentifier；来源域 条码

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- AI编号（如"01"=GTIN，"10"=批号，"17"=有效期）（ai_code）：文本（必填）
- 名称：文本（必填），说明 标识符名称
- 数据类型：枚举（必填），可选值：标识符 / alpha / 日期 / 度量，说明 数据类型
- 固定长度：整数，说明 固定长度（为空表示变长，需FNC1分隔）
- 最大长度：整数，说明 最大长度（变长字段适用）
- 格式：文本，说明 值格式正则表达式
- 说明：长文本，说明 标识符详细说明
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 规则：一对多 -> 条码规则，外键 gs1_ai_id

#### 唯一约束
- 唯一约束 unique_ai_code：ai_code

### Conduct（行为声明）

#### 操作
- 创建，可写字段：ai_code、名称、数据类型、固定长度、最大长度、格式、说明
- 查询
- 更新，可写字段：名称、数据类型、固定长度、最大长度、格式、说明
- 删除

#### 校验
- 创建时，ai_code 不能为空
- 创建时，名称 不能为空
- 创建时，数据类型 不能为空

#### 变更
- 在 创建 / 更新 时，将 编号 设为 编号

#### 工作流
- 流程：gs1_ai_maintain_flow：创建 -> 更新 -> 删除（GS1应用标识符维护）
