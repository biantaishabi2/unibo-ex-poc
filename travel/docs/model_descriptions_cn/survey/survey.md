# 模型业务说明

- 版本：1.0
- 领域：调研
- 领域说明：问卷调查领域模型，涵盖问卷、题目、选项、答题记录与答案行
- 实体数量：7

## 实体：调研（聚合根）

- 说明：问卷主体，支持普通问卷、实时会话、认证考试等多种类型
- 来源：基于 调研；来源域 调研

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 标题：文本（必填），说明 问卷标题
- 状态：枚举，默认值 草稿，可选值：草稿 / 打开 / 已关闭，说明 状态：草稿 / 已发布 / 已关闭
- 调研类型：枚举，默认值 调研，可选值：调研 / 实时会话 / 评估 / 自定义规则，说明 问卷类型
- 访问模式：枚举，默认值 公开，可选值：公开 / 令牌 / 需登录，说明 访问模式：公开 / 令牌邀请 / 需登录
- 用户登录必填：布尔，默认值 否，说明 public 模式下是否要求登录
- 访问令牌：唯一标识（必填、自动生成），说明 自动生成的访问令牌
- 问题布局：枚举，默认值 单页，可选值：单页 / 页面每区域 / 页面每问题，说明 布局模式
- 问题选择：枚举，默认值 全部，可选值：全部 / 随机，说明 题目选择模式
- 随机问题数量：整数，说明 随机抽题数量（每个分区）
- 评分类型：枚举，默认值 无评分，可选值：无评分 / 答案后显示评分 / 页面后显示评分 / 不显示答案评分，说明 评分模式
- 评分成功最小：浮点，默认值 80.0，说明 及格线百分比
- 时间限定：布尔，默认值 否，说明 是否限时
- 时间限制：浮点，必须大于 0（时限必须大于零），说明 时限（分钟）
- 尝试限定：布尔，默认值 否，说明 是否限制答题次数
- 尝试限制：整数，说明 最大尝试次数
- 认证给予徽章：布尔，默认值 否，说明 及格后是否授予徽章
- 会话状态：枚举，可选值：就绪 / 进行中，说明 实时会话状态
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 问题且页面编号列表：一对多 -> 问题
- 问题：一对多 -> 问题
- 页面编号列表：一对多 -> 问题
- 用户输入：一对多 -> 用户输入

### Conduct（行为声明）

#### 操作
- 创建，可写字段：标题、调研类型、访问模式、用户登录必填、问题布局、问题选择、随机问题数量、评分类型、评分成功最小、时间限定、时间限制、尝试限定、尝试限制、认证给予徽章
- 查询
- 更新，可写字段：标题、调研类型、访问模式、用户登录必填、问题布局、问题选择、随机问题数量、评分类型、评分成功最小、时间限定、时间限制、尝试限定、尝试限制、认证给予徽章
- 操作打开（类型：更新），说明：发布问卷
- 操作关闭（类型：更新），说明：关闭问卷
- 操作草稿（类型：更新），说明：重置为草稿（从已关闭状态）

#### 校验
- 创建时，标题 不能为空
- 操作打开时，只有草稿状态可以发布
- 操作关闭时，只有已发布状态可以关闭
- 操作草稿时，只有已关闭状态可以重置为草稿

#### 变更
- 在 操作打开 时，将 状态 设为 打开
- 在 操作关闭 时，将 状态 设为 已关闭
- 在 操作草稿 时，将 状态 设为 草稿
- 在 创建 / 更新 / 操作打开 / 操作关闭 / 操作草稿 时，将 编号 设为 编号

#### 计算
- 计算字段 回答数量：整数，规则 数量(用户输入)
- 计算字段 回答完成数量：整数，规则 数量(用户输入)
- 计算字段 成功数量：整数，规则 数量(用户输入)
- 计算字段 回答评分平均：浮点，规则 平均(用户输入.评分百分比)
- 计算字段 成功比率：浮点，规则 成功数量 × 100 ÷ 回答数量
- 计算字段 回答时长平均：浮点
- 计算字段 问题数量：整数，规则 数量(问题)
- 计算字段 评分最大可获得：浮点

#### 事件
- 事件：操作打开 -> 调研.调研.已打开
- 事件：操作关闭 -> 调研.调研.已关闭

#### 工作流
- 流程：survey_lifecycle：创建 -> 操作打开 -> 操作关闭 -> 操作草稿（问卷生命周期）
- 流程：survey_edit_flow：创建 -> 更新（问卷编辑流程）

## 实体：问题

- 说明：问卷题目，支持 8 种题目类型（选择/文本/数值/时间/矩阵）
- 来源：基于 问题；来源域 调研

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 标题：文本（必填），说明 题目标题
- 问题类型：枚举（必填），可选值：单选 / 多选 / 单行文本 / 多行文本 / 数值 / 日期 / 日期时间 / 矩阵，说明 题目类型
- 序列：整数（必填），说明 排序序号
- 约束必填：布尔，默认值 否，说明 是否必答
- 约束错误消息：文本，说明 必答校验失败提示
- 评论允许：布尔，默认值 否，说明 是否允许备注
- 评论数量回答：布尔，默认值 否，说明 备注是否算作回答
- 验证邮箱：布尔，默认值 否，说明 char_box 是否校验邮箱格式
- 验证最小浮点值：浮点，说明 numerical_box 最小值
- 验证最大浮点值：浮点，说明 numerical_box 最大值
- 验证最小日期：日期，说明 date 最小值
- 验证最大日期：日期，说明 date 最大值
- 矩阵子类型：枚举，默认值 简单，可选值：简单 / 多项，说明 矩阵子类型
- 保存邮箱：布尔，默认值 否，说明 char_box 值保存为邮箱
- 保存昵称：布尔，默认值 否，说明 char_box 值保存为昵称
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 调研：多对一 -> 调研，必填关系
- 页面：多对一 -> 问题
- 建议回答编号列表：一对多 -> 回答
- 矩阵行编号列表：一对多 -> 回答
- 触发中回答编号列表：多对多 -> 回答，中间关系 问题触发回答链接

### Conduct（行为声明）

#### 操作
- 创建，可写字段：标题、问题类型、序列、约束必填、约束错误消息、评论允许、评论数量回答、验证邮箱、验证最小浮点值、验证最大浮点值、验证最小日期、验证最大日期、矩阵子类型、保存邮箱、保存昵称，参数：调研编号：唯一标识（必填）
- 查询
- 更新，可写字段：标题、问题类型、序列、约束必填、约束错误消息、评论允许、评论数量回答、验证邮箱、验证最小浮点值、验证最大浮点值、验证最小日期、验证最大日期、矩阵子类型、保存邮箱、保存昵称
- 删除

#### 校验
- 创建时，标题 不能为空
- 创建时，问题类型 不能为空

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 计算
- 计算字段 已评分问题：布尔，规则 op=neq，args=调研.评分类型、无评分 且 问题类型 属于 单选、多选、数值、日期、日期时间、矩阵

#### 工作流
- 流程：question_write_flow：创建 -> 更新 -> 删除（题目写操作覆盖流程）

## 实体：用户输入（聚合根）

- 说明：用户答题记录，跟踪答题状态、时间和得分
- 来源：基于 用户输入；来源域 调研

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 状态：枚举，默认值 新，可选值：新 / 进行中 / 完成，说明 答题状态
- 开始日期时间：日期时间，说明 开始时间
- 结束日期时间：日期时间，说明 完成时间
- 截止日：日期时间，说明 截止时间
- 访问令牌：唯一标识（必填、自动生成），说明 访问令牌
- 邀请令牌：唯一标识，说明 邀请令牌（token 模式）
- 邮箱：文本，说明 答题者邮箱
- 昵称：文本，说明 答题者昵称
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 调研：多对一 -> 调研，必填关系
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号
- 明细行：一对多 -> 用户输入行，管理模式 直接管理

### Conduct（行为声明）

#### 操作
- 创建，可写字段：邮箱、昵称、邀请令牌，参数：调研编号：唯一标识（必填）
- 查询
- 标记进行中（类型：更新），说明：开始答题
- 标记完成（类型：更新），说明：完成答题

#### 校验
- 标记进行中时，只有新建状态可以开始答题
- 标记完成时，只有进行中状态可以完成答题

#### 变更
- 在 标记进行中 时，将 状态 设为 进行中
- 在 标记进行中 时，将 开始日期时间 设为 当前时间
- 在 标记完成 时，将 状态 设为 完成
- 在 标记完成 时，将 结束日期时间 设为 当前时间
- 在 创建 / 标记进行中 / 标记完成 时，将 编号 设为 编号

#### 计算
- 计算字段 评分合计：浮点，规则 合计(明细行.回答评分)
- 计算字段 评分百分比：浮点，规则 评分合计 × 100 ÷ 调研.评分最大可获得
- 计算字段 评分成功：布尔，规则 评分百分比 ≥ 调研.评分成功最小
- 计算字段 调研时间限制已达到：布尔，规则 当前时间 > 开始日期时间 + 调研.时间限制

#### 事件
- 事件：标记完成 -> 调研用户输入完成

#### 工作流
- 流程：answering_flow：创建 -> 标记进行中 -> 标记完成（答题流程）

#### 关系
