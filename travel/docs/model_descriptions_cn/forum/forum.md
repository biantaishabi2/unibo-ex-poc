- 领域说明：论坛管理领域模型，涵盖论坛、帖子、投票、标签及 Karma 声望系统

## 实体：论坛（聚合根）

- 说明：论坛实例，承载 Karma 阈值配置与全局设置
- 来源：基于 论坛；来源域 论坛

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 论坛名称
- 模式：枚举，默认值 问题，可选值：问题 / 讨论，说明 论坛模式（questions=单一最佳答案，discussions=多答案讨论）
- 隐私：枚举，默认值 公开，可选值：公开 / 已连接 / 已授权，说明 访问权限（public=公开，connected=需登录，authorized=指定用户组）
- 已授权分组编号：唯一标识，说明 privacy=authorized 时的授权用户组
- 说明：长文本，说明 论坛描述
- 欢迎消息：长文本，说明 欢迎消息
- 默认过账类型：枚举，默认值 问题，可选值：问题 / 链接 / 讨论，说明 新帖默认类型
- 默认订单：文本，默认值 相关度，说明 默认排序方式

- 允许分享：布尔，默认值 是，说明 是否允许分享
- 允许标记违规：布尔，默认值 是，说明 是否允许标记冒犯

## 实体：过账（聚合根）

- 说明：帖子实体，通过 parent_id 区分问题（null）与回答（非null）
- 来源：基于 过账；来源域 论坛

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 帖子标题（仅问题级别需要）
- 内容：长文本（必填），说明 帖子内容（经 sanitize 处理）
- 过账类型：枚举，可选值：问题 / 链接 / 讨论，说明 帖子类型
- 状态：枚举，默认值 启用，可选值：启用 / 待处理 / 关闭 / 违规 / 已标记，说明 帖子状态
- 正确：布尔，默认值 否，说明 是否为采纳的最佳答案
- 视图：整数，默认值 0，说明 浏览数
- 最近活动日期：日期时间，说明 最后活跃时间，默认为创建时间
- 关闭日期：日期时间，说明 关闭时间
- 关闭原因编号：唯一标识，说明 关闭原因
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 论坛：多对一 -> 论坛，必填关系
- 上级：多对一 -> 过账
- 子项：一对多 -> 过账，外键 上级编号
- 创建标识：多对一 -> 参与方，外键 创建标识参与方编号
- 版主：多对一 -> 参与方，外键 版主参与方编号
- 已关闭标识：多对一 -> 参与方，外键 已关闭标识参与方编号
- 投票：一对多 -> 投票
- 标签：多对多 -> 标签，中间关系 过账标签链接
- 收藏：多对多 -> 参与方，外键 收藏参与方编号，中间关系 过账收藏链接

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、内容、过账类型，参数：论坛编号：唯一标识（必填）；上级编号：唯一标识；标签编号列表：列表
- 查询
- 更新，可写字段：名称、内容、标签编号列表
- 关闭（类型：更新），说明：关闭帖子，参数：关闭原因编号：唯一标识（必填）
- 重新打开（类型：更新），说明：重新打开帖子
- 标记（类型：更新），说明：标记帖子
- 标记违规（类型：更新），说明：确认帖子冒犯并施加 Karma 惩罚
- 验证（类型：更新），说明：版主审核通过待审核帖子
- 接受回答（类型：更新），说明：采纳为最佳答案
- 取消采纳（类型：更新），说明：取消采纳
- 切换收藏（类型：更新），说明：切换收藏状态
- 删除

#### 校验
- 创建时，名称 不能为空
- 创建时，内容 不能为空
- 关闭时，只有活跃状态的帖子可以关闭
- 重新打开时，只有已关闭的帖子可以重新打开
- 标记时，只有活跃状态的帖子可以标记
- 标记违规时，只有已标记的帖子可以确认冒犯
- 验证时，只有待审核的帖子可以通过审核
- 接受回答／取消采纳时，上级编号 不能为空（只有回答可以被采纳）
- 创建时，Karma 不足，无法提问
- 标记时，Karma 不足，无法标记冒犯

#### 策略
- 权限：* 操作，当 操作者.管理员 时允许
- 权限：查询 操作，当 是 时允许
- 权限：创建 操作，当 操作者.声望值 ≥ 论坛.声望值提问 或 操作者.声望值 ≥ 论坛.声望值回答 时允许
- 权限：更新 操作，当 操作者.编号 = 数据.创建标识编号 且 操作者.声望值 ≥ 论坛.声望值编辑自有 时允许
- 权限：更新 操作，当 操作者.声望值 ≥ 论坛.声望值编辑全部 时允许
- 权限：删除 操作，当 操作者.编号 = 数据.创建标识编号 且 操作者.声望值 ≥ 论坛.声望值取消关联自有 时允许
- 权限：删除 操作，当 操作者.声望值 ≥ 论坛.声望值取消关联全部 时允许

#### 变更
- 在 创建 时，将 创建标识 设为当前操作人
- 在 创建 时，将 最近活动日期 设为 当前时间
- 在 创建 时，将 状态 设为 （操作者.声望值 ≥ 论坛.声望值审核，启用，待处理）
- 在 验证 时，将 状态 设为 启用
- 在 验证 时，将 版主 设为当前操作人
- 在 关闭 时，将 状态 设为 关闭
- 在 关闭 时，将 关闭日期 设为 当前时间
- 在 关闭 时，将 已关闭标识 设为当前操作人
- 在 重新打开 时，将 状态 设为 启用
- 在 重新打开 时，设置 关闭日期
- 在 重新打开 时，设置 已关闭标识
- 在 标记 时，将 状态 设为 已标记
- 在 标记违规 时，将 状态 设为 违规
- 在 接受回答 时，将 正确 设为 是
- 在 取消采纳 时，将 正确 设为 否
- 在 创建 / 更新 / 关闭 / 重新打开 / 标记 / 标记违规 / 验证 / 接受回答 / 取消采纳 / 切换收藏 / 删除 时，将 编号 设为 编号

#### 计算
- 计算字段 纯文本内容：文本，规则 truncate(html2plaintext(内容), 500)
- 计算字段 网站链接：文本，规则 格式(/forum/{}/{}, 论坛.slug, slug)
- 计算字段 投票数量：整数，规则 合计(投票.投票)
- 计算字段 用户投票：整数，规则 coalesce(投票（条件: 用户编号 = 当前用户）, 0)
- 计算字段 收藏数量：整数，规则 数量(收藏)
- 计算字段 用户收藏：布尔，规则 contains(收藏, 当前用户)
- 计算字段 下级数量：整数，规则 数量(子项)
- 计算字段 已验证回答：布尔，规则 exists(子项（条件: 正确 = 是）)
- 计算字段 标识已回答：布尔，规则 exists(子项（条件: 创建标识 = 当前用户）)
- 计算字段 自身回复：布尔，规则 创建标识 = 上级.创建标识
- 计算字段 相关度：金额，规则 签署(投票数量) × pow(abs(投票数量 - 1), 论坛.相关度过账投票) ÷ pow(天数自(创建时间) + 2, 论坛.相关度时间衰减)

#### 事件
- 事件：创建 -> 论坛.过账.创建
- 事件：验证 -> 论坛.过账.已验证
- 事件：关闭 -> 论坛.过账.已关闭
- 事件：标记 -> 论坛.过账.已标记
- 事件：标记违规 -> 论坛帖子已标记违规
- 事件：接受回答 -> 论坛过账回答已接受
- 事件：取消采纳 -> 论坛帖子回答已取消采纳

#### 工作流
- 流程：post_lifecycle：创建 -> 验证 -> 更新 -> 关闭 -> 重新打开 -> 标记 -> 标记违规 -> 接受回答 -> 取消采纳 -> 切换收藏 -> 删除（帖子生命周期（创建→审核→活跃→关闭/冒犯））
