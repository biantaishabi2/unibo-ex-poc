# 模型业务说明

- 版本：1.0
- 领域：物联网
- 领域说明：物联网与网络电话领域模型，涵盖 IoT 网关、设备管理、触发规则、事件日志，以及 VoIP 服务商、通话记录、呼叫队列、队列成员、拨号计划、入站号码、语音信箱、会议室
- 实体数量：20

## 实体：物联网盒子（聚合根）

- 说明：IoT 网关盒子，负责连接和管理物理设备，通过心跳保持在线状态
- 来源：基于 固定资产；来源域 ofbiz/accounting；过滤条件 固定资产类型编号=物联网网关

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成）
- 名称：文本（必填），说明 显示名称
- IP地址：文本，说明 IP 地址
- 标识符：文本（必填），说明 唯一标识令牌
- 配对令牌：文本，默认值 random_8_char，说明 一次性配对令牌，配对成功后置 nil
- 固件版本：文本，说明 固件版本号
- 连接类型：枚举（必填），默认值 以太网，可选值：以太网 / WiFi / 蜂窝，说明 网络连接方式
- 状态：枚举（必填），默认值 待处理，可选值：待处理 / 在线 / 离线 / 错误，说明 网关状态
- 最近心跳：日期时间，说明 最后心跳时间戳
- 最近已查看：日期时间，说明 最后可见时间
- 自动更新：布尔，默认值 是，说明 是否自动更新固件
- 网络信息：jsonb，说明 网络详情 {mac, ssid, gateway, dns, signal_strength}
- 配对：日期时间，说明 配对成功时间

#### 关系
- 设备：一对多 -> 物联网设备，外键 物联网箱编号
- 配对：多对一 -> 参与方，外键 配对参与方编号
- 组织：多对一 -> 组织，外键 组织编号

#### 唯一约束
- 唯一约束 唯一标识符：标识符

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、IP地址、标识符、固件版本、连接类型、自动更新、网络信息、组织编号
- 查询
- 更新，可写字段：名称、IP地址、固件版本、连接类型、自动更新、网络信息
- 注册设备（类型：更新），说明：通过配对令牌完成配对，参数：配对令牌：文本（必填）
- 心跳（类型：更新），说明：接收心跳更新，可写字段：IP地址、固件版本、网络信息

#### 校验
- 创建时，名称 不能为空
- 创建时，标识符 不能为空
- 注册设备时，只有待配对状态可以注册

#### 变更
- 在 注册设备 时，将 状态 设为 在线
- 在 注册设备 时，设置 配对令牌
- 在 注册设备 时，将 配对 设为 当前时间
- 在 注册设备 时，将 配对 设为当前操作人
- 在 心跳 时，将 最近心跳 设为 当前时间
- 在 心跳 时，将 最近已查看 设为 当前时间
- 在 创建 / 更新 / 注册设备 / 心跳 时，将 编号 设为 编号

#### 计算
- 计算字段 设备数量：整数，规则 数量(设备)
- 计算字段 过期：布尔，规则 日期时间差异(当前时间, 最近心跳) > 300

#### 事件
- 事件：注册设备 -> 物联网.箱.配对
- 事件：心跳超时 -> 物联网.箱.离线

#### 工作流
- 流程：iot_box_lifecycle_flow：创建 -> 注册设备 -> 心跳 -> 更新（IoTBox 创建、配对注册、心跳更新与配置维护流程）

## 实体：物联网设备

- 说明：IoT 设备/外设，通过网关发现和管理，按 identifier+box_id 做 upsert
- 来源：基于 固定资产；来源域 ofbiz/accounting；过滤条件 固定资产类型编号=物联网设备

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成）
- 名称：文本（必填），默认值 自动生成，说明 设备名称
- 标识符：文本（必填），说明 设备标识（唯一于 box 内）
- 设备类型：枚举（必填），可选值：打印机 / 缩放 / 相机 / 扫描器 / 传感器 / 显示 / 支付终端，说明 设备类型
- 连接：枚举（必填），可选值：USB / 蓝牙 / WiFi / HDMI / 网络，说明 连接方式
- 状态：枚举（必填），默认值 已断开，可选值：已连接 / 已断开 / 错误，说明 设备状态
- 驱动名称：文本，说明 驱动标识（如 "epson_tm_t20"）
- 能力：文本列表，默认值 ，说明 能力列表，如 ["print", "cut", "cash_drawer"]
- 配置：jsonb，默认值 ，说明 设备专属配置（按类型不同结构不同）
- 最近值：jsonb，说明 最新读数/状态
- 最近活动：日期时间，说明 最后事件时间
- 健康状态：枚举，默认值 正常，可选值：正常 / 警告 / 错误，说明 健康状态
- 健康消息：文本，说明 健康状态描述
- 制造商：文本，说明 制造商
- 模型：文本，说明 型号

#### 关系
- 物联网箱：多对一 -> 物联网盒子，必填关系
- 触发规则：一对多 -> 触发规则，外键 设备编号
- 活动日志：一对多 -> 活动日志，外键 设备编号

#### 唯一约束
- 唯一约束 唯一设备每箱：物联网箱编号、标识符

### Conduct（行为声明）

#### 操作
- 创建或更新（类型：创建），说明：按 identifier+box_id 查找或创建设备，可写字段：物联网箱编号、名称、标识符、设备类型、连接、驱动名称、能力、配置、制造商、模型
- 查询
- 更新，可写字段：名称、驱动名称、能力、配置
- 更新值（类型：更新），说明：更新设备最新读数，可写字段：最近值

#### 校验
- 创建或更新时，标识符 不能为空
- 创建或更新时，物联网箱编号 不能为空

#### 变更
- 在 更新值 时，将 最近活动 设为 当前时间
- 在 创建或更新 时，将 名称 设为 concat（设备类型，-，标识符）
- 在 创建或更新 / 更新 / 更新值 时，将 编号 设为 编号

#### 计算
- 计算字段 在线：布尔，规则 状态 = 已连接 且 op=neq，args=健康状态、错误
- 计算字段 时间自最近活动：整数，规则 日期时间差异(当前时间, 最近活动)

#### 工作流
- 流程：iot_device_sync_flow：创建或更新 -> 更新 -> 更新值（设备发现上报、配置更新与读数同步流程）

## 实体：触发规则（聚合根）

- 说明：IoT 触发规则，当设备事件匹配时执行指定动作，支持冷却防抖和优先级排序
- 来源：基于 工作任务；来源域 ofbiz/workeffort；过滤条件 工作工作量类型编号=物联网触发规则

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成）
- 名称：文本（必填），说明 规则名称
- 说明：文本，说明 人类可读描述
- 活动类型：枚举（必填），可选值：扫描 / 重量稳定 / 按钮按下 / 测量 / 温度警报，说明 事件类型
- 条件：文本，说明 可选条件表达式（如 "weight > 0.5kg"）
- 操作类型：枚举（必填），可选值：打印报表 / 创建记录 / 调用Webhook / 更新字段 / 通知用户，说明 动作类型
- 操作配置：jsonb（必填），说明 动作配置（结构随 action_type 变化）
- 是否启用：布尔（必填），默认值 是，说明 是否启用
- 优先级：整数，默认值 10，说明 执行优先级（越小越先）
- 停止格式匹配校验：布尔，默认值 否，说明 命中后阻止后续低优先级规则
- 冷却秒：整数，默认值 5，说明 冷却时间（秒）
- 最近已触发：日期时间，说明 上次触发时间
- 执行数量：整数，默认值 0，说明 累计成功次数
- 错误数量：整数，默认值 0，说明 累计失败次数
- 错误操作：枚举，默认值 通知管理员，可选值：忽略 / 重试一次 / 通知管理员，说明 失败处理策略

#### 关系
- 设备：多对一 -> 物联网设备，必填关系
- 活动日志：一对多 -> 活动日志，外键 触发规则编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、说明、设备编号、活动类型、条件、操作类型、操作配置、是否启用、优先级、停止格式匹配校验、冷却秒、错误操作
- 查询
- 更新，可写字段：名称、说明、条件、操作类型、操作配置、是否启用、优先级、停止格式匹配校验、冷却秒、错误操作
- 启用（类型：更新），说明：启用规则
- 停用（类型：更新），说明：停用规则

#### 校验
- 创建时，名称 不能为空
- 创建时，设备编号 不能为空
- 创建时，操作配置 不能为空

#### 变更
- 在 启用 时，将 是否启用 设为 是
- 在 停用 时，将 是否启用 设为 否
- 在 创建 / 更新 / 启用 / 停用 时，将 编号 设为 编号

#### 计算
- 计算字段 成功费率：金额，规则 执行数量 ÷ 执行数量 + 错误数量
- 计算字段 包含冷却：布尔，规则 日期时间差异(当前时间, 最近已触发) < 冷却秒

#### 工作流
- 流程：trigger_rule_toggle_flow：创建 -> 更新 -> 启用 -> 停用（触发规则创建、维护与启停流程）

## 实体：活动日志

- 说明：IoT 事件日志，只追加写入，记录每个设备事件及规则处理结果，30 天自动清理
- 来源：基于 沟通活动；来源域 ofbiz/party；过滤条件 沟通活动类型编号=物联网活动

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成）
- 活动类型：文本（必填），说明 事件类型（scan / measure / status_change / error / heartbeat）
- 载荷：jsonb（必填），说明 原始事件数据
- 已处理：布尔（必填），默认值 否，说明 是否已被规则引擎处理
- 操作结果：枚举，可选值：成功 / 失败 / 跳过 / 冷却，说明 处理结果
- 操作错误消息：文本，说明 失败时错误信息
- 处理中时间毫秒：整数，说明 处理耗时（毫秒）
- 创建：日期时间（必填、自动生成），说明 事件到达时间

#### 关系
- 设备：多对一 -> 物联网设备，必填关系
- 箱：多对一 -> 物联网盒子，必填关系
- 触发规则：多对一 -> 触发规则

### Conduct（行为声明）

#### 操作
- 创建，可写字段：设备编号、箱编号、活动类型、载荷
- 查询
- 标记已处理（类型：更新），说明：标记为已处理，可写字段：触发规则编号、操作结果、操作错误消息、处理中时间毫秒

#### 校验
- 创建时，设备编号 不能为空
- 创建时，活动类型 不能为空
- 创建时，载荷 不能为空

#### 变更
- 在 标记已处理 时，将 已处理 设为 是
- 在 创建 / 标记已处理 时，将 编号 设为 编号

#### 计算
- 计算字段 错误：布尔，规则 操作结果 = 失败
- 计算字段 年龄天数：整数，规则 日期时间差异天数(当前时间, 创建)

#### 工作流
- 流程：event_log_processing_flow：创建 -> 标记已处理（事件日志写入与处理完成标记流程）

## 实体：VoIP提供商（聚合根）

- 说明：SIP 服务商配置，存储 SIP/STUN/TURN 连接参数及 WebSocket/编解码器配置，密码加密存储
- 来源：基于 VoIP提供商；来源域 物联网

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成）
- 名称：文本（必填），说明 显示名
- SIP服务器：文本（必填），说明 SIP 服务器地址
- SIP端口：整数，默认值 5060，说明 端口（TLS 使用 5061）
- 运输：枚举（必填），默认值 WSS，可选值：UDP / TCP / TLS / WSS，说明 传输协议
- 域：文本（必填），说明 SIP domain
- 出站代理：文本，说明 出站代理地址
- STUN服务器：文本，说明 STUN 服务器（WebRTC NAT 穿透）
- 轮次服务器：文本，说明 TURN 服务器（WebRTC relay）
- 轮次用户名：文本，说明 TURN 用户名
- 轮次密码：文本，说明 TURN 密码（AES-256 加密存储）
- WebSocket 连接 URL（WebRTC 模式使用）（websocket_url）：文本
- 支持的编解码器列表（逗号分隔，如 opus,g711a,g711u）（codecs）：文本
- 默认：布尔，默认值 否，说明 是否默认服务商

#### 关系
- 组织：多对一 -> 组织，必填关系
- 通话：一对多 -> VoIP通话，外键 供应商编号
- user_configs：一对多 -> VoIPUserConfig，外键 供应商编号

#### 唯一约束
- 唯一约束 唯一默认每组织：组织编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、SIP服务器、SIP端口、运输、域、出站代理、STUN服务器、轮次服务器、轮次用户名、轮次密码、websocket_url、codecs、默认、组织编号
- 查询
- 更新，可写字段：名称、SIP服务器、SIP端口、运输、域、出站代理、STUN服务器、轮次服务器、轮次用户名、轮次密码、websocket_url、codecs、默认
- 删除

#### 校验
- 创建时，名称 不能为空
- 创建时，SIP服务器 不能为空
- 创建时，域 不能为空

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：voip_provider_lifecycle_flow：创建 -> 更新 -> 删除（VoIP 服务商配置创建、更新与删除流程）

## 实体：VoIP通话（聚合根）

- 说明：通话记录，跟踪从振铃到结束的完整生命周期，支持保持/转接，自动关联联系人和商机
- 来源：基于 沟通活动；来源域 ofbiz/party；过滤条件 沟通活动类型编号=电话沟通

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成）
- 主叫：文本（必填），说明 主叫号码/分机
- 被叫：文本（必填），说明 被叫号码/分机
- 方向：枚举（必填），可选值：入库 / 出库，说明 通话方向
- 状态：枚举（必填），默认值 响铃，可选值：响铃 / 进行中 / 保留 / 已完成 / 未接 / 语音信箱，说明 通话状态（完整 enum）
- 处置：枚举，可选值：已回答 / 无回答 / 忙碌 / 失败 / 语音信箱 / 已取消，说明 结束原因
- 开始时间：日期时间，说明 接通时间
- 结束时间：日期时间，说明 挂断时间
- 时长：整数，默认值 0，说明 通话时长（秒）
- 录制链接：文本，说明 录音文件 URL
- 录制时长：整数，说明 录音时长（秒）
- 转录：长文本，说明 通话转写文本
- 转录状态：枚举，可选值：待处理 / 处理中 / 已完成 / 失败，说明 转写状态
- 备注：长文本，说明 通话备注
- 标签：文本列表，默认值 ，说明 标签
- SIP通话编号：文本，说明 SIP Call-ID header
- 关联模型：文本，说明 通用关联模型名
- 关联记录编号：bigint，说明 通用关联记录 ID
- 转账：文本，说明 转接目标号码/分机
- 转账类型：枚举，可选值：blind / attended，说明 转接类型（盲转/咨询转）
- 保留时长：整数，默认值 0，说明 累计保持时长（秒）
- 保留开始：日期时间，说明 保持开始时间（用于计算累计时长）

#### 关系
- 用户：多对一 -> 参与方，外键 用户参与方编号
- 组织：多对一 -> 组织，必填关系
- 供应商：多对一 -> VoIP提供商，外键 供应商编号
- 关联联系：多对一 -> 联系，外键 关联联系编号
- 关联线索：多对一 -> 客户关系线索，外键 关联线索编号
- 关联工单：多对一 -> 服务台工单，外键 关联工单编号
- 队列：多对一 -> 通话队列，外键 队列编号
- 转接来源：多对一 -> VoIP通话，外键 转接来源通话编号
- 语音信箱：一对一 -> 语音信箱，外键 通话编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：主叫、被叫、方向、用户编号、组织编号、队列编号、SIP通话编号
- 查询
- 更新，可写字段：备注、标签、关联联系编号、关联线索编号、关联工单编号、关联模型、关联记录编号
- 回答（类型：更新），说明：接听通话
- 结束通话（类型：更新），说明：结束通话，参数：hangup_cause：文本
- 标记未接（类型：更新），说明：标记未接
- 语音信箱（类型：更新），说明：转语音信箱，可写字段：录制链接、录制时长
- 添加备注（类型：更新），说明：添加备注，可写字段：备注、标签
- 保留（类型：更新），说明：通话保持
- unhold（类型：更新），说明：恢复通话
- 转账（类型：更新），说明：转接通话，参数：目标单号：文本（必填）；转账模式：文本（必填）

#### 校验
- 创建时，主叫 不能为空
- 创建时，被叫 不能为空
- 回答时，只有振铃中的通话可以接听
- 结束通话时，只有振铃或通话中的通话可以结束

### Conduct（行为声明）

#### 操作
- 创建，可写字段：主叫、时长、录制链接、组织编号，参数：用户编号：bigint（必填）；通话编号：bigint
- 查询
- 标记查询（类型：更新），说明：标记已读
- 归档（类型：更新），说明：归档语音留言
- 删除

#### 校验

- 创建时，组织编号 不能为空

- 事件：transcribe -> voip.语音信箱.transcribed

## 实体：ConferenceRoom（聚合根）

- 说明：虚拟电话会议室配置，支持 PIN 码保护、录音和参会人管理
- 来源：基于 ConferenceRoom；来源域 物联网

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成）
- 名称：文本（必填），说明 会议室名称
- 扩展：文本（必填），说明 内部分机号
- 置顶：文本，说明 进入 PIN 码
- 管理员置顶：文本，说明 管理员 PIN 码
- 最大参与者：整数，默认值 50，说明 最大参会人数
- 是否录音（record_conference）：布尔，默认值 否
- 静音加入：布尔，默认值 否，说明 加入时静音
- 公告加入请假：布尔，默认值 是，说明 播报加入/离开
- 是否启用：布尔，默认值 是，说明 是否激活

#### 关系
- 组织：多对一 -> 组织，必填关系
- incoming_numbers：一对多 -> IncomingNumber，外键 conference_room_id

#### 唯一约束
- 唯一约束 唯一扩展每组织：扩展、组织编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、扩展、置顶、管理员置顶、最大参与者、record_conference、静音加入、公告加入请假、是否启用、组织编号
- 查询
- 更新，可写字段：名称、置顶、管理员置顶、最大参与者、record_conference、静音加入、公告加入请假、是否启用
- 删除
- start_conference（类型：更新），说明：开始会议
- end_conference（类型：更新），说明：结束会议

#### 校验
- 创建时，名称 不能为空
- 创建时，扩展 不能为空
- 创建时，组织编号 不能为空
- 创建／更新时，最大参与者 必须大于 0（最大参会人数必须大于零）
- start_conference时，只有激活的会议室可以开始会议

#### 变更
- 在 创建 / 更新 / 删除 / start_conference / end_conference 时，将 编号 设为 编号

#### 事件
- 事件：start_conference -> voip.conference.开始
- 事件：end_conference -> voip.conference.ended

#### 工作流
- 流程：conference_room_lifecycle：创建 -> 更新 -> start_conference -> end_conference -> 删除（会议室创建、维护、开始/结束会议与删除流程）
