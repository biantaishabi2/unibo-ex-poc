# 模型业务说明

- 版本：1.0
- 领域：电商
- 领域说明：电商领域模型，涵盖产品模板、变体、分类、价格、目录、购物车、主题
- 实体数量：25

## 实体：产品模板（聚合根）

- 说明：产品模板
- 来源：基于 产品；来源域 ofbiz/product

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 产品编码：文本（必填），说明 产品编号
- 名称：文本（必填）
- 产品类型：枚举，默认值 商品，可选值：商品 / 服务 / 消耗品
- 状态：枚举，默认值 草稿，可选值：草稿 / 启用 / 已停产
- 说明：长文本
- 说明电商：长文本，说明 电商专用描述（HTML），写入时自动清理空标签
- 内部备注：长文本
- 重量：金额
- 重量单位：文本，默认值 kg
- 是否发布：布尔，默认值 否，说明 是否上架（多站点发布）
- 网站序列：整数，默认值 0，说明 商城排序，步进5，支持 top/bottom/up/down 操作
- 网站大小（website_size_x）：整数，默认值 1，说明 网格布局宽度
- 网站大小（website_size_y）：整数，默认值 1，说明 网格布局高度
- 基础单位数量：金额，说明 基础计量单位数量（用于"每kg价格"展示）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 变体：一对多 -> 产品变体，外键 模板编号
- 分类：多对一 -> 产品分类
- 价格：一对多 -> 产品价格，外键 产品编号
- 组织视图：一对多 -> 产品模板组织视图，外键 产品模板编号
- 网站标签条：多对一 -> 标签条
- 公开分类：多对多 -> 产品分类，中间关系 产品模板公开分类链接
- 备选产品：多对多 -> 产品模板，中间关系 产品模板备选链接
- 配件产品：多对多 -> 产品模板，中间关系 产品模板配件链接
- 基础单位：多对一 -> 单位

#### 唯一约束
- 唯一约束 唯一产品编码：产品编码

### Conduct（行为声明）

#### 操作
- 创建，可写字段：产品编码、名称、产品类型、说明、说明电商、内部备注、重量、重量单位、基础单位数量，参数：分类编号：唯一标识
- 查询
- 更新，可写字段：名称、产品类型、状态、说明、说明电商、内部备注、重量、重量单位、是否发布、网站序列、网站大小、网站大小、基础单位数量
- 发布（类型：更新），说明：上架 — 同时设置 is_published=true 和 status=active；必须至少有一个 active 变体
- 取消发布（类型：更新），说明：下架 — 设置 is_published=false，status 保持 active
- 停产（类型：更新），说明：停产
- 重新激活（类型：更新），说明：重新激活已停产产品

#### 校验
- 创建时，产品编码 不能为空
- 创建时，名称 不能为空
- 发布时，只有草稿状态的产品可以上架
- 取消发布／停产时，只有活跃状态的产品可以下架或停产
- 重新激活时，只有已停产的产品可以重新激活
- 发布时，上架前必须至少有一个 active 的变体

#### 变更
- 在 发布 时，将 是否发布 设为 是
- 在 发布 时，将 状态 设为 启用
- 在 取消发布 时，将 是否发布 设为 否
- 在 停产 时，将 状态 设为 已停产
- 在 停产 时，将 是否发布 设为 否
- 在 重新激活 时，将 状态 设为 启用
- 在 创建 / 更新 时，清理HTML 说明电商
- 在 创建 / 更新 / 发布 / 取消发布 / 停产 / 重新激活 时，将 编号 设为 编号

#### 计算
- 计算字段 评级平均：金额，表达式 avg(ratings.score)
- 计算字段 评级数量：整数，表达式 count(ratings where is_published=true)
- 计算字段 基础单位价格：金额，表达式 avg(prices.amount)

#### 事件
- 事件：发布 -> 电商.产品.已发布
- 事件：停产 -> 电商.产品.已停产

#### 工作流
- 流程：product_template_lifecycle：创建 -> 发布 -> 更新 -> 取消发布 -> 停产 -> 重新激活（产品模板生命周期）

- 访问令牌：文本（自动生成），说明 用于弃购恢复链接
- 购物车回收邮箱已发送：布尔，默认值 否，说明 弃购恢复邮件是否已发送

- 承运商：多对一 -> 配送承运商

### Conduct（行为声明）

#### 操作
- 创建，可写字段：币种
- 查询
- 更新，可写字段：合计金额、项数量、状态
- 转换（类型：更新），说明：转为订单
- 购物车更新（类型：更新），说明：核心加购逻辑：(a) 校验订单处于 draft 状态 → (b) 解析产品变体 → (c) 查找已有相同产品行合并数量 → (d) 通过 _get_closest_possible_combination() 解析最近有效组合 → (e) 移除配送行后重新计算

- 更新价格表（类型：更新），说明：切换价格表并重算所有行价格，参数：价格表编号：唯一标识（必填）
- 选择承运商（类型：更新），说明：选择物流方式，参数：承运商编号：唯一标识（必填）

- 转换时，支付前校验：调用 _is_cart_ready() 钩子 + 非服务订单必须选择配送方式
- 购物车更新时，当 website.prevent_zero_price_sale=true 时，拒绝加入价格为 0 的产品

#### 变更

- 在 恢复 时，将 状态 设为 启用
- 在 恢复 时，将 购物车回收邮箱已发送 设为 否
- 在 购物车更新 时，移除配送明细行
- 在 更新价格表 时，重算所有行价格
- 在 购物车更新 时，更新会话数量
- 在 创建 / 更新 / 转换 / 购物车更新 / 恢复 / 更新价格表 / 选择承运商 时，将 编号 设为 编号

#### 计算

- 计算字段 仅服务：布尔，规则 自定义规则（）

#### 事件

#### 工作流
