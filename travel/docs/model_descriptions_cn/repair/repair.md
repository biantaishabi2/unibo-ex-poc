# 模型业务说明

- 版本：1.0
- 领域：维修
- 领域说明：维修工单领域模型，涵盖客户维修工单、维修明细（零件/工时）、费用调整、保修验证与工单标签
- 实体数量：6

## 实体：维修工单（聚合根）

- 说明：维修工单，客户送修产品的主工单，追踪从接单到交付的全生命周期
- 来源：基于 退货单；来源域 ofbiz/order；过滤条件 退货表头类型编号=维修

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 维修单号：文本（必填），说明 工单编号，格式 RO-YYYYMMDD-NNNN
- 状态：枚举（必填），默认值 草稿，可选值：草稿 / 已确认 / 维修中 / repaired / 完成 / 已取消，说明 工单状态（草稿/已确认/维修中/已完成维修/已交付/已取消）
- 说明：长文本，说明 故障描述/客户备注
- 内部备注：长文本，说明 内部备注（仅技术员可见）
- 是否适用保修（warranty_applicable）：布尔，默认值 否
- 保修过期日期：日期，说明 保修到期日，由关联 Warranty 记录或手动录入
- 已排期日期：日期时间，说明 预约维修日期
- 完成度日期：日期时间，说明 实际完成日期
- 币种编号：文本，说明 结算币种（对应 OFBiz currency_uom_id）
- 合计费用：金额，说明 费用合计（零件费 + 工时费 + 调整费）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 客户：多对一 -> 参与方，外键 客户参与方编号，必填关系
- 技术员：多对一 -> 参与方，外键 技术员参与方编号
- 维修明细行：一对多 -> 维修行，外键 维修工单编号
- repair_fees：一对多 -> 维修费用，外键 维修工单编号

#### 唯一约束
- 唯一约束 唯一维修单号：维修单号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：维修单号、说明、内部备注、warranty_applicable、保修过期日期、已排期日期、币种编号，参数：客户编号：唯一标识（必填）；产品编号：唯一标识（必填）；销售订单编号：唯一标识；设施编号：唯一标识；技术员编号：唯一标识
- 查询
- 更新，可写字段：说明、内部备注、warranty_applicable、保修过期日期、已排期日期
- 确认（类型：更新），说明：确认工单（draft -> confirmed）
- 开始维修（类型：更新），说明：开始维修（confirmed -> under_repair），可写字段：技术员编号
- 完成维修（类型：更新），说明：完成维修（under_repair -> repaired），可写字段：内部备注
- 发货（类型：更新），说明：交付客户（repaired -> done）
- 取消（类型：更新），说明：取消工单（draft/confirmed -> cancelled）

#### 校验
- 创建时，维修单号 不能为空
- 创建时，客户编号 不能为空
- 创建时，产品编号 不能为空
- 确认时，只有草稿状态可以确认
- 开始维修时，只有已确认工单可以开始维修
- 完成维修时，只有维修中工单可以标记完成
- 发货时，只有已修复工单可以交付
- 取消时，只有草稿或确认状态可以取消

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 维修经理、管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=客户 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=客户 时允许

#### 变更
- 在 确认 时，将 状态 设为 已确认
- 在 开始维修 时，将 状态 设为 维修中
- 在 完成维修 时，将 状态 设为 repaired
- 在 完成维修 时，将 完成度日期 设为 now()
- 在 发货 时，将 状态 设为 完成
- 在 取消 时，将 状态 设为 已取消
- 在 创建 / 更新 / 确认 / 开始维修 / 完成维修 / 发货 / 取消 时，将 编号 设为 编号

#### 事件
- 事件：确认 -> 维修.工单.已确认
- 事件：开始维修 -> 维修.工单.开始
- 事件：完成维修 -> 维修.工单.repaired
- 事件：发货 -> 维修.工单.已送达
- 事件：取消 -> 维修.工单.已取消

#### 工作流
- 流程：repair_ticket_lifecycle：创建 -> 确认 -> 开始维修 -> 完成维修 -> 发货 -> 取消（维修工单完整生命周期）

## 实体：维修行

- 说明：维修明细行，记录使用零件和工时，对应 OFBiz ReturnItem 扩展
- 来源：基于 退货项；来源域 ofbiz/order

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 行类型：枚举（必填），可选值：part / labor / 其他，说明 明细类型（零件/工时/其他）
- 说明：文本（必填），说明 零件名称或工时描述
- 数量：金额（必填），默认值 1，说明 零件数量或工时小时数
- 单价：金额（必填），说明 单价（零件单价或工时费率）
- 零件费（quantity * unit_price when line_type == part）（part_cost）：金额
- 工时费（quantity * unit_price when line_type == labor）（labor_cost）：金额
- 该行是否由保修覆盖（不计费）（warranty_covered）：布尔，默认值 否
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 维修工单：多对一 -> 维修工单，外键 维修工单编号，必填关系
- 保修：多对一 -> 保修

### Conduct（行为声明）

#### 操作
- 创建，可写字段：行类型、说明、数量、单价、warranty_covered，参数：维修工单编号：唯一标识（必填）；产品编号：唯一标识；技术员编号：唯一标识
- 查询
- 更新，可写字段：说明、数量、单价、warranty_covered
- 删除

#### 校验
- 创建时，说明 不能为空
- 创建／更新时，数量 greater_than（数量必须大于 0）
- 创建／更新时，单价 greater_than_or_equal（单价不能为负数）
- 创建／更新／删除时，工单状态为 draft/confirmed/under_repair 时才允许编辑明细行

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：repair_line_maintain_flow：创建 -> 更新 -> 删除（维修明细维护）

## 实体：维修费用

- 说明：维修费用调整，记录诊断费、运费、折扣等额外费用，对应 OFBiz ReturnAdjustment 扩展
- 来源：基于 退货调整；来源域 ofbiz/order；过滤条件 退货调整类型编号=维修费用、维修折扣、维修发货

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 费用类型：枚举（必填），可选值：diagnostic / 发货 / 折扣 / 附加费 / 其他，说明 费用类型（诊断费/运费/折扣/附加费/其他）
- 说明：文本（必填），说明 费用说明
- 金额：金额（必填），说明 金额（折扣为负数）
- 税费率：金额，默认值 0，说明 适用税率（%）
- 税金额：金额，说明 税额
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 维修工单：多对一 -> 维修工单，外键 维修工单编号，必填关系

### Conduct（行为声明）

#### 操作
- 创建，可写字段：费用类型、说明、金额、税费率，参数：维修工单编号：唯一标识（必填）
- 查询
- 更新，可写字段：说明、金额、税费率
- 删除

#### 校验
- 创建时，说明 不能为空
- 创建／更新／删除时，工单为 draft/confirmed/under_repair/repaired 时才可编辑费用

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：repair_fee_maintain_flow：创建 -> 更新 -> 删除（费用调整维护）
