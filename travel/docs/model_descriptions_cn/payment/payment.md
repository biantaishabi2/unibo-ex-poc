# 模型业务说明

- 版本：1.0
- 领域：付款
- 领域说明：支付处理领域模型，涵盖支付渠道配置、支付方式管理、支付流水记录、网关响应追踪、支付核销
- 实体数量：10

## 实体：付款类型

- 说明：支付类型字典，区分收款/付款/薪资等方向与性质，支持父子层级
- 来源：基于 付款类型；来源域 ofbiz/accounting

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 付款类型编号：唯一标识（必填），说明 业务码，如 RECEIPT / DISBURSEMENT / PAYROLL_PAYMENT
- 表：布尔，默认值 否，说明 是否有扩展子表
- 说明：文本，说明 类型描述
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 上级：多对一 -> 付款类型，外键 上级类型编号
- 子项：一对多 -> 付款类型，外键 上级类型编号
- 付款：一对多 -> 付款，外键 付款类型编号

#### 唯一约束
- 唯一约束 唯一付款类型编号：付款类型编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：付款类型编号、上级类型编号、表、说明
- 查询
- 更新，可写字段：说明、表
- 删除

#### 校验
- 创建时，付款类型编号 不能为空

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：payment_type_lifecycle：创建 -> 更新 -> 删除（支付类型维护流程）

## 实体：付款供应商（聚合根）

- 说明：支付渠道配置，将 OFBiz PaymentGatewayConfig 及各网关子表合并为统一实体，以 provider_type 区分网关类型
- 来源：基于 支付网关配置；来源域 ofbiz/accounting

### Schema（数据模型）

#### 字段

- 供应商类型：文本（必填），说明 网关类型标识，如 alipay、wechat、stripe 等，不硬编码枚举以支持自定义网关
- 是否启用：布尔，默认值 是，说明 是否启用
- 测试模式：布尔，默认值 否，说明 是否为沙箱/测试模式

- API密钥（api_key）：文本，说明 API 密钥（加密存储）
- API密钥（api_secret）：文本，说明 API 密文（加密存储）
- 商户编号：文本，说明 商户号
- 说明：文本，说明 配置说明
- 配置类型编号：文本，说明 对应 PaymentGatewayConfigType.payment_gateway_config_type_id
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- gateway_responses：一对多 -> 支付网关响应，外键 付款供应商编号
- tokens：一对多 -> 付款令牌，外键 供应商编号

- 更新，可写字段：名称、是否启用、测试模式、API端点、API密钥、API密钥、商户编号、说明
- 删除
- 启用（类型：更新），说明：启用/禁用支付渠道，可写字段：是否启用
- toggle_test_mode（类型：更新），说明：切换沙箱/生产模式，可写字段：测试模式

#### 校验
- 创建时，名称 不能为空
- 创建时，供应商类型 不能为空

#### 变更

## 实体：付款（聚合根）

- 说明：核心支付流水实体，记录每笔实际支付的完整信息，支持状态流转（draft→pending→authorized→captured→refunded/cancelled/failed）
- 来源：基于 付款；来源域 ofbiz/accounting

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 付款方法类型编号：文本，说明 支付方式类型（冗余存储，方便查询）
- 付款偏好编号：文本，说明 关联的订单支付偏好 ID
- 状态：枚举（必填），默认值 草稿，可选值：草稿 / 待处理 / 已授权 / captured / 已退款 / 已取消 / 失败，说明 支付状态（draft→pending→authorized→captured；可流转到 refunded/cancelled/failed）
- 生效日期：日期时间（必填），说明 支付生效日期
- 付款参考编号：文本，说明 支付参考编号（第三方流水号）
- 金额：金额（必填），必须大于 0（支付金额必须大于零），说明 支付金额
- 币种单位编号：文本（必填），说明 货币单位（USD、CNY 等）
- 实际币种金额：金额，说明 实际货币金额（汇率转换后）
- 实际币种单位编号：文本，说明 实际货币单位
- 评论：长文本，说明 备注
- 财务科目交易编号：文本，说明 关联金融账户交易 ID
- 覆盖总账科目编号：文本，说明 覆盖总账科目 ID
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 付款类型参考：多对一 -> 付款类型，外键 付款类型编号
- 付款方法参考：多对一 -> 付款方法，外键 付款方法编号
- 网关响应：多对一 -> 支付网关响应，外键 付款网关响应编号
- 来源参与方：多对一 -> 参与方，外键 参与方编号来源
- 参与方：多对一 -> 参与方，外键 参与方编号
- 公司参与方：多对一 -> 参与方，外键 参与方编号
- 申请：一对多 -> 付款应用，外键 付款编号
- refunds：一对多 -> 付款退款，外键 付款编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：付款类型编号、付款方法类型编号、付款方法编号、付款偏好编号、参与方编号来源、参与方编号、状态、生效日期、付款参考编号、金额、币种单位编号、实际币种金额、实际币种单位编号、评论、财务科目交易编号、覆盖总账科目编号
- 查询
- 更新，可写字段：付款参考编号、评论、覆盖总账科目编号
- 删除
- 提交（类型：更新），说明：提交支付，状态从 draft 变为 pending
- authorize（类型：更新），说明：授权支付，状态从 pending 变为 authorized，可写字段：付款参考编号、付款网关响应编号
- 获取（类型：更新），说明：捕获/扣款，状态从 authorized 变为 captured，可写字段：付款参考编号、付款网关响应编号
- 标记失败（类型：更新），说明：标记支付失败，状态变为 failed，可写字段：评论
- 取消（类型：更新），说明：取消支付，状态变为 cancelled，可写字段：评论
- 退款（类型：更新），说明：标记已退款，状态从 captured 变为 refunded，可写字段：评论

#### 校验
- 创建时，付款类型编号 不能为空
- 创建时，参与方编号来源 不能为空
- 创建时，参与方编号 不能为空
- 创建时，金额 不能为空
- 创建时，币种单位编号 不能为空
- 提交时，只有草稿状态可以提交
- authorize时，只有待处理状态可以授权
- 获取时，只有已授权状态可以捕获扣款
- 退款时，只有已捕获状态可以退款
- 取消时，已捕获/已退款/已失败的支付不能取消
- 标记失败时，只有待处理或已授权状态可以标记失败

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 finance_clerk、管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=公司参与方 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=公司参与方 时允许

#### 变更
- 在 提交 时，将 状态 设为 待处理
- 在 authorize 时，将 状态 设为 已授权
- 在 获取 时，将 状态 设为 captured
- 在 标记失败 时，将 状态 设为 失败
- 在 取消 时，将 状态 设为 已取消
- 在 退款 时，将 状态 设为 已退款
- 在 创建 / 更新 / 删除 / 提交 / authorize / 获取 / 标记失败 / 取消 / 退款 时，将 编号 设为 编号

#### 计算
- 计算字段 已退款金额：金额
- 计算字段 剩余金额：金额，规则 金额 - 已退款金额

#### 事件
- 事件：authorize -> 付款.付款.已授权
- 事件：获取 -> 付款.付款.captured
- 事件：退款 -> 付款.付款.已退款
- 事件：取消 -> 付款.付款.已取消
- 事件：标记失败 -> 付款.付款.失败

#### 工作流
- 流程：payment_lifecycle：创建 -> 更新 -> 提交 -> authorize -> 获取 -> 退款 -> 标记失败 -> 取消 -> 删除（支付生命周期流程（draft → pending → authorized → captured → refunded/cancelled/failed））

## 实体：付款退款

- 说明：支付退款记录，记录每笔退款的金额、原因、状态和处理时间
- 来源：基于 付款；来源域 ofbiz/accounting；过滤条件 付款类型编号=退款

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 金额：金额（必填），必须大于 0（退款金额必须大于零），说明 退款金额
- 原因：长文本，说明 退款原因
- 状态：枚举（必填），默认值 待处理，可选值：待处理 / 已审批 / 已处理 / 已驳回，说明 退款状态
- 退款方法：文本，说明 退款方式（原路退回、余额退款等）
- 已处理：日期时间，说明 退款处理完成时间
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 付款：多对一 -> 付款，外键 付款编号，必填关系

### Conduct（行为声明）

#### 操作
- 创建，可写字段：付款编号、金额、原因、退款方法
- 查询
- 审批（类型：更新），说明：审批退款，状态从 pending 变为 approved
- 流程（类型：更新），说明：处理退款，状态从 approved 变为 processed，可写字段：已处理
- 驳回（类型：更新），说明：拒绝退款，状态从 pending 变为 rejected，可写字段：原因

#### 校验
- 创建时，付款编号 不能为空
- 创建时，金额 不能为空
- 审批时，只有待处理状态可以审批
- 流程时，只有已审批状态可以处理
- 驳回时，只有待处理状态可以拒绝

#### 变更
- 在 审批 时，将 状态 设为 已审批
- 在 流程 时，将 状态 设为 已处理
- 在 驳回 时，将 状态 设为 已驳回
- 在 创建 / 审批 / 流程 / 驳回 时，将 编号 设为 编号

#### 事件
- 事件：审批 -> 付款.退款.已审批
- 事件：流程 -> 付款.退款.已处理
- 事件：驳回 -> 付款.退款.已驳回

#### 工作流
- 流程：refund_lifecycle：创建 -> 审批 -> 流程 -> 驳回（退款生命周期流程（pending → approved → processed / rejected））

## 实体：付款令牌

- 说明：支付令牌，安全存储用户在支付网关上的令牌化卡信息，用于免密/快捷支付
- 来源：基于 付款方法；来源域 ofbiz/accounting；过滤条件 付款方法类型编号=令牌

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 令牌参考号：文本（必填），说明 网关返回的令牌引用（不存储原始卡号）
- 卡号后四位（用于展示）（card_last_four）：文本
- 卡品牌：文本，说明 卡品牌（Visa/Mastercard/UnionPay 等）
- 过期日期：文本，说明 令牌/卡片过期日期（MM/YY 格式）
- 默认：布尔，默认值 否，说明 是否为默认令牌
- 状态：枚举（必填），默认值 启用，可选值：启用 / 已过期 / revoked，说明 令牌状态
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 参与方：多对一 -> 参与方，外键 参与方编号
- 供应商：多对一 -> 付款供应商，外键 供应商编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：参与方编号、供应商编号、令牌参考号、card_last_four、卡品牌、过期日期、默认
- 查询
- 更新，可写字段：默认、过期日期
- revoke（类型：更新），说明：吊销令牌，状态变为 revoked
- 过期（类型：更新），说明：标记过期，状态变为 expired

#### 校验
- 创建时，参与方编号 不能为空
- 创建时，供应商编号 不能为空
- 创建时，令牌参考号 不能为空
- revoke时，只有活跃状态的令牌可以吊销
- 过期时，只有活跃状态的令牌可以标记过期

#### 变更
- 在 revoke 时，将 状态 设为 revoked
- 在 过期 时，将 状态 设为 已过期
- 在 创建 / 更新 / revoke / 过期 时，将 编号 设为 编号

#### 工作流
- 流程：token_lifecycle：创建 -> 更新 -> revoke -> 过期（支付令牌生命周期）

## 实体：支付网关响应（聚合根）

- 说明：支付网关每次处理（授权/捕获/退款/作废）的原始响应，是审计追踪和对账的关键数据
- 来源：基于 支付网关响应；来源域 ofbiz/accounting

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 付款服务类型枚举编号：枚举（必填），可选值：授权 / 获取 / 发布 / 退款 / 作废，说明 服务类型（授权/捕获/释放/退款/作废）
- 订单付款偏好编号：文本，说明 关联订单支付偏好
- 付款方法类型编号：文本，说明 支付方式类型
- 交易编码枚举编号：文本，说明 交易代码枚举
- 金额：金额（必填），说明 交易金额
- 币种单位编号：文本（必填），说明 货币单位
- 参考号编号：文本，说明 网关返回的主参考号
- 备用参考号：文本，说明 备用参考号
- 子参考号：文本，说明 子参考号
- 网关编码：文本，说明 网关响应码（如"00"表示成功）
- 网关标记：文本，说明 网关标志位

- 网关评分结果：文本，说明 风控评分结果
- 网关消息：文本，说明 网关返回的消息文本
- 交易日期：日期时间（必填），说明 网关交易时间
- 结果已拒绝：布尔，默认值 否，说明 是否被拒绝
