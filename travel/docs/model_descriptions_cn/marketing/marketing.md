## 实体：活动（聚合根）

- 说明：营销活动
- 来源：基于 营销活动；来源域 ofbiz/marketing

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 活动编码：文本（必填），说明 活动编号
- 名称：文本（必填）
- 状态：枚举，默认值 草稿，可选值：草稿 / 运行中 / 暂停 / 已完成 / 已取消
- 活动类型：枚举，默认值 邮箱，可选值：邮箱 / 社交 / 活动 / 晋升 / 其他
- 开始日期：日期
- 结束日期：日期
- 预算：金额，说明 活动预算
- 实际成本：金额，说明 实际花费
- 说明：长文本
- UTM活动编号：唯一标识，说明 UTM 追踪活动关联
- UTM中编号：唯一标识，说明 UTM 渠道来源
- UTM来源编号：唯一标识，说明 UTM 流量来源
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 角色：一对多 -> 活动角色
- 邮件：一对多 -> 邮寄
- 活动：一对多 -> 活动
- 社交帖子：一对多 -> 社交过账
- 创建人：多对一 -> 参与方，外键 创建参与方编号

#### 唯一约束
- 唯一约束 唯一活动编码：活动编码

### Conduct（行为声明）

#### 操作
- 创建，可写字段：活动编码、名称、活动类型、开始日期、结束日期、预算、说明、UTM活动编号、UTM中编号、UTM来源编号
- 查询
- 更新，可写字段：名称、状态、开始日期、结束日期、预算、实际成本、说明、UTM活动编号、UTM中编号、UTM来源编号
- 发布（类型：更新），说明：启动活动
- 暂停（类型：更新），说明：暂停活动
- 恢复（类型：更新），说明：恢复活动
- 完成（类型：更新），说明：完成活动，可写字段：实际成本
- 取消（类型：更新），说明：取消活动

#### 校验
- 创建时，活动编码 不能为空
- 创建时，名称 不能为空
- 发布时，只有草稿状态可以启动
- 发布时，启动前至少关联 1 个 Mailing 或 Event
- 暂停时，只有运行中状态可以暂停
- 恢复时，只有暂停状态可以恢复
- 完成时，只有运行中或暂停状态可以完成
- 取消时，已完成的活动不可取消

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 marketer、管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=创建人 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=创建人 时允许

#### 变更
- 在 创建 时，将 创建人 设为当前操作人
- 在 发布 时，将 状态 设为 运行中
- 在 暂停 时，将 状态 设为 暂停
- 在 恢复 时，将 状态 设为 运行中
- 在 完成 时，将 状态 设为 已完成
- 在 取消 时，将 状态 设为 已取消
- 在 取消 时，cascade
- 在 创建 / 更新 / 发布 / 暂停 / 恢复 / 完成 / 取消 时，将 编号 设为 编号

#### 事件
- 事件：发布 -> 营销活动已发布
- 事件：暂停 -> 营销.活动.暂停
- 事件：恢复 -> 营销活动已恢复
- 事件：完成 -> 营销.活动.已完成
- 事件：取消 -> 营销.活动.已取消

#### 工作流
- 流程：campaign_lifecycle：创建 -> 更新 -> 发布 -> 暂停 -> 恢复 -> 完成 -> 取消（营销活动生命周期）

#### 操作
- 创建，可写字段：名称、主题、正文HTML、预览、回复模式、回复、AB测试启用、AB测试百分比、AB测试获胜者选择、邮寄模型编号、邮寄域，参数：活动编号：唯一标识；联系列表编号列表：列表
- 查询

- 在 取消 时，将 状态 设为 草稿
- 在 取消 时，取消时清空 schedule_date
- 在 发布 / 放入队列 时，BR-M02: 自动排除 opted-out + blacklisted 联系人
- 在 发布 / 放入队列 时，BR-M06: 通过 HMAC-SHA512 生成退订 token，嵌入邮件 body
- 在 完成 时，BR-M07: done 后触发 KPI 邮件通知
- 在 创建 / 更新 / 发布 / 排班 / 放入队列 / 取消 / 重试失败 / 发送获胜者邮寄 时，将 编号 设为 编号

- 事件：发布 -> 群发邮件已发布
- 事件：排班 -> 营销.邮寄.已排期
- 事件：取消 -> 营销.邮寄.已取消

#### 工作流
- 流程：mailing_delivery_flow：创建 -> 排班 -> 放入队列 -> 发布 -> 重试失败（群发邮件投递流程）
