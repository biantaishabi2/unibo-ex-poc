## 实体：订阅计划（聚合根）

- 说明：周期计划模板，定义计费周期和宽限策略
- 来源：基于 产品；来源域 ofbiz/product；过滤条件 产品类型编号=服务订阅

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 计划名称，如"月度计划"、"年度计划"
- 账单期间单位：枚举（必填），可选值：周 / 月 / 年，说明 计费周期单位
- 账单期间值：整数（必填），必须大于 0（周期数值必须大于零），说明 周期数值，与 unit 组合确定计费频率
- 自动关闭限制：整数（必填），默认值 0，必须 ≥ 0（宽限天数不能为负数），说明 支付失败宽限天数，0 表示不自动关闭
- 启用：布尔（必填），默认值 是，说明 是否启用
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 订阅订单：一对多 -> 订阅订单，外键 周期性计划编号

#### 唯一约束
- 唯一约束 唯一计划名称：名称

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、账单期间单位、账单期间值、自动关闭限制、启用
- 查询
- 更新，可写字段：名称、账单期间单位、账单期间值、自动关闭限制、启用
- 停用（类型：更新），说明：停用计划
- 启用（类型：更新），说明：启用计划

#### 校验
- 创建时，名称 不能为空
- 创建时，账单期间单位 不能为空
- 停用时，只有启用状态可以停用
- 启用时，只有停用状态可以启用

#### 变更
- 在 停用 时，将 启用 设为 否
- 在 启用 时，将 启用 设为 是
- 在 创建 / 更新 / 停用 / 启用 时，将 编号 设为 编号

#### 工作流
- 流程：plan_lifecycle：创建 -> 更新 -> 停用 -> 启用（计划生命周期（创建→启用/停用切换））

## 实体：订阅订单（聚合根）

- 说明：订阅订单，承载客户订阅全生命周期
- 来源：基于 订单表头；来源域 ofbiz/order；过滤条件 订单类型编号=订阅订单

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 订阅编号，如 SUB-00042
- 订阅状态：枚举（必填），默认值 草稿，可选值：草稿 / 进行中 / 暂停 / 已关闭，说明 订阅状态
- 开始日期：日期（必填），说明 订阅开始日期
- 结束日期：日期，说明 结束日期，null 表示永续
- 下一个发票日期：日期（必填），说明 下次开票日期，cron 读取
- 关闭日期：日期，说明 实际关闭日期
- 付款异常：布尔（必填），默认值 否，说明 是否存在支付异常
- 首个付款失败日期：日期，说明 首次支付失败日期
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 明细行：一对多 -> 订阅订单行，外键 订单编号，管理模式 直接管理
- 日志：一对多 -> 订阅日志，外键 订阅编号
- 周期性计划：多对一 -> 订阅计划，必填关系
- 关闭原因：多对一 -> 关闭原因
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号，必填关系
- 销售人员：多对一 -> 参与方，外键 销售人员参与方编号，必填关系
- 团队：多对一 -> 销售团队
- 来源订单：多对一 -> 订阅订单
- 付款令牌：多对一 -> 付款令牌
- 币种：多对一 -> 币种，必填关系
- 价格表：多对一 -> 价格表
- 阶段：多对一 -> 阶段

#### 唯一约束
- 唯一约束 唯一订阅名称：名称

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、开始日期、结束日期、下一个发票日期，参数：明细行：列表（必填）；周期性计划编号：唯一标识（必填）；伙伴编号：唯一标识（必填）；销售人员编号：唯一标识（必填）；币种编号：唯一标识（必填）；付款令牌编号：唯一标识；价格表编号：唯一标识；团队编号：唯一标识；阶段编号：唯一标识
- 查询
- 更新，可写字段：结束日期、下一个发票日期、付款令牌编号、价格表编号、团队编号、阶段编号
- 确认操作（类型：更新），说明：确认订阅（draft -> in_progress），生成首张发票
- 操作暂停（类型：更新），说明：暂停订阅（in_progress -> paused）
- 操作恢复（类型：更新），说明：恢复订阅（paused -> in_progress）
- 操作关闭（类型：更新），说明：手动关闭订阅（in_progress -> closed），参数：关闭原因编号：唯一标识（必填）
- 续订（类型：创建），说明：续订（从已关闭订阅创建新的草稿订单）
- 升级加购（类型：更新），说明：升级/加购，生成差价报价单，参数：新明细行：列表（必填）
- 标记付款异常（类型：更新），说明：标记支付异常
- 清除支付异常（类型：更新），说明：清除支付异常（重试扣款成功后）

#### 校验
- 创建时，名称 不能为空
- 确认操作时，只有草稿状态可以确认
- 操作暂停时，只有进行中状态可以暂停
- 操作恢复时，只有暂停状态可以恢复
- 操作关闭时，只有进行中状态可以关闭
- 续订时，只有已关闭状态可以续订
- 升级加购时，只有进行中状态可以升级

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 销售代表、科目经理、管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=伙伴 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=伙伴 时允许

#### 变更
- 在 确认操作 时，将 订阅状态 设为 进行中
- 在 操作暂停 时，将 订阅状态 设为 暂停
- 在 操作恢复 时，将 订阅状态 设为 进行中
- 在 操作关闭 时，将 订阅状态 设为 已关闭
- 在 操作关闭 时，将 关闭日期 设为 今日
- 在 标记付款异常 时，将 付款异常 设为 是
- 在 标记付款异常 时，将 首个付款失败日期 设为 今日
- 在 清除支付异常 时，将 付款异常 设为 否
- 在 清除支付异常 时，设置 首个付款失败日期
- 在 创建 / 更新 / 确认操作 / 操作暂停 / 操作恢复 / 操作关闭 / 续订 / 升级加购 / 标记付款异常 / 清除支付异常 时，将 编号 设为 编号

#### 计算
- 计算字段 周期性合计：金额，规则 合计(明细行.价格小计)
- 计算字段 月度经常性收入：金额，规则 情况（条件=订阅状态 = 已关闭，结果=0，默认=op=mrr_normalize，args=周期性合计、周期性计划.账单期间单位、周期性计划.账单期间值）
- 计算字段 年度经常性收入：金额，规则 月度经常性收入 × 12
- 计算字段 金额未税：金额，规则 合计(明细行.价格小计)
- 计算字段 税额：金额，规则 合计税(明细行)
- 计算字段 金额合计：金额，规则 金额未税 + 税额
- 计算字段 健康：枚举，规则 情况（条件=付款异常 = 是 或 mrr_declining_trend，结果=无效，条件=mrr_decreasing 或 临近到期，结果=attention，默认=良好）

#### 事件
- 事件：确认操作 -> 订阅.订单.已确认
- 事件：操作暂停 -> 订阅.订单.暂停
- 事件：操作恢复 -> 订阅订单已恢复
- 事件：操作关闭 -> 订阅.订单.已关闭
- 事件：续订 -> 订阅订单已续订
- 事件：升级加购 -> 订阅订单已升级加购
- 事件：标记付款异常 -> 订阅订单付款失败
- 事件：清除支付异常 -> 订阅订单支付已恢复

#### 工作流
- 流程：subscription_lifecycle：创建 -> 确认操作 -> 操作暂停 -> 操作恢复 -> 操作关闭 -> 续订（订阅全生命周期流程）
- 流程：cron_invoicing：evaluate_invoicing_due -> generate_invoice（定时开票流程）
- 流程：定时任务自动关闭：evaluate_auto_close_due -> 操作关闭（支付失败自动关闭流程）
- 流程：定时任务过期关闭：evaluate_expiry_due -> 操作关闭（到期自动关闭流程）
- 流程：定时任务付款重试：evaluate_retry_due -> 重试付款（支付失败重试流程（每3天重试一次））

## 实体：订阅订单行

- 说明：订阅订单明细行
- 来源：基于 订单项；来源域 ofbiz/order；过滤条件 订单项类型编号=订阅项

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 行描述
- 数量：金额（必填），必须大于 0（数量必须大于零），说明 数量
- 单价：金额（必填），必须 ≥ 0（单价不能为负数），说明 单价
- 折扣：金额（必填），默认值 0，必须 ≥ 0（折扣不能为负数），必须 ≤ 100（折扣不能超过100%），说明 折扣百分比（0-100）
- 周期性：布尔（必填），说明 是否为周期性项目
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 订单：多对一 -> 订阅订单，必填关系
- 产品：多对一 -> 产品，必填关系
- 税编号列表：多对多 -> 税，中间关系 订阅订单行税链接

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、数量、单价、折扣、周期性，参数：产品编号：唯一标识（必填）
- 更新，可写字段：数量、单价、折扣
- 查询
- 删除

#### 变更
- 在 创建 / 更新 时，将 价格小计 设为 数量 × 单价 × 1 - 折扣 ÷ 100
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 计算
- 计算字段 价格小计：金额，规则 数量 × 单价 × 1 - 折扣 ÷ 100

#### 工作流
- 流程：orderline_management：创建 -> 更新 -> 删除（订阅订单行管理）
