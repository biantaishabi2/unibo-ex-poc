- 版本：1.0
- 领域：财务
- 领域说明：财务管理领域模型，涵盖科目、凭证、发票、付款、核销、预算

## 实体：总账科目（聚合根）

- 说明：总账科目
- 来源：基于 总账科目；来源域 ofbiz/accounting

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 科目编码：文本（必填），说明 科目编号
- 科目名称：文本（必填），说明 科目名称
- 科目类型：枚举（必填），可选值：应收资产 / 应付资产 / 现金 / 银行存款 / 流动资产 / 非流动资产 / 固定资产 / 预付款 / 流动负债 / 非流动负债 / 应付款 / 信用卡 / 所有者权益 / 未分配权益 / 收入 / 其他收入 / 费用 / 直接成本 / 折旧费用 / 表外科目，说明 科目类型（细分类型，兼容 Odoo 17 account_type）
- 核销：布尔，默认值 否，说明 是否允许核销（应收/应付必须为 true）[R-GL-001]
- 上级科目编码：文本，说明 上级科目编号
- 说明：长文本
- 是否启用：布尔，默认值 是，说明 是否启用；已停用科目不可用于新分录 [R-GL-002]
- 币种编号：唯一标识，说明 外币限定（可选，限定该科目只能用某一外币记账）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 上级科目：多对一 -> 总账科目

#### 唯一约束
- 唯一约束 唯一科目编码：科目编码

### Conduct（行为声明）

#### 操作
- 创建，可写字段：科目编码、科目名称、科目类型、核销、上级科目编码、说明、币种编号
- 查询
- 更新，可写字段：科目名称、说明、是否启用、上级科目编码、核销、币种编号
- 停用（类型：更新），说明：停用科目 [R-GL-002]

#### 校验
- 创建时，科目编码 不能为空
- 创建时，科目名称 不能为空
- 停用时，只有活跃科目可以停用

#### 变更
- 在 停用 时，将 是否启用 设为 否

#### 工作流
- 流程：gl_account_lifecycle：创建 -> 更新 -> 停用（科目管理流程）

## 实体：日记账凭证（聚合根）

- 说明：记账凭证（会计分录），涵盖普通凭证、销售发票、采购账单、收据等
- 来源：基于 会计交易；来源域 ofbiz/accounting

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 凭证单号：文本（必填），说明 凭证号，草稿时为 '/'，过账时由 journal sequence 生成 [R-ACC-007]
- 凭证类型：枚举，默认值 凭证，可选值：凭证 / 销项发票 / 销项退款 / 进项发票 / 进项退款 / 销项收据 / 进项收据，说明 凭证类型
- 状态：枚举，默认值 草稿，可选值：草稿 / 已过账 / 取消，说明 凭证状态（draft → posted → cancel，cancel → draft）
- 凭证日期：日期（必填），说明 会计日期 [R-ACC-002]
- 发票日期：日期，说明 发票日期（仅 invoice 类型使用）[R-ACC-005]
- 发票到期日：日期，说明 到期日
- 说明：长文本
- 币种编号：唯一标识，说明 币种
- 税务位置编号：唯一标识，说明 税务位置 [R-ACC-004]
- 来源单据：文本，说明 来源单据号（SO/PO 编号）
- 参考：文本，说明 参考号
- 金额未税：金额，说明 未税合计（计算字段）
公式: sign * SUM(line.balance) WHERE line.display_type IN ('product','rounding')
sign = +1（出站）或 -1（入站）[R-DIR-001][R-DIR-002][R-DIR-003]

- 税额：金额，说明 税额合计（计算字段）
公式: sign * SUM(line.balance) WHERE line.display_type = 'tax'

- 金额合计：金额，说明 含税合计（计算字段）
公式: amount_untaxed + amount_tax

- 未付余额：金额，说明 未付余额（计算字段）
公式: -sign * SUM(line.amount_residual_currency) WHERE line.display_type = 'payment_term'

- 带符号未付余额：金额，说明 已签署未付余额（计算字段）
公式: SUM(line.amount_residual) WHERE line.display_type = 'payment_term'

- 付款状态：枚举，可选值：未付 / 部分付款 / 付款中 / 已付清 / 已冲销 / 历史发票，说明 付款状态（计算字段）[R-REC-004]
not_paid: 无核销记录
partial: 存在核销但 amount_residual != 0
in_payment: amount_residual = 0 但部分付款未匹配银行对账单
paid: amount_residual = 0 且所有付款已匹配银行对账单
reversed: 仅冲销分录匹配

- 合计借方：金额，说明 借方合计
- 合计贷方：金额，说明 贷方合计
- 备注：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 明细行：一对多 -> 日记账凭证行，管理模式 直接管理
- 创建人：多对一 -> 参与方，外键 创建参与方编号
- 日记账：多对一 -> 日记账
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号
- 税现金基础来源：多对一 -> 日记账凭证
- 税现金基础创建移动：一对多 -> 日记账凭证，外键 税现金基础来源编号

#### 唯一约束
- 唯一约束 唯一凭证单号当已过账：凭证单号、日记账编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：凭证单号、凭证类型、凭证日期、发票日期、发票到期日、说明、备注、日记账编号、币种编号、伙伴编号、税务位置编号、来源单据、参考，参数：明细行：列表（必填）
- 查询
- 过账（类型：更新），说明：过账 [R-ACC-001 ~ R-ACC-007]
- 取消（类型：更新），说明：取消（可能生成冲销分录）
- 重置草稿（类型：更新），说明：重置为草稿

#### 校验
- 创建时，凭证单号 不能为空
- 过账时，只有草稿凭证可以过账
- 取消时，只有已过账凭证可以取消
- 重置草稿时，只有已取消或已过账凭证可以重置为草稿

#### 变更
- 在 创建 时，将 创建人 设为当前操作人
- 在 创建 时，将 合计借方 设为 合计(明细行.借方金额)
- 在 创建 时，将 合计贷方 设为 合计(明细行.贷方金额)
- 在 创建 / 过账 时，将 金额未税 设为 方向签署(凭证类型) × 合计(明细行.余额（条件: 明细行.显示类型 属于 产品、四舍五入）)
- 在 创建 / 过账 时，将 税额 设为 方向签署(凭证类型) × 合计(明细行.余额（条件: 明细行.显示类型 = 税）)
- 在 创建 / 过账 时，将 金额合计 设为 金额未税 + 税额
- 在 过账 时，将 状态 设为 已过账
- 在 过账 时，[R-ACC-007] 过账成功后由 journal sequence 分配编号，entry_number 从 '/' 变为实际序列号
- 在 取消 时，将 状态 设为 取消
- 在 重置草稿 时，将 状态 设为 草稿

#### 事件
- 事件：过账 -> 财务.日记账.已过账
- 事件：取消 -> 财务.日记账.已取消
- 事件：重置草稿 -> 财务日记账重置草稿

#### 工作流
- 流程：journal_entry_lifecycle：创建 -> 过账 -> 取消 -> 重置草稿（凭证过账流程）

- 发票：多对一 -> 发票，必填关系
- 总账科目：多对一 -> 总账科目

### Conduct（行为声明）

- 创建／更新时，单价 必须 ≥ 0

- 在 创建 / 更新 时，将 税金额 设为 金额 × 税费率 ÷ 100
- 在 创建 / 更新 时，将 编号 设为 编号

#### 工作流
- 流程：invoice_item_editing：创建 -> 更新（发票明细行编辑流程）

## 实体：付款（聚合根）

- 来源：基于 付款；来源域 ofbiz/accounting

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 付款单号：文本（必填），说明 付款编号
- 付款类型：枚举（必填），可选值：入库 / 出库，说明 收款(inbound) / 付款(outbound)
- 伙伴类型：枚举，可选值：客户 / 供应商，说明 客户/供应商
- 状态：枚举，默认值 草稿，可选值：草稿 / 已过账 / 取消，说明 付款状态，由底层 move.state 驱动
- 金额：金额（必填），说明 付款金额 [R-PAY-001] 必须 >= 0
- 币种：文本，默认值 CNY
- 付款日期：日期（必填）
- 付款方法：枚举，可选值：手动 / 检查 / 银行转账 / 现金 / 信用卡 / SEPA / 批次存款 / 其他，说明 付款方式 [R-PAY-002]
- 目的地科目编号：唯一标识，说明 应收/应付科目 [R-PAY-003]
- 参考号单号：文本，说明 银行流水号
- 已对账：布尔，默认值 否，说明 计算字段 [R-REC-005]: 对方行 + 差额调整行全部已核销（发票已匹配）
公式: ALL(line.amount_residual == 0) WHERE line IN (counterpart_lines + writeoff_lines)

- 匹配：布尔，默认值 否，说明 计算字段 [R-REC-006]: 流动性行全部已核销（银行对账单已匹配）
公式: ALL(line.amount_residual == 0) WHERE line IN (liquidity_lines)

- 配对内部转账付款编号：唯一标识，说明 内部调拨配对付款 [R-PAY-005]
- 备注：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 日记账凭证：多对一 -> 日记账凭证，必填关系
- 申请：一对多 -> 付款应用
- 创建人：多对一 -> 参与方，外键 创建参与方编号
- 配对内部转账：多对一 -> 付款

#### 唯一约束
- 唯一约束 唯一付款单号：付款单号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：付款单号、付款类型、伙伴类型、金额、币种、付款日期、付款方法、目的地科目编号、参考号单号、备注
- 查询
- 过账（类型：更新），说明：确认付款（过账底层 move）[R-PAY-003]
- 取消（类型：更新），说明：取消付款
- 重置草稿（类型：更新），说明：重置为草稿

#### 校验
- 创建时，付款单号 不能为空
