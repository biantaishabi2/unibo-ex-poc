# 模型业务说明

- 版本：1.0
- 领域：表格
- 领域说明：电子表格领域模型，涵盖文档管理、ERP 数据源绑定、协作修订历史、全局筛选器
- 实体数量：5

## 实体：表格文档（聚合根）

- 说明：电子表格文档，承载完整的工作表状态（sheets/styles/formats/pivots/settings）
- 来源：基于 内容；来源域 ofbiz/content；过滤条件 内容类型编号=表格

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成），说明 文档 ID
- 名称：文本（必填），说明 文档名称
- 模板：布尔，默认值 否，说明 是否为模板
- 缩略图：二进制，说明 缩略图
- 数据：jsonb（必填），默认值 {}，说明 完整电子表格状态（sheets/styles/formats/borders/pivots/settings）
- 版本：文本（必填），说明 数据模型版本号，用于兼容性检查和升级迁移
- 当前版本编号：文本，默认值 开始版本，说明 当前修订版本 ID，协作同步锚点
- 模式：枚举（必填），默认值 正常，可选值：正常 / 只读 / 仪表盘，说明 运行模式（非流转状态机，可任意切换）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 所有者：多对一 -> 参与方，外键 所有者参与方编号，必填关系
- 数据来源：一对多 -> 数据来源，外键 文档编号
- 全局筛选：一对多 -> 全局筛选，外键 文档编号
- 版本：一对多 -> 版本，外键 文档编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、数据、版本、模式、模板，参数：所有者编号：唯一标识（必填）
- 查询
- 更新，可写字段：名称、数据、模式、缩略图
- 创建来源模板（类型：创建），说明：从模板创建新文档，参数：模板编号：bigint（必填）；所有者编号：唯一标识（必填）
- 删除，说明：删除文档（级联删除关联的 DataSource、GlobalFilter、Revision）

#### 校验
- 更新时，模板文档不可直接编辑，请使用"从模板创建"
- 更新时，current_revision_id 与最新修订不一致
- 更新／创建时，图表 ID 必须跨工作表全局唯一

#### 变更
- 在 创建 / 更新 / 创建来源模板 / 删除 时，将 编号 设为 编号

#### 计算
- 计算字段 表数量：整数，规则 长度(数据.sheets)
- 计算字段 协作者数量：整数

#### 工作流
- 流程：spreadsheet_document_lifecycle_flow：创建 -> 更新 -> 创建来源模板 -> 删除（电子表格文档创建、更新、模板派生与删除流程）

## 实体：数据来源

- 说明：ERP 数据源绑定，将电子表格与 ERP 模型（sale.order、hr.employee 等）动态关联
- 来源：基于 数据资源；来源域 ofbiz/content

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成），说明 数据源 ID
- 类型：枚举（必填），可选值：列表 / 透视 / 图表 / 全局筛选，说明 数据源类型
- 来源模型：文本（必填），说明 目标 ERP 模型名（如 sale.order）
- 域筛选：jsonb，默认值 []，说明 筛选条件，三元组格式 [["state","=","confirmed"]]
- 字段：jsonb，默认值 []，说明 选中的字段列表
- 分组：jsonb，默认值 []，说明 分组字段，支持时间粒度 ["create_date:month"]
- 度量：jsonb，默认值 []，说明 度量值 ["amount_total:sum"]
- 排序：jsonb，默认值 []，说明 排序规则 [{"field":"...","order":"desc"}]
- 限制：整数，说明 记录数限制（仅 list 类型有效）
- 刷新间隔：整数，默认值 0，说明 自动刷新间隔（秒），0=手动
- 创建时间：日期时间（自动生成）

#### 关系
- 文档：多对一 -> 表格文档，必填关系

### Conduct（行为声明）

#### 操作
- 创建，可写字段：类型、来源模型、域筛选、字段、分组、度量、排序、限制、刷新间隔，参数：文档编号：bigint（必填）
- 查询
- 更新，可写字段：域筛选、字段、分组、度量、排序、限制、刷新间隔
- 删除
- 刷新（类型：自定义规则），说明：刷新数据源，从 ERP 重新拉取数据

#### 校验
- 创建／更新时，source_model 不是已注册的 ERP 模型
- 创建／更新时，透视表类型的数据源必须指定至少一个度量值
- 创建／更新时，列表类型的数据源必须指定至少一个字段
- 创建／更新时，分组字段的时间粒度仅支持 month、quarter、year
- 创建／更新时，筛选条件中引用了不存在的字段
- 刷新时，策略检查

#### 变更
- 在 创建 / 更新 / 删除 / 刷新 时，将 编号 设为 编号

#### 计算
- 计算字段 缓存行数量：整数
- 计算字段 最近已刷新：日期时间

#### 工作流
- 流程：data_source_refresh_flow：创建 -> 更新 -> 刷新 -> 删除（数据源创建、配置更新、刷新与删除流程）

## 实体：版本

- 说明：修订历史，基于 OT（Operational Transformation）实现多人协作编辑的冲突解决
- 来源：基于 内容版本；来源域 ofbiz/content

### Schema（数据模型）

#### 字段
- 编号：文本（主键、自动生成），说明 修订 ID（UUID，即 nextRevisionId）
- 命令：jsonb（必填），说明 OT 操作命令列表
- 类型：枚举（必填），可选值：远程版本 / 版本已撤销 / 版本已重做 / 快照，说明 修订类型（创建时确定，不可变更）
- 时间戳：日期时间（自动生成），说明 时间戳

#### 关系
- 文档：多对一 -> 表格文档，必填关系
- 用户：多对一 -> 参与方，外键 用户参与方编号，必填关系
- 上级版本：多对一 -> 版本

### Conduct（行为声明）

#### 操作
- 应用版本（类型：创建），说明：提交新修订（服务端验证 parent_revision_id 后接受），可写字段：命令、上级版本编号、类型，参数：文档编号：bigint（必填）；用户编号：bigint（必填）
- 查询
- 创建快照（类型：创建），说明：创建完整文档快照修订，用于加速后续加载，可写字段：命令，参数：文档编号：bigint（必填）；用户编号：bigint（必填）

#### 校验
- 应用版本时，parent_revision_id 与文档当前修订不一致，需客户端回滚+变换+重提

#### 变更
- 在 应用版本 时，将 当前版本编号 设为 编号
- 在 应用版本 / 创建快照 时，将 编号 设为 编号

#### 工作流
- 流程：revision_commit_flow：创建快照 -> 应用版本（快照创建与修订提交流程）

## 实体：全局筛选

- 说明：全局筛选器，跨数据源统一筛选，通过 FILTER.VALUE() 公式在单元格中引用
- 来源：基于 内容关联；来源域 ofbiz/content；过滤条件 内容关联类型编号=全局筛选

### Schema（数据模型）

#### 字段
- 编号：bigint（主键、自动生成），说明 筛选器 ID
- 名称：文本（必填），说明 筛选器显示名称（同一文档内唯一，FILTER.VALUE(filter_name) 按名称引用）
- 类型：枚举（必填），可选值：关联 / 日期 / 长文本 / 布尔，说明 筛选器类型（创建时确定，不可变更）
- 来源模型：文本，说明 关联 ERP 模型（仅 relation 类型必填）
- 默认值：jsonb，说明 默认值
- 范围类型：枚举，可选值：年 / 季度 / 月 / 周 / 天，说明 日期范围粒度（仅 date 类型有效且必填）
- 字段匹配：jsonb（必填），默认值 {}，说明 各数据源的字段匹配规则，映射筛选器到具体数据源字段
- 创建时间：日期时间（自动生成）

#### 关系
- 文档：多对一 -> 表格文档，必填关系

#### 唯一约束
- 唯一约束 唯一筛选名称每文档：文档编号、名称

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、类型、来源模型、默认值、范围类型、字段匹配，参数：文档编号：bigint（必填）
- 查询
- 更新，可写字段：名称、默认值、字段匹配
- 删除
- 应用筛选（类型：自定义规则），说明：应用筛选值变更，触发匹配的数据源同步刷新

#### 校验
- 创建／更新时，关联类型的筛选器必须指定 source_model
- 创建／更新时，日期类型的筛选器必须指定 range_type
- 创建／更新时，field_matchings 引用了不存在的数据源
- 创建／更新时，field_matchings 中指定了不存在的字段
- 创建／更新时，筛选器名称在同一文档内必须唯一
- 应用筛选时，策略检查

#### 变更
- 在 创建 / 更新 / 删除 / 应用筛选 时，将 编号 设为 编号

#### 计算
- 计算字段 当前值：jsonb
- 计算字段 匹配数据来源数量：整数，规则 count_keys(字段匹配)

#### 工作流
- 流程：global_filter_apply_flow：创建 -> 更新 -> 应用筛选 -> 删除（全局筛选器创建、更新、应用与删除流程）
