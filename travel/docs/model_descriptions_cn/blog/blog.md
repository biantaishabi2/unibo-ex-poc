# 模型业务说明

- 版本：1.0
- 领域：博客
- 领域说明：博客领域模型，涵盖博客、文章、访客追踪
- 实体数量：7

## 实体：博客（聚合根）

- 说明：博客容器（对应 Odoo blog.blog）
- 来源：基于 博客；来源域 博客

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 博客名称
- 副标题：文本，说明 副标题
- 启用：布尔，默认值 是，说明 归档标记；置 False 级联归档所有文章
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 博客帖子：一对多 -> 博客过账
- 网站：多对一 -> 网站

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、副标题、网站编号
- 查询
- 更新，可写字段：名称、副标题、启用
- 归档（类型：更新），说明：归档博客，级联归档所有文章

#### 校验
- 创建时，名称 不能为空
- 归档时，只有活跃状态的博客可以归档

#### 变更
- 在 归档 时，将 启用 设为 否
- 在 归档 时，cascade
- 在 创建 / 更新 / 归档 时，将 编号 设为 编号

#### 计算
- 计算字段 博客过账数量：整数，规则 数量(博客帖子)

#### 事件
- 事件：归档 -> 博客.博客.已归档

#### 工作流
- 流程：blog_maintain_flow：创建 -> 更新 -> 归档（博客维护流程）

## 实体：博客过账（聚合根）

- 说明：博客文章，支持 Draft→Published→Archived 生命周期
- 来源：基于 博客过账；来源域 博客

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 文章标题
- 副标题：文本，说明 副标题，用于 OG description
- 内容：HTML，说明 正文 HTML
- 摘要：长文本，说明 摘要：content 前 200 字符去标签，支持手动覆盖
- 封面属性：JSON，说明 封面图属性（背景图 URL、resize 参数等）
- 是否发布：布尔，默认值 否，说明 发布标记
- 已发布日期：日期时间，说明 首次发布时间
- 过账日期：日期时间，说明 展示日期，computed = published_date or create_date
- 启用：布尔，默认值 是，说明 归档标记
- 访问：整数，默认值 0，说明 浏览次数
- 作者头像：二进制，说明 作者头像 image_128（related 字段）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 博客：多对一 -> 博客，必填关系
- 作者：多对一 -> 参与方，外键 作者参与方编号
- 标签：一对多 -> 博客标签

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、副标题、内容、封面属性、摘要，参数：博客编号：唯一标识（必填）
- 查询
- 更新，可写字段：名称、副标题、内容、封面属性、摘要、标签编号列表
- 发布（类型：更新），说明：发布文章
- 取消发布（类型：更新），说明：取消发布，回到草稿状态
- 归档（类型：更新），说明：归档文章
- 取消归档（类型：更新），说明：取消归档，恢复为草稿状态

#### 校验
- 创建时，名称 不能为空
- 发布时，文章已经处于发布状态
- 取消发布时，文章未发布，无法取消发布
- 归档时，文章已经处于归档状态
- 取消归档时，文章未归档，无法取消归档

#### 策略
- 权限：查询 操作，当 数据.是否发布 = 是 或 操作者.角色 属于 designer、管理员 时允许

#### 变更
- 在 创建 时，将 作者编号 设为当前操作人
- 在 发布 时，将 是否发布 设为 是
- 在 发布 时，将 已发布日期 设为 当前时间
- 在 取消发布 时，将 是否发布 设为 否
- 在 归档 时，将 启用 设为 否
- 在 归档 时，将 是否发布 设为 否
- 在 取消归档 时，将 启用 设为 是
- 在 创建 / 更新 / 发布 / 取消发布 / 归档 / 取消归档 时，将 编号 设为 编号

#### 计算
- 计算字段 过账日期：日期时间，规则 coalesce（已发布日期，创建时间）
- 计算字段 摘要：长文本，规则 strip_tags_truncate(内容, 200)
- 计算字段 网站链接：文本，规则 格式(/blog/{}/{}, 博客.名称, 名称)

#### 事件
- 事件：发布 -> 博客.过账.已发布
- 事件：归档 -> 博客.过账.已归档

#### 工作流
- 流程：blog_post_lifecycle：创建 -> 更新 -> 发布 -> 取消发布 -> 归档 -> 取消归档（文章生命周期：草稿→发布→归档）

## 实体：访客（聚合根）

- 说明：网站访客追踪，支持匿名哈希标识与访问节流
- 来源：基于 访客；来源域 博客

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 访问令牌：文本（必填），说明 访客标识：已登录=partner_id；匿名=SHA1(IP+UA+Session)
- 访问数量：整数，默认值 0，说明 访问次数（距上次 >= 8h 才递增）
- 最近连接日期时间：日期时间，说明 最后活跃时间
- 国家编号：唯一标识，说明 国家
- 语言编号：唯一标识，说明 语言
- 时区：文本，说明 时区：优先 cookie tz，其次用户设置
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号
- 网站追踪：一对多 -> WebsiteTrack
- 最近已访问页面：多对一 -> 网页页面

#### 唯一约束
- 唯一约束 唯一访问令牌：访问令牌

### Conduct（行为声明）

#### 操作
- 创建或更新（类型：创建），说明：创建或更新访客记录，可写字段：访问令牌、伙伴编号、国家编号、语言编号、时区
- 查询
- 记录访问（类型：更新），说明：记录一次访问，受 8 小时节流规则约束
- 合并（类型：更新），说明：用户登录时合并匿名访客数据到已认证访客记录，参数：目标访客编号：唯一标识（必填）
- 清理（类型：删除），说明：定时清理 60+ 天无活动且无 partner 关联的访客

#### 校验
- 创建或更新时，访问令牌 不能为空

#### 变更
- 在 记录访问 时，将 访问数量 设为 访问数量 + 1
- 在 记录访问 时，将 最近连接日期时间 设为 当前时间
- 在 创建或更新 / 记录访问 / 合并 / 清理 时，将 编号 设为 编号

#### 计算
- 计算字段 已连接：布尔，规则 差异分钟(当前时间, 最近连接日期时间) ≤ 5
- 计算字段 访客页面数量：整数，规则 数量(网站追踪)
- 计算字段 时间自最近操作：文本，规则 human_readable_diff(当前时间, 最近连接日期时间)

#### 工作流
- 流程：visitor_lifecycle：创建或更新 -> 记录访问 -> 合并 -> 清理（访客生命周期）
