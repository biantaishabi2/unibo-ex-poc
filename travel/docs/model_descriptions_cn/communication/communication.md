# 模型业务说明

- 版本：1.0
- 领域：沟通
- 领域说明：即时通讯领域模型，涵盖消息、频道、频道成员、通知分发与实时事件广播
- 实体数量：15

## 实体：频道（聚合根）

- 说明：频道——消息容器，支持 chat（私聊）、channel（公开频道）、group（群组）三种类型
- 来源：基于 联系列表；来源域 ofbiz/marketing；过滤条件 联系列表类型编号=频道

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 频道名称；chat 类型由系统自动生成
- 频道类型：枚举，默认值 频道，可选值：聊天 / 频道 / 分组，说明 频道类型，创建后不可变更
- 唯一标识：文本（必填、自动生成），最长 50 字符，说明 邀请令牌，50 字符唯一随机串，创建时自动生成，不可变
- 说明：长文本，说明 频道描述
- 自定义头像（image_128）：二进制
- 启用：布尔，默认值 是，说明 是否活跃（归档控制）
- 允许公开上传：布尔，默认值 否，说明 是否允许访客上传文件
- 分组编号列表：m2m，说明 自动订阅用户组，仅 channel 类型可设；变更时通过 _subscribe_users_automatically() 批量创建成员记录
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 成员：一对多 -> 频道成员
- 消息：一对多 -> 消息
- 创建人：多对一 -> 参与方，外键 创建参与方编号
- 分组公开：多对一 -> 分组

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、频道类型、说明、image_128、允许公开上传、分组公开编号、分组编号列表
- 查询
- 更新，可写字段：名称、说明、启用、image_128、允许公开上传、分组公开编号、分组编号列表
- 归档（类型：更新），说明：归档频道，将 active 设为 false
- 添加成员（类型：自定义规则），说明：添加成员；创建成员记录 + 发布加入通知 + 广播成员列表 + 可选 RTC 邀请，参数：伙伴编号列表：list(uuid)（必填）
- 频道获取（类型：自定义规则），说明：查找或创建 2 人 chat，为当前用户 pin 频道

#### 校验
- 频道类型 只读后创建（频道类型创建后不可变更）
- 唯一标识 只读后创建（邀请令牌创建后不可变更）
- 创建／更新时，分组公开编号 仅在特定条件下适用（公开访问权限组仅 channel 类型可设置）
- 创建／更新时，分组编号列表 仅在特定条件下适用（自动订阅用户组仅 channel 类型可设置）
- 添加成员时，最大成员（私聊频道最多 2 个成员）
- 阻止删除（Whole Company 系统频道不可删除）
- 归档时，只有活跃频道可以归档
- 禁用消息订阅

#### 变更
- 在 创建 时，将 创建人 设为当前操作人
- 在 创建 时，将 分组公开编号 设为 基础分组用户；如果 频道类型=频道，则 无后续动作
- 在 归档 时，将 启用 设为 否
- 在 创建 时，自动生成 唯一标识
- 在 创建 / 更新 / 归档 / 添加成员 / 频道获取 时，将 编号 设为 编号

#### 工作流
- 流程：channel_member_manage_flow：创建 -> 更新 -> 添加成员 -> 归档（频道维护与成员管理流程）

## 实体：频道成员

- 说明：频道成员——记录用户在频道中的成员身份、阅读位置与通知偏好
- 来源：基于 联系列表参与方；来源域 ofbiz/marketing

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 角色：枚举，默认值 成员，可选值：管理员 / 成员，说明 成员角色
- 折叠状态：枚举，默认值 已关闭，可选值：打开 / 已折叠 / 已关闭，说明 UI 折叠状态
- 最小化：布尔，默认值 否，说明 会话最小化状态
- 已置顶：布尔，默认值 是，说明 是否在侧边栏显示
- 自定义规则频道名称：文本，说明 个人自定义频道名称
- 自定义规则通知：枚举，可选值：仅提及 / 无，说明 个人通知偏好（null 表示使用默认）
- 静音直到时间：日期时间，说明 静音截止时间
- 最近消息时间：日期时间，说明 最后活跃时间戳
- 最近已查看时间：日期时间，说明 最后在线时间
- 已加入日期：日期（必填），默认值 今日，说明 加入日期
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 频道：多对一 -> 频道，必填关系
- 用户：多对一 -> 参与方，外键 用户参与方编号
- 访客：多对一 -> 访客
- 已查看消息：多对一 -> 消息
- 已获取消息：多对一 -> 消息
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号
- RTC邀请中会话：多对一 -> RTCSession

### Conduct（行为声明）

#### 操作
- 创建，可写字段：角色、已加入日期、折叠状态、最小化、已置顶、自定义规则频道名称、自定义规则通知、静音直到时间，参数：频道编号：唯一标识（必填）；伙伴编号：唯一标识；访客编号：唯一标识
- 查询
- 更新，可写字段：折叠状态、最小化、已置顶、自定义规则频道名称、自定义规则通知、静音直到时间
- 删除，说明：删除成员记录 + 广播离开事件 + 发布系统消息（CM-R5 unfollow）
- 标记已查看（类型：更新），说明：标记已读位置（使用 FOR NO KEY UPDATE SQL 锁避免并发冲突），可写字段：已查看消息编号
- 标记已获取（类型：更新），说明：标记已获取位置，可写字段：已获取消息编号
- 加载更多成员（类型：查询），说明：成员列表分页加载，每页 100 条（CM-R10）

#### 校验
- 创建时，二选一（partner_id 和 guest_id 必须二选一，不能同时为空或同时有值）
- 标记已查看时，并发安全

#### 变更
- 在 消息过账 时，将 已置顶 设为 是
- 在 消息过账 时，将 最近消息时间 设为 当前时间
- 在 消息过账后 时，将 已查看消息编号 设为 已过账消息编号
- 在 删除 时，广播事件
- 在 创建 时，广播事件
- 定时任务岗位
- 在 查找或创建角色 时，自动创建；如果 访客编号=空，访客=是，则 无后续动作
- 在 创建 / 更新 / 删除 / 标记已查看 / 标记已获取 时，将 编号 设为 编号

#### 工作流
- 流程：channel_member_read_state_flow：创建 -> 更新 -> 标记已获取 -> 标记已查看 -> 删除（成员状态维护与读取位置更新流程）

## 实体：消息（聚合根）

- 说明：消息——频道中的通信记录，支持评论、邮件、通知、线程回复等多种类型
- 来源：基于 沟通活动；来源域 ofbiz/party

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 内容：长文本（必填），说明 消息体（HTML）
- 主题：文本，说明 邮件主题
- 消息类型：枚举，默认值 评论，可选值：邮箱 / 评论 / 邮件外发 / 通知 / 自动评论 / 用户通知，说明 消息类型
- 内部：布尔，默认值 否，说明 是否为内部消息（非员工不可见）
- 已置顶：布尔，默认值 否，说明 是否置顶
- 回复：文本，说明 回复地址（计算生成）
- 回复强制新：布尔，默认值 否，说明 强制新会话（禁用线程化）
- 消息编号：文本，说明 RFC 5322 Message-ID，创建时自动生成
- 模型：文本，说明 关联模型名称（如 discuss.channel）
- 资源编号：整数，说明 关联记录 ID
- 邮箱来源：文本，说明 发件人邮箱
- 伙伴编号列表：m2m，说明 收件人列表
- 已收藏伙伴编号列表：m2m，说明 星标用户列表
- 附件编号列表：m2m，说明 附件列表
- 追踪值编号列表：o2m，说明 字段变更追踪记录
- 通知编号列表：o2m，说明 通知记录列表
- 已发送：日期时间（必填），默认值 当前时间，说明 发送时间
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 频道：多对一 -> 频道
- 作者：多对一 -> 参与方，外键 作者参与方编号
- 上级：多对一 -> 消息
- 通知：一对多 -> 通知
- 附件：一对多 -> 附件
- 追踪取值：一对多 -> 追踪值
- 子类型：多对一 -> 消息子类型

### Conduct（行为声明）

#### 操作
- 创建，可写字段：内容、主题、消息类型、子类型编号、内部、已置顶、回复强制新、上级编号、模型、资源编号、邮箱来源、伙伴编号列表、附件编号列表，参数：频道编号：唯一标识
- 查询
- 更新，可写字段：内容、已置顶、已收藏伙伴编号列表、附件编号列表
- 删除，说明：删除消息（需有关联文档写/创建权限）
- 切换星标（类型：更新），说明：切换星标状态
- 发送瞬态消息（类型：自定义规则），说明：发送瞬态消息——仅通过 Bus 广播，不持久化（MSG-R8）

#### 变更
- 在 创建 时，自动生成 消息编号
- 在 创建 时，提取内联图片 内容
- 在 创建 时，更新全部频道成员
- 在 创建 时，自动标记查询
- 在 创建 时，提权执行；如果 访客作者=是，则 无后续动作
- 在 创建 时，提取语音元数据；如果 附件类型=voice，则 无后续动作
- 在 创建 时，将 作者 设为当前操作人
- 在 创建 / 更新 / 删除 / 切换星标 / 发送瞬态消息 时，将 编号 设为 编号

#### 工作流
- 流程：message_publish_flow：创建 -> 更新 -> 切换星标 -> 发送瞬态消息 -> 删除（消息发布与星标维护流程）

## 实体：邮件分组（聚合根）

- 说明：邮件组——基于邮件的订阅式讨论组，支持公开/成员/用户组三种访问模式和消息审核
- 来源：基于 邮件分组；来源域 沟通

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 邮件组名称
- 说明：长文本，说明 邮件组描述
- 启用：布尔，默认值 是，说明 是否启用
- 是否开启消息审核（moderation）：布尔，默认值 否
- 访问模式：枚举，默认值 公开，可选值：公开 / 成员 / 分组，说明 访问模式；public 公开，members 仅成员，groups 指定用户组
- 是否自动通知待审核消息（moderation_notify）：布尔，默认值 否
- 审核通知消息模板（moderation_notify_msg）：长文本
- 是否向新订阅者发送指南（moderation_guidelines）：布尔，默认值 否
- 指南内容（moderation_guidelines_msg）：长文本
- 邮件组图片（image_128）：二进制
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 成员：一对多 -> 邮件分组成员
- 分组消息：一对多 -> 邮件分组消息
- moderation_rules：一对多 -> MailGroupModeration

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、说明、启用、moderation、访问模式、moderation_notify、moderation_notify_msg、moderation_guidelines、moderation_guidelines_msg、image_128
- 查询
- 更新，可写字段：名称、说明、启用、moderation、访问模式、moderation_notify、moderation_notify_msg、moderation_guidelines、moderation_guidelines_msg、image_128
- 删除
- 加入（类型：更新），说明：当前用户加入邮件组
- 请假（类型：更新），说明：当前用户离开邮件组

#### 校验
- 创建／更新时，名称 不能为空

#### 变更
- 在 创建 / 更新 / 删除 / 加入 / 请假 时，将 编号 设为 编号

#### 计算
- 计算字段 成员数量：整数，规则 count(members)
- 计算字段 邮件分组消息数量：整数，规则 count(group_messages)
- 计算字段 mail_group_message_moderation_count：整数，规则 count(group_messages, filter: moderation_status == 'pending_moderation')
- 计算字段 moderation_rule_count：整数，规则 count(moderation_rules)

#### 工作流
- 流程：mail_group_membership_flow：创建 -> 加入 -> 请假 -> 更新 -> 删除（邮件组创建与成员加入退出流程）

## 实体：邮件分组消息

- 说明：邮件组消息——邮件组中的通信记录，支持审核状态机（pending_moderation → accepted / rejected）
- 来源：基于 邮件分组消息；来源域 沟通

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 主题：文本，说明 消息主题
- 正文：长文本，说明 消息正文
- 邮箱来源：文本，说明 发件人邮箱
- 标准化发件人邮箱（email_from_normalized）：文本
- 审核状态（moderation_status）：枚举，默认值 pending_moderation，可选值：pending_moderation / 已接受 / 已驳回
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 邮件分组：多对一 -> 邮件分组，必填关系
- 版主：多对一 -> 参与方，外键 版主参与方编号
- 上级消息：多对一 -> 邮件分组消息
- 下级消息：一对多 -> 邮件分组消息，外键 上级消息编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：主题、正文、邮箱来源、email_from_normalized、moderation_status，参数：邮件分组编号：唯一标识（必填）；版主编号：唯一标识；上级消息编号：唯一标识
- 查询
- 审核接受（类型：更新），说明：通过消息并通知所有成员，可写字段：moderation_status
- 审核驳回（类型：更新），说明：拒绝消息，可写字段：moderation_status
- 审核允许（类型：更新），说明：白名单作者并通过其所有待审核消息，可写字段：moderation_status
- moderate_ban（类型：更新），说明：封禁作者并拒绝其所有待审核消息，可写字段：moderation_status

#### 校验
- 创建时，邮件分组编号 不能为空

#### 变更
- 在 审核接受 / 审核允许 时，将 moderation_status 设为 已接受
- 在 审核驳回 / moderate_ban 时，将 moderation_status 设为 已驳回
- 在 创建 / 审核接受 / 审核驳回 / 审核允许 / moderate_ban 时，将 编号 设为 编号

#### 工作流
- 流程：mail_group_message_moderation_flow：创建 -> 审核接受 -> 审核驳回 -> 审核允许 -> moderate_ban（邮件组消息审核流转流程）
