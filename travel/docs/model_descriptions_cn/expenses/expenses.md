# 模型业务说明

- 版本：1.0
- 领域：费用
- 领域说明：费用报销领域模型，涵盖费用报告、费用明细、费用类别
- 实体数量：13

## 实体：费用报表（聚合根）

- 说明：费用报告（员工报销发票）
- 来源：基于 发票；来源域 ofbiz/accounting；过滤条件 发票类型编号=采购发票

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 报表单号：文本（必填），说明 报销单号
- 状态：枚举，默认值 草稿，可选值：草稿 / 已提交 / 已审批 / 已过账 / 完成 / 已取消，说明 报销单状态（由多字段计算得出）
- 审批状态：枚举，可选值：已提交 / 已审批 / 已取消，说明 审批状态（内部字段，驱动 state 计算）
- 付款模式：枚举（必填），可选值：自有科目 / 公司科目，说明 支付方式（员工垫付 / 公司支付）
- 合计金额：金额，说明 报销总金额
- 合计税金额：金额，说明 税额合计
- 未税金额：金额，说明 不含税金额
- 未付余额：金额，说明 待付余额
- 报表日期：日期（必填）
- 审批日期：日期时间，说明 审批日期
- 说明：长文本
- 备注：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 员工：多对一 -> 员工，必填关系
- 审批人：多对一 -> 参与方，外键 审批人参与方编号
- 币种：多对一 -> 币种，必填关系
- 公司：多对一 -> 参与方，外键 公司参与方编号，必填关系
- 员工日记账：多对一 -> 日记账
- 付款方法行：多对一 -> 付款方法行
- 费用行编号列表：一对多 -> 费用行，外键 报表编号，管理模式 直接管理
- 科目移动编号列表：一对多 -> 科目移动，外键 费用报表编号

#### 唯一约束
- 唯一约束 唯一报表单号：报表单号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：报表单号、报表日期、付款模式、说明、备注，参数：明细行：列表（必填）；员工编号：唯一标识（必填）；币种编号：唯一标识（必填）；公司编号：唯一标识（必填）
- 查询
- 提交（类型：更新），说明：提交审批（draft → submitted）
- 审批（类型：更新），说明：审批通过（submitted → approved）
- 拒绝（类型：更新），说明：审批驳回（submitted/approved → cancelled），参数：原因：文本（必填）
- 过账（类型：更新），说明：过账（approved → posted，创建会计凭证或付款）
- 登记付款（类型：更新），说明：登记付款（posted → done，仅 own_account 模式）
- 重置（类型：更新），说明：重置（任意状态 → draft，已过账凭证先冲销）

#### 校验
- 创建时，报表单号 不能为空
- 提交时，只有草稿状态可以提交
- 提交时，费用行编号列表 非空（报销单必须包含至少一条费用明细 (规则1)）
- 提交时，费用行编号列表产品编号 全部必填校验（所有费用明细必须有费用类型 (规则2)）
- 提交时，费用行编号列表员工编号 all_equal（所有费用明细必须属于同一个员工 (规则3)）
- 提交时，费用行编号列表合计金额 全部格式匹配校验（所有费用明细的金额不能为零 (规则4)）
- 审批时，只有已提交状态可以审批
- 审批时，authorize（只有指定审批人或 HR Officer 可以审批 (规则7)）
- 审批时，重复检查（检测到重复费用，需要显式确认后才能审批 (规则8)）
- 审批时，expense_line_ids.analytic_distribution valid_distribution（分析分配校验不通过 (规则10)）
- 拒绝时，只有已提交或已审批状态可以驳回
- 拒绝时，原因 不能为空（驳回必须提供原因 (规则11)）
- 拒绝时，科目移动编号列表 空（已存在会计凭证的报销单不能驳回，必须先重置 (规则12)）
- 过账时，只有已审批状态可以过账
- 过账时，员工工作邮箱 不能为空（员工必须有工作邮箱才能过账 (规则14)）
- 过账时，员工日记账编号 不能为空（采购类日记账必须设置 (规则15)）
- 登记付款时，只有已过账状态可以登记付款
- 登记付款时，仅员工垫付模式需要登记付款 (规则20)
- 创建／提交时，费用行编号列表付款模式 all_equal（同一张报销单的所有费用明细必须是同一支付方式 (规则26)）
- 创建／提交时，费用行编号列表员工编号 all_equal（同一张报销单的所有费用明细必须属于同一员工 (规则27)）
- 创建／提交时，费用行编号列表公司编号 all_equal（同一张报销单的所有费用明细必须属于同一公司 (规则28)）
- 阻止删除（已过账/已付款的报销单不可删除 (规则29)）

#### 变更
- 在 创建 时，将 员工 设为当前操作人
- 在 创建 时，将 合计金额 设为 合计(费用行编号列表.合计金额)
- 在 提交 时，将 审批状态 设为 已提交
- 在 审批 时，将 审批状态 设为 已审批
- 在 审批 时，将 审批人编号 设为 当前用户
- 在 审批 时，将 审批日期 设为 当前时间
- 在 拒绝 时，将 审批状态 设为 已取消
- 在 重置 时，设置 审批状态
- 在 创建 / 提交 / 审批 / 拒绝 / 过账 / 登记付款 / 重置 时，将 编号 设为 编号

#### 事件
- 事件：提交 -> 费用.报表.已提交
- 事件：审批 -> 费用.报表.已审批
- 事件：拒绝 -> 费用.报表.已拒绝
- 事件：过账 -> 费用.报表.已过账
- 事件：登记付款 -> 费用.报表.已付清
- 事件：重置 -> 费用.报表.重置

#### 工作流
- 流程：expense_report_approval_payment_flow：创建 -> 提交 -> 审批 -> 过账 -> 登记付款（报销单提交审批并过账付款流程）
- 流程：expense_report_refuse_reset_flow：创建 -> 提交 -> 拒绝 -> 重置 -> 提交 -> 审批（报销单驳回后重置再提交流程）

#### 集成契约
- 提交排班活动，绑定动作：提交；模式：同步；响应字段：已接受、活动编号；说明：调度审批活动给 approver
- post_own_account_register_payment，绑定动作：过账；模式：同步；请求字段：付款模式；响应字段：已接受、科目移动编号；说明：own_account 模式创建 account.move vendor bill → action_post → register_payment
- 过账公司科目创建付款，绑定动作：过账；模式：同步；请求字段：付款模式；响应字段：已接受、付款编号；说明：company_account 模式创建 account.payment outbound → action_post
- reset_reverse_moves，绑定动作：重置；模式：同步；响应字段：已接受、已冲销数量；说明：reverse_moves 冲销凭证
- 审批拒绝发送邮件，绑定动作：审批 / 拒绝；模式：同步；响应字段：已接受、消息编号；说明：发送审批/驳回通知
- pricing_fetch_standard_price，绑定动作：创建 / 提交；模式：同步；响应字段：已接受、标准价格；说明：取 product.standard_price 费用产品成本价
- 税计算通话科目税，绑定动作：提交 / 过账；模式：同步；响应字段：已接受、税金额；说明：account.tax._compute_taxes 税额计算

## 实体：费用行

- 说明：费用明细
- 来源：基于 发票项；来源域 ofbiz/accounting

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 说明：文本（必填），说明 费用描述
- 数量：金额（必填），默认值 1，说明 数量
- 单价：金额（必填），说明 单价
- 付款模式：枚举（必填），可选值：自有科目 / 公司科目，说明 支付方式（员工垫付 / 公司支付）
- 币种费率：金额，说明 汇率（可手动覆盖，支持自定义汇率）(规则31/32)
- 合计金额币种：金额，说明 费用币种金额
- 合计金额：金额，必须大于 0（费用金额必须大于零 (规则30)），说明 公司币种金额
- 税金额币种：金额，说明 费用币种税额
- 税金额：金额，说明 公司币种税额
- 未税金额币种：金额，说明 费用币种不含税金额
- 费用日期：日期（必填），说明 费用发生日期
- 收据参考号：文本，说明 发票/收据号
- 分析维度分摊：JSON，说明 分析分配
- 重复：布尔，说明 重复标记
- 状态：枚举，可选值：草稿 / 已报告 / 已审批 / 已拒绝 / 完成，说明 费用明细状态（从 report 状态派生）
- 备注：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 报表：多对一 -> 费用报表
- 产品：多对一 -> 产品，必填关系
- 分类：多对一 -> 费用分类
- 员工：多对一 -> 员工，必填关系
- 币种：多对一 -> 币种，必填关系
- 税编号列表：多对多 -> 税，中间关系 费用行税链接

### Conduct（行为声明）

#### 操作
- 创建，可写字段：说明、数量、单价、费用日期、收据参考号、付款模式、币种费率、分析维度分摊、备注，参数：产品编号：唯一标识（必填）；员工编号：唯一标识（必填）；币种编号：唯一标识（必填）；税编号列表：列表；分类编号：唯一标识
- 更新，可写字段：说明、数量、单价、费用日期、收据参考号、付款模式、币种费率、分析维度分摊、备注
- 拆分（类型：更新），说明：费用拆分（50/50 拆为两条明细）(规则35)

#### 校验
- 创建时，产品编号 不能为空（费用类型不能为空）
- 阻止删除（已过账/已付款的费用明细不可删除 (规则29)）

#### 变更
- 在 创建 时，relate_actor_employee 员工
- 在 创建 / 更新 时，计算 合计金额币种
- 在 创建 / 更新 时，计算 合计金额
- 在 创建 / 更新 时，计算 税金额币种
- 在 创建 / 更新 时，计算 税金额
- 在 创建 / 更新 时，计算 未税金额币种
- 在 创建 / 更新 时，计算 重复
- 在 创建 / 更新 时，计算 状态
- 在 创建 / 更新 / 拆分 时，将 编号 设为 编号

#### 工作流
- 流程：expense_line_edit_flow：创建 -> 更新 -> 拆分（费用明细编辑与拆分流程）
