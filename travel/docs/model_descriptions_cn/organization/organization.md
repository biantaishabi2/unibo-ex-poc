# 模型业务说明

- 版本：1.0
- 领域：组织
- 领域说明：组织域底座，统一管理主体（人/组织）、角色分配与主体间关系
- 实体数量：3

## 实体：参与方（聚合根）

- 说明：统一主体，可以是自然人或组织实体，是所有业务角色和关系的基础

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 主体名称
- 参与方类型：枚举（必填），可选值：人员 / 组织，说明 主体类型——区分自然人与组织
- 说明：文本，说明 可选描述信息
- 外部编号：文本，说明 外部系统编号，用于与外部系统对接
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 角色：一对多 -> 参与方角色，外键 参与方编号
- outgoing_relationships：一对多 -> 参与方关系，外键 来源参与方编号
- incoming_relationships：一对多 -> 参与方关系，外键 参与方编号

### Conduct（行为声明）

#### 操作
- 查询
- 创建，可写字段：名称、参与方类型、说明、外部编号
- 更新，可写字段：名称、说明、外部编号
- 删除

#### 策略
- 权限：查询 操作，当 操作者.角色 = 管理员 时允许
- 权限：查询 操作，当 组织范围访问（参与方） 时允许
- 权限：创建 操作，当 操作者.角色 = 管理员 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 操作者.参与方编号 = 编号 且 参与方类型 = 人员 时允许
- 权限：删除 操作，当 操作者.角色 = 管理员 时允许

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 计算
- 计算字段 组织范围：列表，表达式 自定义规则

## 实体：参与方角色（聚合根）

- 说明：主体角色，同一主体可以同时拥有多个角色（如既是员工又是质量检查员）

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 角色类型：枚举（必填），可选值：员工 / 客户 / 供应商 / factory / 部门 / 团队 / 管理员 / quality_inspector / 租赁代理 / 销售代表 / 项目经理，说明 角色类型，可扩展
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 参与方：多对一 -> 参与方，外键 参与方编号，必填关系

### Conduct（行为声明）

#### 操作
- 查询
- 创建，可写字段：角色类型，参数：参与方编号：唯一标识（必填）
- 更新，可写字段：角色类型
- 删除

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

## 实体：参与方关系（聚合根）

- 说明：主体间关系，支持汇报、隶属、管理、子公司等关系类型，带有效期

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 关系类型：枚举（必填），可选值：reports_to / belongs_to_org / manages / subsidiary_of，说明 关系类型
- 来源日期：日期时间（必填），说明 关系起始时间
- 至日期：日期时间，说明 关系结束时间（空表示当前有效）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 来源参与方：多对一 -> 参与方，外键 来源参与方编号，必填关系
- 参与方：多对一 -> 参与方，外键 参与方编号，必填关系

### Conduct（行为声明）

#### 操作
- 查询
- 创建，可写字段：关系类型、来源日期、至日期，参数：来源参与方编号：唯一标识（必填）；参与方编号：唯一标识（必填）
- 更新，可写字段：关系类型、来源日期、至日期
- 删除

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号
