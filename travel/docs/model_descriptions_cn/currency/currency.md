# 模型业务说明

- 版本：1.0
- 领域：币种
- 领域说明：多币种管理领域模型，维护币种和汇率信息
- 实体数量：2

## 实体：币种（聚合根）

- 说明：币种主数据（ISO 4217），本质是计量单位的币种子类型
- 来源：基于 单位；来源域 ofbiz/common；过滤条件 单位类型编号=币种度量

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 币种名称（对齐 Uom.description）
- 系数：浮点，默认值 1.0，说明 换算比率（币种间通过 CurrencyRate 换算，此处固定 1.0，对齐 Uom.factor）
- 四舍五入：浮点，默认值 0.01，说明 舍入精度（对齐 Uom.rounding）
- 启用：布尔，默认值 是，说明 是否启用
- 编码：文本（必填），说明 ISO 4217 币种代码（如 CNY、USD、EUR）
- 币种符号（如 ¥、$、€）（symbol）：文本
- 小数位数（decimal_places）：整数，默认值 2
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 分类：多对一 -> 单位分类
- from_rates：一对多 -> 币种费率，外键 来源币种编号
- to_rates：一对多 -> 币种费率，外键 币种编号

#### 唯一约束
- 唯一约束 唯一编码：编码

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、编码、symbol、系数、四舍五入、decimal_places、启用，参数：分类编号：唯一标识
- 更新，可写字段：名称、symbol、系数、四舍五入、decimal_places、启用
- 查询
- 删除

#### 校验
- 创建时，编码 不能为空
- 创建时，名称 不能为空

#### 变更
- 在 创建 / 更新 时，将 编号 设为 编号

#### 计算
- 计算字段 系数库存：浮点，规则 1 ÷ 系数

#### 工作流
- 流程：currency_maintain_flow：创建 -> 更新 -> 删除（币种维护）

## 实体：币种费率（聚合根）

- 说明：币种汇率（带生效/失效日期的换算记录，对齐 OFBiz UomConversionDated）
- 来源：基于 UomConversionDated；来源域 ofbiz/common

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 费率：金额（必填），必须大于 0（汇率必须为正数），说明 换算比率（对齐 UomConversionDated.conversion_factor）
- 生效日期：日期（必填），说明 生效日期（对齐 UomConversionDated.from_date）
- 至日期：日期，说明 失效日期（对齐 UomConversionDated.thru_date，为空表示长期有效）
- 费率来源：文本，说明 汇率来源（如 央行、手动录入）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 来源币种：多对一 -> 币种
- 币种：多对一 -> 币种

#### 唯一约束
- 唯一约束 唯一费率：来源币种编号、币种编号、生效日期

### Conduct（行为声明）

#### 操作
- 创建，可写字段：费率、生效日期、至日期、费率来源、来源币种编号、币种编号
- 更新，可写字段：费率、至日期、费率来源
- 查询
- 删除

#### 校验
- 创建时，费率 不能为空
- 创建时，生效日期 不能为空

#### 变更
- 在 创建 / 更新 时，将 编号 设为 编号

#### 工作流
- 流程：currency_rate_maintain_flow：创建 -> 更新 -> 删除（汇率维护）
