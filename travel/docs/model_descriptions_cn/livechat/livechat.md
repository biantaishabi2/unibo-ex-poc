# 模型业务说明

- 版本：1.0
- 领域：在线聊天
- 领域说明：在线客服领域模型，涵盖客服频道、频道规则、聊天会话
- 实体数量：9

## 实体：在线聊天频道（聚合根）

- 说明：在线客服频道，管理操作员列表、UI 配置及操作员分配策略
- 来源：基于 在线聊天频道；来源域 在线聊天

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 频道名称
- 按钮长文本：文本，默认值 Have a Question? Chat with us.，说明 聊天按钮文本（支持国际化）
- 默认消息：文本，默认值 How may I help you?，说明 欢迎消息（支持国际化）
- 输入占位符：文本，说明 输入框占位符（支持国际化）
- 表头背景颜色：文本，默认值 #875A7B，说明 头部背景色
- 标题颜色：文本，默认值 #FFFFFF，说明 标题颜色
- 按钮背景颜色：文本，默认值 #875A7B，说明 按钮背景色
- 按钮长文本颜色：文本，默认值 #FFFFFF，说明 按钮文字颜色
- 图片：二进制，说明 频道头像 (128x128)
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 用户编号列表：多对多 -> 参与方，外键 用户编号列表参与方编号，中间关系 LiveChatChannelUserLink
- 会话：一对多 -> 聊天会话，外键 在线聊天频道编号
- 规则编号列表：一对多 -> 频道规则，外键 频道编号，管理模式 直接管理

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、按钮长文本、默认消息、输入占位符、表头背景颜色、标题颜色、按钮背景颜色、按钮长文本颜色、图片
- 查询
- 更新，可写字段：名称、按钮长文本、默认消息、输入占位符、表头背景颜色、标题颜色、按钮背景颜色、按钮长文本颜色、图片
- 加入（类型：更新），说明：当前用户加入操作员列表
- 退出（类型：更新），说明：当前用户退出操作员列表
- 获取在线聊天信息（类型：查询），说明：返回频道可用性及 UI 配置，参数：用户名：文本

#### 校验
- 创建时，名称 不能为空

#### 变更
- 在 创建 时，添加关联 用户编号列表（操作者）
- 在 加入 时，添加关联 用户编号列表（操作者）
- 在 退出 时，移除关联 用户编号列表（操作者）
- 在 创建 / 更新 / 加入 / 退出 时，将 编号 设为 编号

#### 计算
- 计算字段 网页页面：文本，规则 concat（/im_livechat/support/，编号）
- 计算字段 内部：布尔，规则 操作者.编号 属于 用户编号列表
- 计算字段 可用操作员编号列表：列表，规则 自定义规则（）
- 计算字段 数量频道：整数，规则 数量(会话)
- 计算字段 机器人脚本数量：整数，规则 count_distinct(规则编号列表.机器人脚本编号)
- 计算字段 可用：布尔，规则 机器人脚本数量 > 0 或 数量(可用操作员编号列表) > 0

#### 工作流
- 流程：livechat_channel_maintain_flow：创建 -> 更新 -> 加入 -> 退出（客服频道维护流程）

## 实体：频道规则

- 说明：频道显示规则，通过 URL 正则与国家条件控制聊天按钮行为
- 来源：基于 频道规则；来源域 在线聊天

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 正则链接：文本，说明 URL 正则匹配模式
- 操作：枚举，可选值：显示按钮 / 显示按钮且长文本 / 自动弹窗 / 隐藏按钮，说明 匹配后的显示行为
- 自动弹窗计时器：整数，说明 自动弹出延迟秒数（仅 auto_popup 时有效）
- 序列：整数，默认值 10，说明 规则排序优先级（升序）
- 机器人仅无操作员：布尔，默认值 否，说明 仅当无在线操作员时启用 chatbot
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 频道：多对一 -> 在线聊天频道，必填关系
- 国家编号列表：多对多 -> 国家，中间关系 频道规则国家链接
- 机器人脚本编号：多对一 -> 机器人脚本

### Conduct（行为声明）

#### 操作
- 创建，可写字段：正则链接、操作、自动弹窗计时器、序列、机器人仅无操作员，参数：频道编号：唯一标识（必填）
- 查询
- 更新，可写字段：正则链接、操作、自动弹窗计时器、序列、机器人仅无操作员
- 删除
- 格式匹配校验规则（类型：查询），说明：按优先级匹配频道规则，参数：频道编号：唯一标识（必填）；链接：文本（必填）；国家编号：唯一标识

#### 校验
- 创建时，操作 不能为空

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：channel_rule_maintain_flow：创建 -> 更新 -> 删除（频道规则维护流程）

## 实体：聊天会话（聚合根）

- 说明：在线客服聊天会话，由访客发起、系统分配操作员
- 来源：基于 聊天会话；来源域 在线聊天；过滤条件 频道类型=在线聊天

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 在线聊天启用：布尔，默认值 是，说明 会话是否活跃
- 匿名名称：文本，说明 未注册访客的显示名称
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 在线聊天频道：多对一 -> 在线聊天频道，必填关系
- 操作员：多对一 -> 参与方，外键 操作员参与方编号
- 国家：多对一 -> 国家
- 机器人当前步骤：多对一 -> 机器人脚本步骤

### Conduct（行为声明）

#### 操作
- 创建，可写字段：匿名名称，参数：在线聊天频道编号：唯一标识（必填）；上一个操作员编号：唯一标识；语言：文本；国家编号：唯一标识；机器人脚本编号：唯一标识
- 查询
- 关闭（类型：更新），说明：关闭会话（标记为不活跃）

#### 校验
- 关闭时，只有活跃会话可以关闭

#### 策略
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=操作员 时允许
- 权限：关闭 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=操作员 时允许

#### 变更
- 在 创建 时，通话
- 在 关闭 时，将 在线聊天启用 设为 否
- 在 创建 / 关闭 时，将 编号 设为 编号

#### 计算
- 计算字段 显示名称：文本，规则 coalesce（匿名名称，操作员.名称）

#### 事件
- 事件：创建 -> 在线聊天.会话.创建
- 事件：关闭 -> 在线聊天.会话.已关闭

#### 工作流
- 流程：chat_session_lifecycle：创建 -> 关闭（聊天会话生命周期）
