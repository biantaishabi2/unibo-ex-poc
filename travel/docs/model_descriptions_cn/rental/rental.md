# 模型业务说明

- 版本：1.0
- 领域：租赁
- 领域说明：租赁管理领域模型，涵盖租赁订单、订单行、定价规则、逾期罚金
- 实体数量：9

## 实体：租赁订单（聚合根）

- 说明：租赁订单（对应 Odoo sale.order 扩展，is_rental=true 区分普通销售）
- 来源：基于 租赁订单；来源域 租赁；过滤条件 租赁=是

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 租赁：布尔（必填），默认值 是，说明 区分普通销售与租赁订单
- 租赁状态：枚举，默认值 草稿，可选值：草稿 / 已确认 / 取货 / 退货 / 完成 / 取消，说明 订单级租赁状态
- 取货日期：日期时间（必填），说明 计划取货日期
- 退货日期：日期时间（必填），说明 计划归还日期
- 实际退货日期：日期时间，说明 实际归还日期（归还时写入）
- 缓冲时间：浮点，说明 缓冲时间（小时），从全局配置继承或手动覆盖
- 配送订单编号：唯一标识，说明 关联出库单（取货，库存集成时）
- 收据订单编号：唯一标识，说明 关联入库单（归还，库存集成时）
- 预留过期：日期时间，说明 预约过期时间（TTL 自动释放）
- 存款金额：金额，说明 押金金额
- 币种编号：唯一标识（必填），说明 币种
- 公司编号：唯一标识（必填），说明 所属公司
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 明细行：一对多 -> 租赁订单行，外键 订单编号，管理模式 直接管理
- 客户：多对一 -> 客户，必填关系
- 创建人：多对一 -> 参与方，外键 创建参与方编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：取货日期、退货日期、缓冲时间、存款金额、币种编号、公司编号，参数：明细行：列表（必填）；客户编号：唯一标识（必填）
- 查询
- 更新，可写字段：取货日期、退货日期、缓冲时间、存款金额
- 确认操作（类型：更新），说明：确认订单（校验库存可用性，创建出入库单）
- 操作取货（类型：更新），说明：取货（至少一条行完成取货验证）
- 操作退货（类型：更新），说明：归还（所有已取货行完成归还）
- 完成操作（类型：更新），说明：完成（发票已创建且罚金已计算）
- 操作取消（类型：更新），说明：取消订单

#### 校验
- 创建／更新时，退货日期 必须大于 取货日期（归还日期必须晚于取货日期）
- 创建／更新时，缓冲时间 必须 ≥ 0（缓冲时间不能为负数）
- 确认操作时，确认时至少需要一条租赁订单行
- 确认操作时，库存不足，无法确认订单
- 确认操作时，只有草稿状态可以确认
- 操作取货时，只有已确认状态可以取货
- 操作退货时，只有已取货状态可以归还
- 完成操作时，只有已归还状态可以完成
- 操作取消时，只有草稿或已确认状态可以取消

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 租赁代理、管理员 时允许
- 权限：查询 操作，当 是 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 操作者.编号 = 数据.创建编号 时允许

#### 变更
- 在 创建 时，将 创建人 设为当前操作人
- 在 确认操作 时，将 租赁状态 设为 已确认
- 在 操作取货 时，将 租赁状态 设为 取货
- 在 操作退货 时，将 租赁状态 设为 退货
- 在 完成操作 时，将 租赁状态 设为 完成
- 在 操作取消 时，将 租赁状态 设为 取消
- 在 确认操作 时，副作用

#### 计算
- 计算字段 延迟：布尔，规则 任意(明细行.延迟)
- 计算字段 罚金金额：金额，规则 合计(明细行.罚金金额)
- 计算字段 可拣明细行：布尔，规则 任意(明细行.可拣)
- 计算字段 可退明细行：布尔，规则 任意(明细行.可退)

#### 聚合
- 聚合 合计明细行：数量（关系 明细行，字段 无）
- 聚合 合计罚金：合计（关系 明细行，字段 罚金金额）

#### 事件
- 事件：确认操作 -> 租赁.订单.已确认
- 事件：操作取货 -> 租赁订单已取货
- 事件：操作退货 -> 租赁订单已归还
- 事件：完成操作 -> 租赁.订单.完成
- 事件：操作取消 -> 租赁.订单.已取消

#### 工作流
- 流程：rental_flow：创建 -> 确认操作 -> 操作取货 -> 操作退货 -> 完成操作（租赁全流程）

## 实体：租赁订单行

- 说明：租赁订单行（支持部分取货/归还，行级独立状态）
- 来源：基于 订单项；来源域 ofbiz/order；过滤条件 订单项类型编号=租赁项

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 租赁：布尔（必填），默认值 是，说明 是否为租赁行
- 租赁状态：枚举，默认值 草稿，可选值：草稿 / 取货 / 退货 / 已退回，说明 行级租赁状态
- 取货日期：日期时间（必填），说明 行级取货日期（可与订单头不同，支持部分取货）
- 退货日期：日期时间（必填），说明 行级归还日期
- 实际退货日期：日期时间，说明 实际归还时间
- 数量已送达：浮点，默认值 0，说明 已取货数量
- 数量已退回：浮点，默认值 0，说明 已归还数量
- 产品单位数量：浮点（必填），说明 租赁数量
- 时长单位：枚举，可选值：小时 / 天 / 周 / 月 / 年，说明 时长单位
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 订单：多对一 -> 租赁订单，必填关系
- 产品：多对一 -> 产品，必填关系
- 定价规则：多对一 -> 租赁定价

### Conduct（行为声明）

#### 操作
- 创建，可写字段：租赁、取货日期、退货日期、产品单位数量、时长单位，参数：产品编号：唯一标识（必填）
- 更新，可写字段：取货日期、退货日期、产品单位数量、时长单位
- 验证取货（类型：更新），说明：取货验证（产品已交付给客户），参数：数量：浮点（必填）
- 验证退货（类型：更新），说明：归还验证（客户已归还产品），参数：数量：浮点（必填）；实际退货日期：日期时间（必填）
- 完成（类型：更新），说明：完成归还流程（库存已恢复）

#### 校验
- 验证退货时，数量已退回 必须 ≤ 数量已送达（归还数量不能超过已取货数量）
- 创建时，该产品未启用租赁功能
- 验证取货时，只有草稿状态可以取货
- 验证退货时，只有已取货状态可以归还
- 完成时，只有已归还状态可以完成

#### 变更
- 在 验证取货 时，将 数量已送达 设为 数量已送达 + arguments.数量
- 在 验证取货 时，将 租赁状态 设为 取货
- 在 验证退货 时，将 数量已退回 设为 数量已退回 + arguments.数量
- 在 验证退货 时，将 实际退货日期 设为 arguments.实际退货日期
- 在 验证退货 时，将 租赁状态 设为 退货
- 在 完成 时，将 租赁状态 设为 已退回
- 在 验证退货 时，副作用
- 在 更新 时，副作用

#### 计算
- 计算字段 数量剩余：浮点，规则 数量已送达 - 数量已退回
- 计算字段 租赁价格：金额，规则 计算租赁价格(自身)
- 计算字段 罚金金额：金额，规则 计算罚金(自身, 实际退货日期)
- 计算字段 延迟：布尔，规则 op=neq，args=实际退货日期、空 且 实际退货日期 > 退货日期
- 计算字段 时长：浮点，规则 日期差异(退货日期, 取货日期, 时长单位)
- 计算字段 可拣：布尔，规则 租赁状态 = 草稿
- 计算字段 可退：布尔，规则 租赁状态 = 取货 且 数量剩余 > 0

#### 工作流
- 流程：rental_order_line_lifecycle：创建 -> 更新 -> 验证取货 -> 验证退货 -> 完成（租赁订单行生命周期）

## 实体：租赁定价（聚合根）

- 说明：租赁定价规则（cheapest-line 算法：遍历所有适用规则，自动选择最便宜方案）
- 来源：基于 产品价格；来源域 ofbiz/product；过滤条件 产品价格类型编号=租赁价格

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 产品模板编号：唯一标识（必填），说明 关联产品模板
- 时长：整数（必填），必须大于 0（时长必须大于零），说明 时长数值（如 1, 7, 30）
- 单位：枚举（必填），可选值：小时 / 天 / 周 / 月 / 年，说明 时间单位
- 价格：金额（必填），必须 ≥ 0（租赁价格不能为负数），说明 该档位的租赁价格
- 币种编号：唯一标识（必填），说明 币种
- 公司编号：唯一标识（必填），说明 所属公司
- 启用：布尔（必填），默认值 是，说明 是否启用
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 产品模板：多对一 -> 产品模板，必填关系
- 价格表：多对一 -> 价格表

### Conduct（行为声明）

#### 操作
- 创建，可写字段：产品模板编号、时长、单位、价格、价格表编号、币种编号、公司编号
- 查询
- 更新，可写字段：时长、单位、价格、价格表编号、启用
- 删除

#### 工作流
- 流程：rental_pricing_maintain_flow：创建 -> 更新 -> 删除（租赁定价规则维护）

## 实体：租赁罚金（聚合根）

- 说明：逾期罚金配置（支持产品级和全局默认，含宽限期和封顶机制）
- 来源：基于 租赁罚金；来源域 租赁

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 产品模板编号：唯一标识，说明 关联产品模板（null 则为全局默认配置）
- 额外小时成本：金额（必填），必须 ≥ 0（每小时逾期费用不能为负数），说明 每小时逾期费用
- 额外天成本：金额（必填），必须 ≥ 0（每天逾期费用不能为负数），说明 每天逾期费用
- 宽限期间工时：浮点（必填），必须 ≥ 0（宽限期不能为负数），说明 宽限期（小时），宽限期内不计罚金
- 最大罚金百分比：浮点，默认值 0，必须 ≥ 0（罚金上限比例不能为负数），说明 罚金上限比例（占租赁总价 %，0 表示无上限）
- 币种编号：唯一标识（必填），说明 币种
- 公司编号：唯一标识（必填），说明 所属公司
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 产品模板：多对一 -> 产品模板

### Conduct（行为声明）

#### 操作
- 创建，可写字段：产品模板编号、额外小时成本、额外天成本、宽限期间工时、最大罚金百分比、币种编号、公司编号
- 查询
- 更新，可写字段：额外小时成本、额外天成本、宽限期间工时、最大罚金百分比
- 删除

#### 工作流
- 流程：rental_penalty_maintain_flow：创建 -> 更新 -> 删除（逾期罚金配置维护）
