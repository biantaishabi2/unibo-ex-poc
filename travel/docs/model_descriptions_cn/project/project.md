- 版本：1.0
- 领域：项目
- 领域说明：项目管理领域模型，涵盖项目、任务、里程碑、任务分配、依赖、工时表、排班
- 实体数量：19

## 实体：项目（聚合根）

- 说明：项目
- 来源：基于 工作任务；来源域 ofbiz/workeffort；过滤条件 工作工作量类型编号=项目

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 项目编码：文本（必填），说明 项目编号
- 名称：文本（必填），说明 项目名称
- 启用：布尔（必填），默认值 是，说明 归档标志
- 隐私可见性：枚举，默认值 门户，可选值：关注者 / 员工 / 门户，说明 可见性设置
- 最近更新状态：枚举，默认值 待定义，可选值：正常 / 风险 / 偏离 / 保留 / 待定义 / 完成，说明 项目状态更新
- 允许任务依赖：布尔，默认值 否，说明 启用任务依赖/阻塞
- 允许里程碑：布尔，默认值 否，说明 启用里程碑
- 允许工时表：布尔，默认值 否，说明 启用工时记录
- 标签任务：文本，默认值 任务，说明 任务标签文本，空字符串时自动重置为 Tasks
- 开始日期：日期，说明 项目开始日期
- 结束日期：日期，说明 项目截止日期
- 颜色：整数，默认值 0，说明 看板颜色索引
- 预算：金额，说明 项目预算
- 说明：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 任务：一对多 -> 任务
- 里程碑：一对多 -> 里程碑
- 经理：多对一 -> 参与方，外键 经理参与方编号
- 类型编号列表：多对多 -> 任务阶段，中间关系 项目任务阶段链接
- 阶段：多对一 -> 项目阶段，必填关系
- 分析科目：多对一 -> 分析科目
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号
- 公司：多对一 -> 参与方，外键 公司参与方编号，必填关系
- 资源日历：多对一 -> 资源日历

#### 唯一约束
- 唯一约束 唯一项目编码：项目编码

### Conduct（行为声明）

#### 操作
- 创建，可写字段：项目编码、名称、开始日期、结束日期、预算、说明、隐私可见性、允许任务依赖、允许里程碑、允许工时表、标签任务、伙伴编号、公司编号、资源日历编号
- 查询
- 更新，可写字段：名称、开始日期、结束日期、预算、说明、隐私可见性、启用、最近更新状态、允许任务依赖、允许里程碑、允许工时表、标签任务、伙伴编号、资源日历编号、颜色
- 开始（类型：更新），说明：启动项目
- 完成（类型：更新），说明：完成项目
- 归档（类型：更新），说明：归档项目
- 取消归档（类型：更新），说明：取消归档
- 复制（类型：创建），说明：复制项目
- 删除，说明：删除项目

#### 校验
- 创建时，项目编码 不能为空
- 创建时，名称 不能为空
- 开始时，只有非完成状态可以启动
- 创建／更新时，company_consistency（项目各阶段、分析账户、合作伙伴的 company_id 必须与项目一致）

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 项目经理、管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=公司 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=公司 时允许

#### 变更
- 在 创建 时，自动分配 阶段编号（首个（项目阶段（条件: 公司编号=公司编号），订单=序列））
- 在 归档 时，cascade_update 启用：否
- 在 取消归档 时，cascade_update 启用：是
- 在 更新 时，取消订阅门户用户
- 在 更新 时，订阅伙伴
- 在 更新 时，同步阶段公司
- 在 更新 时，创建记录
- 在 删除 时，conditional_cascade_delete
- 在 删除 时，cascade_delete
- 在 复制 时，deep_copy，参数 名称后缀= (copy)，preserve_followers=是，recursive_copy=里程碑、任务，maintain_mapping=是
- 在 更新 时，cascade_update 状态：进行中
- 在 创建 / 更新 时，设置默认 标签任务：任务
- 在 创建 时，将 经理 设为当前操作人
- 在 开始 时，将 最近更新状态 设为 正常
- 在 完成 时，将 最近更新状态 设为 完成
- 在 创建 / 更新 / 开始 / 完成 / 归档 / 取消归档 / 复制 / 删除 时，将 编号 设为 编号

#### 事件
- 事件：完成 -> 项目.已完成
- 事件：归档 -> 项目.已归档
- 事件：更新 -> 项目状态更新（条件 最近更新状态 发生变更）

#### 工作流
- 流程：project_lifecycle_flow：创建 -> 更新 -> 开始 -> 完成（项目正常生命周期流程）
- 流程：project_archive_flow：创建 -> 归档 -> 取消归档（项目归档与取消归档流程）
- 流程：project_copy_destroy_flow：创建 -> 复制 -> 删除（项目复制与删除流程）

- 开始日期时间：日期时间（必填），说明 排班开始时间
- 结束日期时间：日期时间（必填），说明 排班结束时间
- 已分配工时：金额，说明 基于 start/end 和员工工作日历自动计算的工时
- 状态：枚举，默认值 草稿，可选值：草稿 / 已发布，说明 排班状态
- 允许重叠：布尔，默认值 否，说明 是否允许时段重叠
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 员工：多对一 -> 员工，必填关系
- 项目：多对一 -> 项目
- 角色：多对一 -> 排班角色
- 重复周期：多对一 -> 排班周期
- 模板：多对一 -> 排班时段模板

### Conduct（行为声明）

#### 操作
- 创建，可写字段：开始日期时间、结束日期时间、允许重叠，参数：员工编号：唯一标识（必填）；项目编号：唯一标识；角色编号：唯一标识
- 查询
- 更新，可写字段：开始日期时间、结束日期时间、状态、允许重叠、项目编号、角色编号
- 发布（类型：更新），说明：发布排班
- 创建来源模板（类型：创建），说明：从模板快速创建排班，参数：模板编号：唯一标识（必填）

#### 校验
- 创建／更新时，结束日期时间 必须大于 开始日期时间（排班结束时间必须晚于开始时间）
- 创建／更新时，无重叠（同一员工在同一时段不能有重叠排班）

#### 变更
- 在 创建 / 更新 时，计算 已分配工时（资源日历获取工作时长(开始日期时间, 结束日期时间)）
- 在 创建 / 更新 时，associate
- 在 发布 / 更新 时，发送通知
- 在 创建 时，generate_recurrence
- 在 创建来源模板 时，复制来源模板
- 在 发布 时，将 状态 设为 已发布
- 在 创建 / 更新 / 发布 / 创建来源模板 时，将 编号 设为 编号

#### 工作流
- 流程：planning_slot_lifecycle_flow：创建 -> 更新 -> 发布（排班正常流转流程）
- 流程：planning_slot_template_flow：创建来源模板（从模板创建排班流程）
