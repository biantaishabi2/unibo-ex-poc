# 模型业务说明

- 版本：1.0
- 领域：制造
- 领域说明：生产制造领域模型，涵盖 BOM、生产工单、工序、工作中心、工艺路线、MRP 排程
- 实体数量：14

## 实体：物料清单（聚合根）

- 说明：物料清单
- 来源：基于 产品关联；来源域 ofbiz/product；过滤条件 产品关联类型编号=MANUF_COMPONENT

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- BOM编码：文本（必填），说明 BOM 编号
- 产品模板编号：唯一标识（必填），说明 产品模板 ID
- 产品编号：唯一标识，说明 特定变体 ID（可空，空=适用全部变体）
- 产品名称：文本（必填），说明 成品名称
- 产品编码：文本（必填），说明 成品编号
- 产品数量：金额（必填），默认值 1.0，必须大于 0（BOM 基准产出数量必须大于零），说明 BOM 基准产出数量
- 产品单位编号：唯一标识（必填），说明 BOM 产出单位
- 类型：枚举，默认值 正常，可选值：正常 / 虚拟，说明 BOM 类型（normal=标准生产，phantom=套件/虚拟件）
- 消耗：枚举，默认值 灵活，可选值：灵活 / 警告 / 严格，说明 消耗模式（flexible=不限制，warning=提示，strict=精确匹配）
- 序列：整数，默认值 1，说明 排序优先级
- 版本：文本，默认值 1.0，说明 BOM 版本
- 状态：枚举，默认值 草稿，可选值：草稿 / 启用 / 已淘汰
- 启用：布尔，默认值 是，说明 是否启用
- 公司编号：唯一标识，说明 所属公司
- 说明：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 明细行：一对多 -> BOM行，外键 BOM编号，管理模式 直接管理
- 副产品：一对多 -> BOM副产品，外键 BOM编号，管理模式 直接管理
- 操作：一对多 -> 工艺路线操作，外键 BOM编号，管理模式 直接管理
- 公司：多对一 -> 参与方，外键 公司编号

#### 唯一约束
- 唯一约束 唯一BOM编码：BOM编码

### Conduct（行为声明）

#### 操作
- 创建，可写字段：BOM编码、产品模板编号、产品编号、产品名称、产品编码、产品数量、产品单位编号、类型、消耗、序列、版本、说明、公司编号，参数：明细行：列表（必填）；副产品：列表
- 查询
- 更新，可写字段：产品数量、产品单位编号、类型、消耗、版本、说明、状态、启用
- 启用（类型：更新），说明：激活 BOM
- 已淘汰（类型：更新），说明：废弃 BOM
- 展开（类型：查询），说明：BOM 展开（递归展开 phantom 套件，返回叶子节点组件列表），参数：数量：金额（必填）；产品编号：唯一标识

#### 校验
- 创建时，BOM编码 不能为空
- 启用时，只有草稿状态可以激活
- 已淘汰时，只有激活状态可以废弃

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 制造经理、管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=公司 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=公司 时允许

#### 变更
- 在 启用 时，将 状态 设为 启用
- 在 已淘汰 时，将 状态 设为 已淘汰
- 在 创建 / 更新 / 启用 / 已淘汰 时，将 编号 设为 编号

#### 计算
- 计算字段 展开结果：文本，表达式 BOM编码
- 计算字段 BOM查找优先级：整数，表达式 序列

#### 工作流
- 流程：bom_lifecycle_flow：创建 -> 更新 -> 启用 -> 已淘汰（BOM 创建、维护、激活与废弃流程）

- 在 确认 时，cross_module_call
- 在 确认 时，cross_module_call
