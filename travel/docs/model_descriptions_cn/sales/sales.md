# 模型业务说明

- 版本：1.0
- 领域：销售
- 领域说明：销售管理领域模型，涵盖客户、报价、销售订单、退货
- 实体数量：15

## 实体：客户（聚合根）

- 说明：客户主数据（对应 OFBiz PartyGroup + PartyRole CUSTOMER）
- 来源：基于 参与方分组；来源域 ofbiz/party；关联 参与方角色（角色类型编号=客户）

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 客户编码：文本（必填），说明 客户编号
- 名称：文本（必填），说明 客户名称
- 状态：枚举，默认值 启用，可选值：启用 / 停用 / 冻结
- 客户类型：枚举，默认值 公司，可选值：个人 / 公司
- 联系人：文本
- 联系电话：文本
- 联系邮箱：文本
- 账单地址：长文本
- 发货地址：长文本
- 贷方限制：金额，说明 信用额度
- 付款条件：文本，说明 付款条件
- 税号：文本
- 备注：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 销售订单：一对多 -> 销售订单
- 报价：一对多 -> 报价
- 公司参与方：多对一 -> 参与方，外键 公司参与方编号，必填关系

#### 唯一约束
- 唯一约束 唯一客户编码：客户编码

### Conduct（行为声明）

#### 操作
- 创建，可写字段：客户编码、名称、客户类型、联系人、联系电话、联系邮箱、账单地址、发货地址、贷方限制、付款条件、税号、备注
- 查询
- 列表（类型：查询），说明：列表查询
- 搜索（类型：查询），说明：条件检索
- 获取（类型：查询），说明：详情查询
- 预览（类型：查询），说明：预览查询
- 计算（类型：查询），说明：计算查询
- lookup（类型：查询），说明：快速检索
- 更新，可写字段：名称、联系人、联系电话、联系邮箱、账单地址、发货地址、贷方限制、付款条件、税号、备注、状态
- 冻结（类型：更新），说明：冻结客户

#### 校验
- 创建时，客户编码 不能为空
- 创建时，名称 不能为空
- 更新时，名称 不能为空
- 冻结时，只有活跃状态可以冻结

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 销售代表、管理员 时允许

#### 变更
- 在 冻结 时，将 状态 设为 冻结
- 在 创建 / 更新 / 冻结 时，将 编号 设为 编号

#### 工作流
- 流程：customer_lifecycle：创建 -> 更新 -> 冻结（客户管理流程）

## 实体：报价（聚合根）

- 说明：销售报价单
- 来源：基于 报价；来源域 ofbiz/order

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 报价单号：文本（必填），说明 报价单号
- 状态：枚举，默认值 草稿，可选值：草稿 / 已提交 / 已接受 / 已驳回 / 已过期
- 报价日期：日期（必填）
- 有效至日期：日期，说明 有效期至
- 合计金额：金额，说明 报价总金额
- 币种：文本，默认值 CNY
- 说明：长文本
- 备注：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 项目：一对多 -> 报价项，管理模式 直接管理
- 客户：多对一 -> 客户，必填关系
- 创建人：多对一 -> 参与方，外键 创建参与方编号
- 公司参与方：多对一 -> 参与方，外键 公司参与方编号，必填关系

#### 唯一约束
- 唯一约束 唯一报价单号：报价单号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：报价单号、报价日期、有效至日期、币种、说明、备注，参数：项目：列表（必填）；客户编号：唯一标识（必填）
- 查询
- 列表（类型：查询），说明：列表查询
- 搜索（类型：查询），说明：条件检索
- 获取（类型：查询），说明：详情查询
- 预览（类型：查询），说明：预览查询
- 计算（类型：查询），说明：计算查询
- lookup（类型：查询），说明：快速检索
- 提交（类型：更新），说明：发送报价
- 接受（类型：更新），说明：客户接受报价
- 驳回（类型：更新），说明：客户拒绝报价

#### 校验
- 创建时，报价单号 不能为空
- 提交时，只有草稿状态可以发送
- 接受时，只有已发送状态可以接受
- 驳回时，只有已发送状态可以拒绝

#### 变更
- 在 创建 时，将 创建人 设为当前操作人
- 在 创建 时，将 合计金额 设为 合计(项目.行金额)
- 在 提交 时，将 状态 设为 已提交
- 在 接受 时，将 状态 设为 已接受
- 在 驳回 时，将 状态 设为 已驳回
- 在 创建 / 提交 / 接受 / 驳回 时，将 编号 设为 编号

#### 事件
- 事件：提交 -> 销售.报价.已提交
- 事件：接受 -> 销售.报价.已接受

#### 工作流
- 流程：quote_lifecycle：创建 -> 提交 -> 接受 -> 驳回（报价单生命周期）

## 实体：报价项

- 说明：报价单明细行（对齐 OFBiz QuoteItem）
- 来源：基于 报价项；来源域 ofbiz/order

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 数量：金额（必填），必须大于 0（数量必须大于零），说明 数量（对齐 OFBiz quantity，类型从 integer 改为 decimal）
- 报价单位价格：金额（必填），必须 ≥ 0，说明 报价单价（对齐 OFBiz quote_unit_price）
- 预估配送日期：日期时间，说明 预计交付日（对齐 OFBiz estimated_delivery_date）
- 评论：长文本，说明 备注（对齐 OFBiz comments）
- 序列编号：整数，说明 行序号（对齐 OFBiz quote_item_seq_id）
- 促销：布尔，默认值 否，说明 是否促销项（对齐 OFBiz is_promo）
- 线索时间天数：整数，说明 交付提前期天数（对齐 OFBiz lead_time_days）
- 产品名称：文本（必填），说明 产品名称（业务扩展，OFBiz 通过 product_id 关联）
- 产品编码：文本，说明 产品编码（业务扩展）
- 行金额：金额（必填），说明 行金额（computed = quantity * quote_unit_price）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 报价：多对一 -> 报价，必填关系

### Conduct（行为声明）

#### 操作
- 创建，可写字段：产品名称、产品编码、数量、报价单位价格、评论、预估配送日期、序列编号、促销、线索时间天数
- 更新，可写字段：数量、报价单位价格、评论、预估配送日期、序列编号、促销、线索时间天数

#### 变更
- 在 创建 / 更新 时，将 行金额 设为 数量 × 报价单位价格
- 在 创建 / 更新 时，将 编号 设为 编号

#### 工作流
- 流程：quote_item_editing：创建 -> 更新（报价明细编辑流程）

## 实体：销售订单（聚合根）

- 说明：销售订单（状态机对齐 Odoo：draft → sent → sale → done → cancel）
- 来源：基于 订单表头；来源域 ofbiz/order；过滤条件 订单类型编号=销售订单；关联 订单角色（角色类型编号=客户）

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 订单编号（自动生成序列号）
- 状态：枚举，默认值 草稿，可选值：草稿 / 已发送 / 销售 / 完成 / 取消，说明 订单状态（Odoo 状态机）
- 锁定：布尔，默认值 否，说明 锁定标记，sale 状态下 action_done 时置 true
- 日期订单：日期时间（必填），默认值 当前时间，说明 订单日期
- 承诺配送日期：日期，说明 承诺交付日期
- 金额未税：金额，说明 未税金额（所有行 price_subtotal 之和）
- 税额：金额，说明 税额合计（所有行 price_tax 之和）
- 金额合计：金额，说明 订单总金额（amount_untaxed + amount_tax）
- 发票状态：枚举，可选值：无 / 待开票 / 已开票 / 追加销售，说明 开票状态（聚合自订单行）
- 币种：文本，默认值 CNY，说明 币种
- 付款条件：文本，说明 付款条件
- 发货地址：长文本，说明 送货地址
- 备注：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 项目：一对多 -> 销售订单项，外键 订单编号，管理模式 直接管理
- 客户：多对一 -> 客户，必填关系
- 发货伙伴：多对一 -> 客户，必填关系
- 创建人：多对一 -> 参与方，外键 创建参与方编号
- 公司参与方：多对一 -> 参与方，外键 公司参与方编号，必填关系
- 发货：一对多 -> 销售订单发货
- 退货：一对多 -> 退货
- source_cross_org_transactions：一对多 -> CrossOrgTransaction，外键 来源销售订单编号

#### 唯一约束
- 唯一约束 唯一订单名称：名称

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、日期订单、承诺配送日期、付款条件、发货地址、币种、备注，参数：项目：列表（必填）；客户编号：唯一标识（必填）
- 查询
- 列表（类型：查询），说明：列表查询
- 搜索（类型：查询），说明：条件检索
- 获取（类型：查询），说明：详情查询
- 预览（类型：查询），说明：预览查询
- 计算（类型：查询），说明：计算查询
- lookup（类型：查询），说明：快速检索
- 操作报价单发送（类型：更新），说明：发送报价（draft → sent）
- 确认操作（类型：更新），说明：确认订单（draft/sent → sale）
- 完成操作（类型：更新），说明：锁定订单（sale → done/locked）
- 操作取消（类型：更新），说明：取消订单（any → cancel，locked==false 时可执行）
- 操作草稿（类型：更新），说明：重置为草稿（cancel → draft）
- 创建发票（类型：自定义规则），说明：手动创建发票（state == sale 时可执行），参数：最终：布尔

#### 校验
- 创建时，项目 不能为空（创建销售订单时必须包含至少一条订单行）
- 创建时，创建销售订单时必须选择客户
- 操作报价单发送时，只有草稿状态可以发送报价
- 确认操作时，只有草稿或已发送状态可以确认
- 确认操作时，项目 不能为空（订单行不能为空）
- 确认操作时，税务配置校验失败
- 确认操作时，分析分配校验失败
- 完成操作时，只有已确认(sale)状态可以锁定
- 操作取消时，锁定 必须等于 否（已锁定的订单不能取消）
- 操作草稿时，只有已取消状态可以重置为草稿
- 创建发票时，只能对已确认订单创建发票
- 创建发票时，至少有一行的待开票数量大于0

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 销售代表、管理员 时允许

#### 变更
- 在 创建 时，将 创建人 设为当前操作人
- 在 操作报价单发送 时，将 状态 设为 已发送
- 在 确认操作 时，将 状态 设为 销售
- 在 确认操作 时，将 日期订单 设为 now()
- 在 确认操作 时，创建关联
- 在 确认操作 时，订阅伙伴 客户
- 在 确认操作 时，将 锁定 设为 是
- 在 完成操作 时，将 状态 设为 完成
- 在 完成操作 时，将 锁定 设为 是
- 在 操作取消 时，取消关联
- 在 操作取消 时，取消关联
- 在 操作取消 时，将 状态 设为 取消
- 在 操作草稿 时，将 状态 设为 草稿
- 在 创建发票 时，创建关联
- 在 创建发票 时，最终发票且金额为负时转为贷项通知单
- 在 创建 / 操作报价单发送 / 确认操作 / 完成操作 / 操作取消 / 操作草稿 / 创建发票 时，将 编号 设为 编号

#### 计算
- 计算字段 金额未税：金额，规则 合计(项目.价格小计)
- 计算字段 税额：金额，规则 合计(项目.价格税)
- 计算字段 金额合计：金额，规则 金额未税 + 税额
- 计算字段 发票状态：枚举，规则 op=aggregate，来源=项目.发票状态，规则=当=全部等于 已开票，then=已开票、当=op=任意等于，args=待开票，then=待开票、当=op=任意等于，args=追加销售，then=追加销售、otherwise=无
- 计算字段 项数量：整数，规则 数量(项目)

#### 聚合
- 聚合 合计项目：数量（关系 项目，字段 无）
- 聚合 合计数量：合计（关系 项目，字段 数量）

#### 事件
- 事件：操作报价单发送 -> 销售.订单.已发送
- 事件：确认操作 -> 销售.订单.已确认
- 事件：完成操作 -> 销售.订单.完成
- 事件：操作取消 -> 销售.订单.已取消
- 事件：操作草稿 -> 销售订单重置草稿
- 事件：创建发票 -> 销售订单发票创建

#### 工作流
- 流程：sales_order_lifecycle_flow：创建 -> 操作报价单发送 -> 确认操作 -> 创建发票 -> 完成操作（销售订单业务流程）
- 流程：sales_order_reopen_flow：操作取消 -> 操作草稿 -> 确认操作（取消后重启订单流程）
- 流程：pricing_chain：选择产品价格 -> 计算行小计 -> 计算税 -> 汇总合计（定价链路）

## 实体：销售订单项

- 说明：销售订单明细（对齐 OFBiz OrderItem）
- 来源：基于 订单项；来源域 ofbiz/order；过滤条件 订单项类型编号=销售项

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 订单项类型编号：文本，说明 行类型（对齐 OFBiz order_item_type_id，替代 Odoo display_type）
- 序列编号：整数，说明 行序号（对齐 OFBiz order_item_seq_id）
- 项说明：文本（必填），说明 行描述（对齐 OFBiz item_description）
- 数量：金额（必填），默认值 1，说明 订购数量（对齐 OFBiz quantity）
- 取消数量：金额，说明 取消数量（对齐 OFBiz cancel_quantity）
- 单价：金额（必填），必须 ≥ 0，说明 成交单价（对齐 OFBiz unit_price）
- 单位列表价格：金额，说明 目录/标牌价（对齐 OFBiz unit_list_price）
- 折扣费率：金额，默认值 0，必须 ≥ 0，必须 ≤ 100（折扣百分比不能超过100），说明 折扣率（对齐 OFBiz discount_rate，0-100）
- 状态编号：文本，说明 行状态（对齐 OFBiz status_id）
- 预估配送日期：日期时间，说明 预计交货日（对齐 OFBiz estimated_delivery_date）
- 评论：文本，说明 备注（对齐 OFBiz comments）
- 促销：布尔，默认值 否，说明 是否促销项（对齐 OFBiz is_promo）
- 对应采购订单编号：文本，说明 对应采购单（对齐 OFBiz corresponding_po_id）
- 产品名称：文本，说明 产品名称（业务扩展）
- 产品编码：文本，说明 产品编码（业务扩展）
- 数量已送达：金额，默认值 0，说明 已发货数量（业务扩展）
- 数量已开票：金额，默认值 0，说明 已开票数量（computed）
- 数量发票：金额，说明 待开票数量（computed）
- 价格小计：金额，说明 税前小计（computed）
- 价格税：金额，说明 税额（computed）
- 价格合计：金额，说明 含税合计（computed）
- 发票状态：枚举，可选值：无 / 待开票 / 已开票 / 追加销售，说明 行级开票状态（业务扩展）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 订单：多对一 -> 销售订单，必填关系
- 产品：多对一 -> 产品，必填关系
- 税编号列表：多对多 -> 税，中间关系 SalesOrderItemTaxRel

### Conduct（行为声明）

#### 操作
- 创建，可写字段：项说明、产品名称、产品编码、数量、单价、折扣费率、订单项类型编号、序列编号、预估配送日期、评论、状态编号、促销
- 更新，可写字段：数量、单价、折扣费率、预估配送日期、评论、状态编号

#### 校验
- 创建／更新时，数量 必须大于 0（订购数量必须大于零）
- 更新时，产品 immutable（已确认订单中已有发票或已发货的行不可修改产品）
- 更新时，单价 immutable（已锁定订单的价格、数量、折扣、税率均不可修改），前提：订单.锁定 = 是
- 删除时，已确认的非预付款订单行不可删除
