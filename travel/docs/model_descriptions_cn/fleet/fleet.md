# 模型业务说明

- 版本：1.0
- 领域：Fleet
- 领域说明：车队管理领域模型，涵盖车辆主数据、车辆类型、驾驶员、车辆分配、服务记录、合同管理
- 实体数量：8

## 实体：FleetVehicle（聚合根）

- 说明：车队车辆主数据，来源于 OFBiz FixedAsset，过滤类型为 FLEET_VEHICLE（区别于 Maintenance 域的 VEHICLE）
- 来源：基于 固定资产；来源域 ofbiz/accounting；过滤条件 固定资产类型编号=FLEET_VEHICLE

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 车辆名称（对齐 FixedAsset.fixed_asset_name）
- 车架号：文本，说明 车架号（对齐 FixedAsset.serial_number）
- 采购日期：日期，说明 购置日期（对齐 FixedAsset.date_acquired）
- 最近服务日期：日期时间，说明 最近一次保养日期（对齐 FixedAsset.date_last_serviced）
- 下一个服务日期：日期时间，说明 下次保养计划日期（对齐 FixedAsset.date_next_service）
- 预计报废日期（对齐 FixedAsset.expected_end_of_life）（decommission_date）：日期
- 收购成本：金额，说明 购置成本（对齐 FixedAsset.purchase_cost）
- 停放车库/设施（对齐 FixedAsset.located_at_facility_id）（garage_id）：文本
- 许可证车牌：文本（必填），说明 车牌号
- 品牌：文本，说明 品牌（Toyota、BYD 等）
- 模型名称：文本，说明 型号（Corolla、Han 等）
- 模型年：整数，说明 出厂年份
- 里程：金额，默认值 0，说明 当前里程（km）
- 燃料类型：枚举，可选值：汽油 / 柴油 / 电动 / 混合 / CNG，说明 燃料类型
- 颜色：文本，说明 车身颜色
- 席位：整数，说明 座位数
- 状态：枚举，默认值 可用，可选值：可用 / 包含使用 / 维护 / 已退休，说明 车辆状态
- 最近里程更新：日期时间，说明 里程更新时间
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 车辆类型：多对一 -> FleetVehicleType
- 分配：一对多 -> 车辆分配，外键 fleet_vehicle_id
- 服务：一对多 -> 车辆服务，外键 fleet_vehicle_id
- 合同：一对多 -> 车辆合同，外键 fleet_vehicle_id

#### 唯一约束
- 唯一约束 唯一许可证车牌：许可证车牌
- 唯一约束 唯一车架号：车架号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、许可证车牌、品牌、模型名称、模型年、车架号、采购日期、收购成本、燃料类型、颜色、席位、里程、garage_id、fleet_vehicle_type_id
- 查询
- 更新，可写字段：名称、许可证车牌、品牌、模型名称、模型年、里程、燃料类型、颜色、席位、状态、garage_id、最近里程更新、下一个服务日期、fleet_vehicle_type_id
- decommission（类型：更新），说明：报废/停用车辆，可写字段：decommission_date

#### 校验
- 创建时，许可证车牌 不能为空
- 创建时，名称 不能为空
- decommission时，只有非报废状态的车辆可以报废

#### 变更
- 在 decommission 时，将 状态 设为 已退休
- 在 创建 / 更新 / decommission 时，将 编号 设为 编号

#### 计算
- 计算字段 逾期服务：布尔，规则 过去(下一个服务日期)
- 计算字段 合计服务成本：金额
- 计算字段 天数直到下一个服务：整数，规则 日期差异天数(下一个服务日期, 当前时间)

#### 事件
- 事件：decommission -> fleet.车辆.decommissioned

#### 工作流
- 流程：fleet_vehicle_lifecycle：创建 -> 更新 -> decommission（车队车辆生命周期）

- 来源：基于 参与方角色；来源域 ofbiz/party；过滤条件 角色类型编号=驱动

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 驾驶员姓名
- 许可证单号：文本（必填），说明 驾驶证号
- 许可证类型：枚举，可选值：A1 / A2 / A3 / B1 / B2 / C1 / C2 / C3 / D / E，说明 驾照类型
- 许可证过期日期：日期，说明 驾驶证有效期
- 电话：文本，说明 联系电话
- 状态：枚举，默认值 启用，可选值：启用 / 停用，说明 驾驶员状态
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 参与方：多对一 -> 参与方，外键 参与方编号
- 员工：多对一 -> 人力员工
- 分配：一对多 -> 车辆分配，外键 驱动编号

#### 唯一约束
- 唯一约束 唯一许可证单号：许可证单号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、许可证单号、许可证类型、许可证过期日期、电话、人力员工编号
- 查询
- 更新，可写字段：名称、许可证单号、许可证类型、许可证过期日期、电话、状态、人力员工编号
- 停用（类型：更新），说明：停用驾驶员

#### 校验
- 创建时，名称 不能为空
- 创建时，许可证单号 不能为空
- 停用时，只有在职驾驶员可以停用

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 fleet_manager、管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=参与方 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=参与方 时允许

#### 变更
- 在 停用 时，将 状态 设为 停用
- 在 创建 / 更新 / 停用 时，将 编号 设为 编号

#### 计算
- 计算字段 许可证已过期：布尔，规则 过去(许可证过期日期)

#### 工作流
- 流程：driver_lifecycle：创建 -> 更新 -> 停用（驾驶员生命周期）

## 实体：车辆分配（聚合根）

- 说明：车辆分配记录，记录谁用哪辆车、时间段

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 来源日期：日期（必填），说明 分配开始日期
- 日期：日期，说明 分配结束日期
- 状态：枚举，默认值 启用，可选值：启用 / 已退回 / transferred，说明 分配状态
- 备注：长文本，说明 备注
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- fleet_vehicle：多对一 -> FleetVehicle，必填关系
- 驱动：多对一 -> 驱动，必填关系

### Conduct（行为声明）

#### 操作
- 分配（类型：创建），说明：分配车辆给驾驶员，可写字段：fleet_vehicle_id、驱动编号、来源日期、备注
- 查询
- 退货（类型：更新），说明：归还车辆，可写字段：日期、备注
- 转账（类型：更新），说明：转移车辆给其他驾驶员，可写字段：驱动编号、备注

#### 校验
- 分配时，fleet_vehicle_id 不能为空
- 分配时，驱动编号 不能为空
- 分配时，来源日期 不能为空
- 分配时，该车辆已分配给其他驾驶员
- 退货／转账时，只有活跃的分配可以归还或转移

#### 变更
- 在 分配 时，将 状态 设为 启用
- 在 分配 时，设置关联 状态：包含使用
- 在 退货 时，将 状态 设为 已退回
- 在 退货 时，设置关联 状态：可用
- 在 转账 时，将 状态 设为 transferred
- 在 分配 / 退货 / 转账 时，将 编号 设为 编号

#### 事件
- 事件：分配 -> fleet.车辆.已分配

#### 工作流
- 流程：vehicle_assignment_flow：分配 -> 退货 -> 转账（车辆分配流程）

## 实体：车辆服务（聚合根）

- 说明：车辆服务记录（保养/维修/年检），来源于 OFBiz FixedAssetMaint
- 来源：基于 固定资产维护；来源域 ofbiz/accounting

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 服务类型：枚举（必填），可选值：维护 / 维修 / inspection / 其他，说明 服务类型（对应 product_maint_type_id）
- 状态：枚举，默认值 已排期，可选值：已排期 / 进行中 / 已完成 / 已取消，说明 服务状态
- 已排期日期：日期时间（必填），说明 计划日期（对应 schedule_work_effort）
- 已完成日期：日期时间，说明 完成日期
- 里程服务：金额，说明 服务时里程数
- 间隔数量：金额，说明 保养间隔数量（如每 5000 公里）
- 间隔单位编号：文本，说明 间隔单位（km / month）
- 成本：金额，说明 服务费用
- 供应商：文本，说明 服务供应商
- 备注：长文本，说明 备注
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- fleet_vehicle：多对一 -> FleetVehicle，必填关系

### Conduct（行为声明）

#### 操作
- 排班（类型：创建），说明：预约服务，可写字段：fleet_vehicle_id、服务类型、已排期日期、里程服务、间隔数量、间隔单位编号、供应商、备注
- 查询
- 开始（类型：更新），说明：开始服务（scheduled -> in_progress），可写字段：备注
- 完成（类型：更新），说明：完成服务，可写字段：已完成日期、里程服务、成本、备注
- 取消（类型：更新），说明：取消服务，可写字段：备注

#### 校验
- 排班时，fleet_vehicle_id 不能为空
- 排班时，服务类型 不能为空
- 排班时，已排期日期 不能为空
- 开始时，只有已预约的服务可以开始
- 完成时，只有已预约或进行中的服务可以完成
- 取消时，只有已预约的服务可以取消

#### 变更
- 在 开始 时，将 状态 设为 进行中
- 在 完成 时，将 状态 设为 已完成
- 在 完成 时，设置关联 最近服务日期（已完成日期）
- 在 取消 时，将 状态 设为 已取消
- 在 排班 / 开始 / 完成 / 取消 时，将 编号 设为 编号

#### 事件
- 事件：完成 -> fleet.服务.已完成

#### 工作流
- 流程：vehicle_service_flow：排班 -> 开始 -> 完成 -> 取消（车辆服务流程）

## 实体：车辆合同（聚合根）

- 说明：车辆合同（租赁、保险等）

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 合同类型：枚举（必填），可选值：lease / insurance / 维护计划 / 其他，说明 合同类型
- 状态：枚举，默认值 草稿，可选值：草稿 / 启用 / 已过期 / 已终止，说明 合同状态
- 开始日期：日期（必填），说明 合同开始日期
- 结束日期：日期，说明 合同结束日期
- 供应商：文本，说明 合同供应商/保险公司
- 合同单号：文本，说明 合同编号
- 金额：金额，说明 合同金额
- 周期性成本：金额，说明 周期费用（月租/年费等）
- 周期性期间：枚举，可选值：月度 / 季度 / 年度，说明 周期类型
- 备注：长文本，说明 备注
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- fleet_vehicle：多对一 -> FleetVehicle，必填关系

### Conduct（行为声明）

#### 操作
- 创建，可写字段：fleet_vehicle_id、合同类型、开始日期、结束日期、供应商、合同单号、金额、周期性成本、周期性期间、备注
- 查询
- 启用（类型：更新），说明：激活合同（draft -> active）
- renew（类型：更新），说明：续签合同（active/expired -> active，更新结束日期和金额），可写字段：结束日期、金额、周期性成本、备注
- 终止（类型：更新），说明：终止合同，可写字段：备注

#### 校验
- 创建时，fleet_vehicle_id 不能为空
- 创建时，合同类型 不能为空
- 创建时，开始日期 不能为空
- 启用时，只有草稿状态的合同可以激活
- renew时，只有生效中或已过期的合同可以续签
- 终止时，只有草稿或生效中的合同可以终止

#### 变更
- 在 启用 时，将 状态 设为 启用
- 在 renew 时，将 状态 设为 启用
- 在 终止 时，将 状态 设为 已终止
- 在 创建 / 启用 / renew / 终止 时，将 编号 设为 编号

#### 计算
- 计算字段 已过期：布尔，规则 过去(结束日期)
- 计算字段 合计成本：金额，规则 计算合同合计成本(金额, 周期性成本, 周期性期间, 开始日期, 结束日期)

#### 事件
- 事件：终止 -> fleet.合同.已终止
- 事件：renew -> fleet.合同.renewed

#### 工作流
- 流程：vehicle_contract_flow：创建 -> 启用 -> renew -> 终止（车辆合同流程）
