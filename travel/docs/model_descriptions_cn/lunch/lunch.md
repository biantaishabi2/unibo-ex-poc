# 模型业务说明

- 版本：1.0
- 领域：午餐
- 领域说明：午餐管理领域模型，涵盖午餐订单、供应商、菜品、配料、资金流水
- 实体数量：12

## 实体：午餐供应商（聚合根）

- 说明：午餐供应商，管理营业时间、配送方式、配料分类定义
- 来源：基于 午餐供应商；来源域 午餐

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 供应商名称（来自关联partner）
- 发送：枚举（必填），可选值：电话 / 邮箱，说明 订单发送方式
- 自动邮箱时间：浮点，最小值 0，最大值 12，说明 自动邮件发送时间（0-12，小时制）
- 时刻：枚举，可选值：上午 / 下午，说明 上午/下午标识
- 时区：文本，说明 时区（用于定时任务计算）
- 周一：布尔，默认值 否，说明 周一营业
- 周二：布尔，默认值 否，说明 周二营业
- 周三：布尔，默认值 否，说明 周三营业
- 周四：布尔，默认值 否，说明 周四营业
- 周五：布尔，默认值 否，说明 周五营业
- 周六：布尔，默认值 否，说明 周六营业
- 周日：布尔，默认值 否，说明 周日营业
- 重复周期结束日期：日期，说明 可用性截止日期
- 第1类配料标签：文本，说明 第1类配料分类标签
- 第1类配料数量：枚举，默认值 零个或多个，可选值：零个或多个 / 一个或多个 / 仅一个，说明 第1类配料数量约束
- 第2类配料标签：文本，说明 第2类配料分类标签
- 第2类配料数量：枚举，默认值 零个或多个，可选值：零个或多个 / 一个或多个 / 仅一个，说明 第2类配料数量约束
- 第3类配料标签：文本，说明 第3类配料分类标签
- 第3类配料数量：枚举，默认值 零个或多个，可选值：零个或多个 / 一个或多个 / 仅一个，说明 第3类配料数量约束
- 启用：布尔，默认值 是，说明 是否启用
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号，必填关系
- 负责人：多对一 -> 参与方，外键 负责人参与方编号
- 产品：一对多 -> 午餐产品，外键 供应商编号
- 配料：一对多 -> 午餐配料，外键 供应商编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、发送、自动邮箱时间、时刻、时区、周一、周二、周三、周四、周五、周六、周日、重复周期结束日期、第1类配料标签、第1类配料数量、第2类配料标签、第2类配料数量、第3类配料标签、第3类配料数量，参数：伙伴编号：唯一标识（必填）
- 查询
- 更新，可写字段：名称、发送、自动邮箱时间、时刻、时区、周一、周二、周三、周四、周五、周六、周日、重复周期结束日期、第1类配料标签、第1类配料数量、第2类配料标签、第2类配料数量、第3类配料标签、第3类配料数量
- 发送订单（类型：更新），说明：批量发送当日订单给供应商（邮件方式调用自动邮件；电话方式逐条标记sent）
- 确认订单（类型：更新），说明：批量确认当日所有sent状态订单
- 归档（类型：更新），说明：归档供应商（级联归档所有关联产品）
- 取消归档（类型：更新），说明：取消归档供应商

#### 校验
- 创建时，名称 不能为空
- 创建时，发送 不能为空
- 归档时，只有启用状态的供应商可以归档
- 取消归档时，只有已归档状态的供应商可以取消归档

#### 变更
- 在 归档 时，将 启用 设为 否
- 在 取消归档 时，将 启用 设为 是
- 在 归档 时，cascade_archive
- 在 创建 / 更新 / 发送订单 / 确认订单 / 归档 / 取消归档 时，将 编号 设为 编号

#### 计算
- 计算字段 可用今日：布尔，规则 可用日期(今日)
- 计算字段 订单截止日已通过：布尔，规则 截止日已通过(自动邮箱时间, 时刻, 时区)
- 计算字段 显示订单按钮：布尔
- 计算字段 显示确认按钮：布尔

#### 事件
- 事件：发送订单 -> 午餐供应商订单已发送
- 事件：确认订单 -> 午餐供应商订单已确认

#### 工作流
- 流程：supplier_lifecycle：创建 -> 更新 -> 发送订单 -> 确认订单 -> 归档 -> 取消归档（供应商生命周期（创建→运营→归档））

#### 计算
- 计算字段 新：布尔，规则 新直到 ≥ 今日
- 计算字段 收藏：布尔
- 计算字段 最近订单日期：日期
- 计算字段 产品图片：二进制，规则 coalesce（图片，分类.图片）

#### 工作流
- 流程：product_management：创建 -> 更新 -> 切换收藏 -> 删除（菜品管理流程）

## 实体：午餐订单（聚合根）

- 说明：午餐订单行，支持购物车合并、配料选择、钱包预检
- 来源：基于 午餐订单；来源域 午餐

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 数量：整数（必填），默认值 1，必须 ≥ 0（数量不能为负数），说明 数量，降至0时自动停用
- 日期：日期（必填），默认值 今日，说明 订单日期
- 备注：长文本，说明 备注
- 状态：枚举（必填），默认值 新，可选值：新 / 已排序 / 已发送 / 已确认 / 已取消，说明 订单状态
- 启用：布尔，默认值 是，说明 是否活跃（quantity降至0时设为false）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 产品：多对一 -> 午餐产品，必填关系
- 用户：多对一 -> 参与方，外键 用户参与方编号，必填关系
- 午餐位置：多对一 -> 午餐位置
- 加料组1：多对多 -> 午餐配料，中间关系 LunchOrderTopping1Link
- 加料组2：多对多 -> 午餐配料，中间关系 LunchOrderTopping2Link
- 加料组3：多对多 -> 午餐配料，中间关系 LunchOrderTopping3Link

### Conduct（行为声明）

#### 操作
- 创建，可写字段：数量、日期、备注，参数：产品编号：唯一标识（必填）；午餐位置编号：唯一标识；加料组1：列表；加料组2：列表；加料组3：列表
- 查询
- 更新数量（类型：更新），说明：更新数量（降至0时自动停用并触发钱包校验），可写字段：数量
- 操作订单（类型：更新），说明：下单（new → ordered），校验supplier可用性和产品active状态
- 操作发送（类型：更新），说明：发送给供应商（ordered → sent）
- 确认操作（类型：更新），说明：供应商确认交付（sent → confirmed）
- 操作取消（类型：更新），说明：取消订单（任意状态 → cancelled）
- 操作重置（类型：更新），说明：重新打开已取消订单（cancelled → ordered）

#### 校验
- 操作订单时，只有新建状态可以下单
- 操作发送时，只有已下单状态可以发送
- 确认操作时，只有已发送状态可以确认
- 操作重置时，只有已取消状态可以重置

#### 变更
- 在 创建 时，将 用户 设为当前操作人
- 在 操作订单 时，将 状态 设为 已排序
- 在 操作发送 时，将 状态 设为 已发送
- 在 确认操作 时，将 状态 设为 已确认
- 在 操作取消 时，将 状态 设为 已取消
- 在 操作重置 时，将 状态 设为 已排序
- 在 更新数量 时，停用当零 启用
- 在 创建 / 更新数量 / 操作订单 / 操作发送 / 确认操作 / 操作取消 / 操作重置 时，将 编号 设为 编号

#### 计算
- 计算字段 价格：金额，规则 数量 × 产品.价格 + 合计配料价格(加料组1, 加料组2, 加料组3)
- 计算字段 显示配料：文本，规则 join_names( + , 加料组1, 加料组2, 加料组3)
- 计算字段 可用今日：布尔，规则 产品.供应商.可用今日
- 计算字段 订单截止日已通过：布尔，规则 产品.供应商.订单截止日已通过

#### 事件
- 事件：操作订单 -> 午餐.订单.已排序
- 事件：操作发送 -> 午餐.订单.已发送
- 事件：确认操作 -> 午餐.订单.已确认
- 事件：操作取消 -> 午餐.订单.已取消

#### 工作流
- 流程：订单流程：创建 -> 操作订单 -> 操作发送 -> 确认操作 -> 操作取消 -> 操作重置（午餐订单流程）
