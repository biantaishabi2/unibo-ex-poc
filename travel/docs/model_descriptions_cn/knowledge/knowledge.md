# 模型业务说明

- 版本：1.0
- 领域：知识库
- 领域说明：知识管理领域模型，涵盖文章、版本历史、权限成员、标签、收藏
- 实体数量：8

## 实体：文章（聚合根）

- 说明：知识库文章，支持树形层级、状态机、软删除、锁定编辑
- 来源：基于 内容；来源域 ofbiz/content；过滤条件 内容类型编号=KB_ARTICLE

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 文章标题
- 正文：HTML，默认值 ，说明 富文本正文（HTML 或 JSONB）
- 状态：枚举（必填），默认值 草稿，可选值：草稿 / 已发布 / 已归档，说明 生命周期状态
- 序列：整数（必填），默认值 0，说明 同级排序序号
- 分类：枚举（必填），默认值 私有，可选值：工作区 / 共享 / 私有，说明 分类决定默认权限策略
- 图标：文本，说明 文章图标
- 封面图片编号：唯一标识，说明 封面图片（FK → Attachment）
- 锁定（is_locked）：布尔（必填），默认值 否，说明 是否锁定编辑
- 模板：布尔（必填），默认值 否，说明 是否为模板
- 启用：布尔（必填），默认值 是，说明 软删除标志（false = 回收站）
- 已删除日期：日期时间，说明 移入回收站时间，用于90天自动清理
- 最近版次日期：日期时间，说明 最近一次 body 变更时间
- 锁定（locked_at）：日期时间，说明 锁定开始时间（超30分钟自动释放）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 上级：多对一 -> 文章
- 子项：一对多 -> 文章，外键 上级编号
- 成员：一对多 -> 文章成员，管理模式 直接管理
- 版本：一对多 -> 文章版本
- 收藏：一对多 -> 收藏
- 标签：多对多 -> 标签，中间关系 文章标签链接
- 创建人：多对一 -> 参与方，外键 创建人参与方编号
- 最近作者：多对一 -> 参与方，外键 最近作者参与方编号
- 储物柜：多对一 -> 参与方，外键 储物柜参与方编号
- 最近编辑者：多对一 -> 参与方，外键 最近编辑者参与方编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、正文、上级编号、序列、分类、图标、封面图片编号、模板
- 查询
- 更新，可写字段：名称、正文、序列、分类、图标、封面图片编号、模板
- 操作发布（类型：更新），说明：发布文章（draft → published）
- 操作取消发布（类型：更新），说明：撤销发布（published → draft）
- 操作归档（类型：更新），说明：归档文章（published → archived），递归归档所有后代
- 操作恢复状态（类型：更新），说明：从归档恢复（archived → draft）
- 移入回收站（类型：更新），说明：移入回收站（软删除），递归处理后代
- 从回收站恢复（类型：更新），说明：从回收站恢复
- 操作锁定（类型：更新），说明：抢锁开始编辑
- 解锁（类型：更新），说明：释放锁（保存版本快照后解锁）
- 操作移动（类型：更新），说明：移动文章到新父级，检查循环引用，参数：新上级编号：唯一标识
- 操作复制（类型：创建），说明：深拷贝文章（递归复制子文章+member权限，不复制版本历史），参数：来源文章编号：唯一标识（必填）

#### 校验
- 创建时，名称 不能为空
- 操作发布时，只有草稿状态可以发布
- 操作取消发布时，只有已发布状态可以撤销发布
- 操作归档时，只有已发布状态可以归档
- 操作恢复状态时，只有已归档状态可以恢复
- 操作发布／操作取消发布／操作归档／操作恢复状态／更新时，策略检查（当前用户没有写权限）
- 移入回收站／从回收站恢复时，策略检查（当前用户没有删除权限（需要 owner 级别））
- 操作移动时，不能将文章移动到自身或其后代下（循环引用）
- 移入回收站时，文章已在回收站中
- 从回收站恢复时，文章不在回收站中

#### 策略
- 权限：创建 操作，当 操作者.角色 = 知识库编辑者 或 操作者.角色 = 知识库经理 或 操作者.角色 = 管理员 时允许
- 权限：查询 操作，当 检查访问(数据, 操作者, 查询) 时允许
- 权限：更新 操作，当 检查访问(数据, 操作者, 写入) 时允许
- 权限：删除 操作，当 检查访问(数据, 操作者, 所有者) 时允许

#### 变更
- 在 创建 时，将 创建标识 设为当前操作人
- 在 创建 / 更新 / 操作发布 / 操作取消发布 / 操作归档 / 操作恢复状态 时，将 写入标识 设为当前操作人
- 在 操作发布 时，将 状态 设为 已发布
- 在 操作取消发布 / 操作恢复状态 时，将 状态 设为 草稿
- 在 操作归档 时，将 状态 设为 已归档
- 在 移入回收站 时，将 启用 设为 否
- 在 移入回收站 时，将 已删除日期 设为 当前时间
- 在 从回收站恢复 时，将 启用 设为 是
- 在 从回收站恢复 时，设置 已删除日期
- 在 操作锁定 时，将 锁定 设为 是
- 在 操作锁定 时，将 锁定 设为当前操作人
- 在 操作锁定 时，将 锁定 设为 当前时间
- 在 解锁 时，将 锁定 设为 否
- 在 解锁 时，设置 锁定
- 在 解锁 时，设置 锁定
- 在 操作移动 时，移动后继承新父级 category，递归传播到所有后代
- 在 操作归档 时，递归归档所有后代文章，归档前创建版本快照
- 在 移入回收站 时，递归软删除所有后代文章
- 在 从回收站恢复 时，若父文章仍在回收站，则移到根级并设为 private
- 在 操作发布 / 操作归档 / 解锁 时，创建版本快照（发布、归档、解锁时触发）
- 在 操作复制 时，递归复制子文章+member权限，不复制版本历史；state 重置为 draft，标题追加"（副本）"
- 在 创建 / 更新 / 操作发布 / 操作取消发布 / 操作归档 / 操作恢复状态 / 移入回收站 / 从回收站恢复 / 操作锁定 / 解锁 / 操作移动 / 操作复制 时，将 编号 设为 编号

#### 计算
- 计算字段 全名：文本，规则 recursive_join(上级.名称, 名称, separator= / ，最大深度=10)
- 计算字段 根文章编号：唯一标识，规则 root_ancestor(上级编号)
- 计算字段 文章链接：文本，规则 格式(/knowledge/article/{}-{}, 编号, slugify(名称))
- 计算字段 正文简短：文本，规则 truncate(strip_tags(正文), 200)
- 计算字段 写入访问：布尔，规则 检查访问(自身, 当前用户, 写入)
- 计算字段 查询访问：布尔，规则 检查访问(自身, 当前用户, 查询)
- 计算字段 收藏：布尔，规则 exists(收藏, 用户编号 = 当前用户.编号)
- 计算字段 版本数量：整数，规则 数量(版本)
- 计算字段 收藏数量：整数，规则 数量(收藏)

#### 事件
- 事件：操作发布 -> 知识库.文章.已发布
- 事件：操作归档 -> 知识库.文章.已归档
- 事件：移入回收站 -> 知识库.文章.已删除

#### 工作流
- 流程：article_lifecycle：创建 -> 更新 -> 操作发布 -> 操作取消发布 -> 操作归档 -> 操作恢复状态 -> 移入回收站 -> 从回收站恢复 -> 操作锁定 -> 解锁 -> 操作移动 -> 操作复制（文章生命周期与编辑协作流程）

## 实体：文章成员

- 说明：文章权限成员，支持个人（partner）和用户组（group）两种授权基准
- 来源：基于 内容角色；来源域 ofbiz/content

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 基于：枚举（必填），可选值：伙伴 / 分组，说明 授权基准：partner（个人）或 group（用户组）
- 权限：枚举（必填），可选值：查询 / 写入 / 所有者，说明 权限级别
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 文章：多对一 -> 文章，必填关系
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号
- 分组：多对一 -> 分组，外键 分组编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：文章编号、伙伴编号、分组编号、基于、权限
- 更新，可写字段：权限
- 删除

#### 校验
- 创建时，伙伴编号 不能为空（based_on=partner 时 partner_id 必填）
- 创建时，分组编号 不能为空（based_on=group 时 group_id 必填）
- 创建时，partner_id 和 group_id 不能同时填写

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：article_member_management：创建 -> 更新 -> 删除（文章成员权限维护流程）
