# 模型业务说明

- 版本：1.0
- 领域：网站
- 领域说明：多站点基础设施（站点配置、页面管理、导航菜单）
- 实体数量：4

## 实体：网站（聚合根）

- 说明：网站
- 来源：基于 网站；来源域 网站

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 站点编码：文本（必填）
- 名称：文本（必填）
- 域名称：文本，说明 域名（SQL 唯一约束，写入时自动 HTTPS + 去尾斜杠）
- 默认语言编号：唯一标识（必填），说明 默认语言
- 主页链接：文本，默认值 /，说明 首页 URL
- 图标：二进制，说明 网站图标，上传时自动缩放至 256x256 ICO 格式
- 标识：二进制，说明 网站 Logo
- 社交Twitter：文本，说明 Twitter 账号
- 社交Facebook：文本，说明 Facebook 链接
- 社交GitHub：文本，说明 GitHub 链接
- 社交LinkedIn：文本，说明 LinkedIn 链接
- 社交YouTube：文本，说明 YouTube 链接
- 社交Instagram：文本，说明 Instagram 链接
- 社交TikTok：文本，说明 TikTok 链接
- Google分析键：文本，说明 Google Analytics 追踪码
- Google搜索控制台：文本，说明 Google Search Console 验证码
- 合理共享键：文本，说明 Plausible 分析密钥
- CDN已激活：布尔，默认值 否，说明 CDN 开关
- CDN链接：文本，说明 CDN 基础 URL
- CDN筛选：长文本，说明 CDN URL 匹配正则
- Cookie条：布尔，默认值 否，说明 Cookie 弹窗开关
- 自定义规则编码头部：长文本，说明 自定义 head 脚本
- 自定义规则编码表尾：长文本，说明 自定义 footer 脚本
- 是否启用：布尔，默认值 是
- 说明：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 页面：一对多 -> 网页页面，外键 网站编号
- 菜单：一对多 -> 菜单，外键 网站编号
- 公司：多对一 -> 参与方，外键 公司参与方编号

#### 唯一约束
- 唯一约束 唯一站点编码：站点编码
- 唯一约束 唯一域名称：域名称

### Conduct（行为声明）

#### 操作
- 创建，可写字段：站点编码、名称、域名称、说明、公司编号、默认语言编号、主页链接
- 查询
- 更新，可写字段：名称、域名称、是否启用、说明、主页链接、图标、标识、社交Twitter、社交Facebook、社交GitHub、社交LinkedIn、社交YouTube、社交Instagram、社交TikTok、Google分析键、Google搜索控制台、合理共享键、CDN已激活、CDN链接、CDN筛选、Cookie条、自定义规则编码头部、自定义规则编码表尾

#### 校验
- 创建时，站点编码 不能为空
- 创建时，名称 不能为空

#### 策略
- 权限：创建 操作，当 操作者.角色 = 网站经理 或 操作者.角色 = 管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=公司 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=公司 时允许

#### 变更
- 在 创建 时，自动创建主页
- 在 创建 时，自动创建公开用户
- 在 更新 时，自动创建Cookie策略页
- 在 创建 / 更新 时，格式域 域名称
- 在 创建 / 更新 时，缩放图标 图标
- 在 创建 / 更新 时，将 编号 设为 编号

#### 计算
- 计算字段 获取CDN链接：文本，表达式 CDN链接
- 计算字段 图片链接：文本，表达式 CDN链接
- 计算字段 备选语言：文本，表达式 名称
- 计算字段 规范链接：文本，表达式 主页链接

#### 工作流
- 流程：website_lifecycle：创建 -> 更新（网站管理流程）

## 实体：网页页面

- 说明：网站静态页面，支持 URL slugification 与定时发布
- 来源：基于 网页页面；来源域 网站

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 链接：文本（必填），说明 页面 URL（网站内唯一）
- 名称：文本（必填），说明 页面名称
- 视图编号：唯一标识（必填），说明 关联 ir.ui.view（级联删除）
- 网站已发布：布尔，默认值 否，说明 发布状态
- 日期发布：日期时间，说明 定时发布时间
- 网站已索引：布尔，默认值 是，说明 搜索引擎索引开关
- 表头覆盖：布尔，默认值 否，说明 页头覆盖模式
- 表头颜色：文本，说明 页头颜色
- 表头可见：布尔，默认值 是，说明 页头可见
- 表尾可见：布尔，默认值 是，说明 页脚可见
- 可见性：枚举，默认值 公开，可选值：公开 / 密码 / 受限分组，说明 可见性控制
- 可见性密码：文本，说明 密码保护时的密码
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 网站：多对一 -> 网站
- 菜单：一对多 -> 菜单，外键 页面编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：链接、名称、视图编号、网站已发布、日期发布、网站已索引、表头覆盖、表头颜色、表头可见、表尾可见、可见性、可见性密码，参数：网站编号：唯一标识
- 查询
- 更新，可写字段：链接、名称、网站已发布、日期发布、网站已索引、表头覆盖、表头颜色、表头可见、表尾可见、可见性、可见性密码
- 发布（类型：更新），说明：发布页面
- 取消发布（类型：更新），说明：取消发布
- 克隆页面（类型：创建），说明：克隆页面（不支持跨网站菜单克隆），可写字段：链接、名称，参数：网站编号：唯一标识

#### 校验
- 创建时，链接 不能为空
- 创建时，名称 不能为空
- 创建／更新时，URL 在同一 website_id 内必须唯一

#### 变更
- 在 发布 时，将 网站已发布 设为 是
- 在 取消发布 时，将 网站已发布 设为 否
- 在 创建 / 更新 时，URL规范化 链接
- 在 更新 时，创建重定向
- 在 更新 时，同步菜单链接
- 在 更新 时，同步主页
- 在 更新 时，写时复制分支
- 在 删除 时，清除缓存
- 在 创建 / 更新 / 发布 / 取消发布 / 克隆页面 时，将 编号 设为 编号

#### 计算
- 计算字段 可见：布尔，规则 网站已发布 = 是 且 日期发布 = 空 或 日期发布 ≤ 当前时间
- 计算字段 主页：布尔，规则 链接 = 网站.主页链接
- 计算字段 搜索优先级：整数，表达式 count(menus)

#### 事件
- 事件：发布 -> 网站.页面.已发布

#### 工作流
- 流程：page_lifecycle：创建 -> 更新 -> 发布 -> 取消发布 -> 克隆页面（网页生命周期）

## 实体：菜单

- 说明：网站菜单
- 来源：基于 网页站点内容；来源域 ofbiz/content

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 菜单名称（可翻译）
- 链接：文本，说明 菜单链接
- 上级路径：文本，说明 层级路径（高效查询用）
- 序列：整数，默认值 10，说明 排序序号
- 新窗口：布尔，默认值 否，说明 新窗口打开
- 超大菜单：布尔，默认值 否，说明 是否为 Mega Menu
- 超大菜单内容：长文本，说明 Mega Menu HTML 内容
- 超大菜单类：文本，说明 Mega Menu CSS 类名
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 网站：多对一 -> 网站
- 页面：多对一 -> 网页页面
- 上级：多对一 -> 菜单
- 子项：一对多 -> 菜单，外键 上级编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、链接、序列、新窗口、超大菜单、超大菜单内容、超大菜单类，参数：网站编号：唯一标识；页面编号：唯一标识；上级编号：唯一标识
- 查询
- 更新，可写字段：名称、链接、序列、新窗口、超大菜单、超大菜单内容、超大菜单类

#### 校验
- 创建时，名称 不能为空
- 创建／更新时，菜单最多支持 2 级嵌套
- 创建／更新时，Mega Menu 不能有父级也不能有子级
- 更新时，已有子级的菜单不能设置 parent_id

#### 变更
- 在 创建 / 更新 时，清理URL 链接
- 在 创建 时，自动复制到所有网站
- 在 创建 时，重新分配上级
- 在 创建 / 更新 / 删除 时，失效菜单缓存
- 在 创建 / 更新 时，将 编号 设为 编号

#### 计算
- 计算字段 可见：布尔，规则 自定义规则（）
- 计算字段 启用高亮：布尔，规则 自定义规则（）
- 计算字段 获取树：文本，表达式 名称

#### 工作流
- 流程：menu_lifecycle：创建 -> 更新（菜单管理流程）
