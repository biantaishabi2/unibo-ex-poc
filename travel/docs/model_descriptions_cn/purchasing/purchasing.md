## 实体：供应商（聚合根）

- 说明：供应商主数据（对应 OFBiz PartyGroup + PartyRole SUPPLIER）
- 来源：基于 参与方分组；来源域 ofbiz/party；关联 参与方角色（角色类型编号=供应商）

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 供应商编码：文本（必填），说明 供应商编号
- 名称：文本（必填），说明 供应商名称
- 状态：枚举，默认值 启用，可选值：启用 / 停用 / 冻结
- 联系人：文本，说明 联系人
- 联系电话：文本
- 联系邮箱：文本
- 地址：长文本
- 付款条件：文本，说明 付款条件（如 Net30, Net60）
- 税号：文本，说明 税务登记号
- 采购警告：枚举，默认值 无消息，可选值：无消息 / 警告 / 冻结，说明 采购警告级别；block 时阻止选择该供应商
- 采购警告消息：长文本，说明 采购警告消息内容
- 上级编号：唯一标识，说明 上级联系人（子联系人的父公司）；供应商注册时用 parent_id 作为实际供应商
- 备注：长文本
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 产品：一对多 -> 供应商产品
- 采购订单：一对多 -> 采购订单
- 供应商信息：一对多 -> 产品供应商信息
- 公司参与方：多对一 -> 参与方，外键 公司参与方编号，必填关系

- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 申请单号/协议编号（默认 New，确认时自动生成序列号）
- 来源：文本，说明 来源文档编号
- 状态：枚举，默认值 草稿，可选值：草稿 / 持续 / 进行中 / 打开 / 完成 / 取消，说明 协议状态（draft→in_progress 普通 / draft→ongoing Blanket Order）
- 说明：长文本，说明 协议描述（HTML）
- 下单日期（ordering_date）：日期
- 日期结束：日期时间，说明 协议截止日期
- 排班日期：日期，说明 预计交付日期
- 备注：长文本
- 币种：文本，默认值 CNY，说明 币种
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 项目：一对多 -> 采购申请单项，外键 申请单编号，管理模式 直接管理
- 类型：多对一 -> 采购申请单类型，必填关系
- 供应商：多对一 -> 供应商
- 用户：多对一 -> 参与方，外键 用户参与方编号
- 采购订单：一对多 -> 采购订单，外键 申请单编号

#### 唯一约束
- 唯一约束 唯一申请单名称：名称

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、来源、说明、ordering_date、日期结束、排班日期、币种、备注，参数：项目：列表（必填）；类型编号：唯一标识（必填）；供应商编号：唯一标识
- 查询
- 列表（类型：查询），说明：列表查询
- 搜索（类型：查询），说明：条件检索
- 获取（类型：查询），说明：详情查询
- 预览（类型：查询），说明：预览查询
- 计算（类型：查询），说明：计算查询
- lookup（类型：查询），说明：快速检索
- 操作包含进度（类型：更新），说明：确认协议（draft → in_progress / ongoing，Blanket Order 校验价格和数量）
- 操作打开（类型：更新），说明：进入投标选择（in_progress/ongoing → open）
- 完成操作（类型：更新），说明：关闭协议（open → done，检查无未确认的 RFQ）
- 操作取消（类型：更新），说明：取消协议及关联报价单
- 操作草稿（类型：更新），说明：重置为草稿（cancel → draft）

#### 校验
- 创建时，名称 不能为空
- 操作包含进度时，只有草稿状态可以确认
- 操作打开时，只有进行中状态可以进入投标选择
- 完成操作时，只有开放状态可以关闭
- 操作草稿时，只有已取消状态可以重置为草稿
- 操作取消时，仅未完成状态的协议允许取消

#### 变更
- 在 创建 时，将 用户 设为当前操作人
- 在 操作包含进度 时，将 状态 设为 进行中
- 在 操作打开 时，将 状态 设为 打开
- 在 完成操作 时，将 状态 设为 完成
- 在 操作取消 时，将 状态 设为 取消
- 在 操作草稿 时，将 状态 设为 草稿
- 在 创建 / 操作包含进度 / 操作打开 / 完成操作 / 操作取消 / 操作草稿 时，将 编号 设为 编号

#### 事件
- 事件：操作包含进度 -> 采购.申请单.已确认
- 事件：完成操作 -> 采购.申请单.完成
- 事件：操作取消 -> 采购.申请单.已取消

#### 工作流
- 流程：requisition_lifecycle_flow：创建 -> 操作包含进度 -> 操作打开 -> 完成操作 -> 操作取消（采购申请生命周期）
- 流程：requisition_reopen_flow：操作取消 -> 操作草稿 -> 操作包含进度（取消后重新发起采购申请）

- 按钮审批（类型：更新），说明：审批通过（管理员操作或自动审批）
- 按钮完成（类型：更新），说明：锁定订单
- 按钮解锁（类型：更新），说明：解锁订单（done -> purchase）
- 按钮取消（类型：更新），说明：取消订单
- 按钮草稿（类型：更新），说明：重置为草稿
- 操作创建发票（类型：创建），说明：从采购单创建供应商发票

#### 校验
- 创建时，名称 不能为空
- 按钮确认时，只有草稿或已发送状态可以确认
- 按钮审批时，只有待审批状态可以审批通过
- 按钮完成时，只有采购订单状态可以锁定
- 按钮解锁时，只有已锁定状态可以解锁
- 按钮取消时，存在非草稿/非取消状态的关联发票，无法取消订单
- 删除时，仅已取消状态的订单允许删除
- 创建／更新时，订单行中产品的公司必须与订单公司一致
- 创建／更新时，该供应商已被设置为采购阻止，无法选择
- 按钮确认时，订单行的分析账户分配不合法
- 操作创建发票时，当前无待开票内容，无法创建发票
- 打印报价单时，只有草稿状态可以打印报价单

#### 策略

- 权限：按钮审批 操作，当 操作者.角色 = 采购经理 或 op=通话，模块=审批，方法=审批允许，args=操作者 时允许
