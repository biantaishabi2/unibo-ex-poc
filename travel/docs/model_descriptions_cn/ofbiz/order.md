## 实体：订单调整（聚合根）

- 说明：注意：includeInTax 和 includeInShipping 应默认为 true，但当调整为税收或运费调整时应被忽略
- 表名：order_adjustments

### Schema（数据模型）

#### 字段
- 编号：文本（主键、自动生成）
- 订单调整编号：文本
- 订单项序列编号：文本
- 发货分组序列编号：文本
- 评论：文本
- 说明：文本
- 金额：金额
- 周期性金额：金额
- 此处的金额已在价格中表示，例如增值税（amount_already_included）：金额
- 产品促销编号：文本
- 产品促销规则编号：文本
- 产品促销操作序列编号：文本
- 产品功能编号：文本
- 对应产品编号：文本
- 税权限费率序列编号：文本
- 来源参考号编号：文本
- 来源百分比：金额，说明 对于税收条目，这是税收百分比
- 客户参考号编号：文本，说明 对于税收条目，这是交易方税务ID
- 主要地理编号：文本，说明 对于税收条目，这是主要管辖区Geo（税收所适用的最小或最本地Geo，通常是州/省，也许是县或市）
- 次要地理编号：文本，说明 对于税收条目，这是次要管辖区Geo（通常是国家或主要Geo所在的其他Geo）
- 免税金额：金额，说明 通常应适用但不适用于此订单的金额；对于税收豁免，表示税款本应为的金额
- 税授权地理编号：文本，说明 这些taxAuth字段已弃用primaryGeoId和secondaryGeoId字段，将用于较新的税收计算
- 税授权参与方编号：文本
- 覆盖总账科目编号：文本，说明 用于指定用于调整的覆盖或实际glAccountId，避免初始过账后配置更改引发的问题等
- 包含税：布尔
- 包含发货：布尔
- 手动：布尔
- 创建日期：日期时间
- 创建用户登录：文本
- 最近修改日期：日期时间
- 最近修改用户登录：文本

#### 关系
- 订单调整类型：多对一 -> 订单调整类型，外键 订单调整类型编号
- 订单表头：多对一 -> 订单表头，外键 订单编号
- 订单调整：多对一 -> 订单调整，外键 原始调整编号
