## 实体：产品制造规则（聚合根）

- 表名：product_manufacturing_rules

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成），说明 编号
- 规则编号：文本，说明 规则编号
- 产品编号（product_id）：文本，说明 产品编号
- 产品编号（product_id_for）：文本，说明 用于产品编号
- 产品编号输入：文本，说明 产品编号包含（原 product_id_in，重命名避免与 ent 谓词冲突）
- 规则序列编号：文本，说明 规则序列编号
- 来源日期：日期时间，说明 来源日期
- 产品编号包含替代：文本，说明 替代产品编号
- 产品功能：文本，说明 产品功能
- 规则操作员：文本，说明 规则操作员
- 数量：浮点，说明 数量
- 说明：文本，说明 说明
- 至日期：日期时间，说明 到日期

### Conduct（行为声明）

#### 操作
- 查询
- 创建
- 更新
- 删除

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号
