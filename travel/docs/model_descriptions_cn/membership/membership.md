# 模型业务说明

- 版本：1.0
- 领域：Membership
- 领域说明：会员管理领域模型，涵盖会员记录行、状态流转、合作伙伴会员状态计算
- 实体数量：3

## 实体：MembershipLine（聚合根）

- 说明：会员记录行，跟踪合作伙伴的会员产品、有效期和支付状态
- 来源：基于 参与方角色；来源域 ofbiz/party；关联 参与方分类（参与方分类类型编号=MEMBERSHIP）

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 日期来源：日期，说明 会员开始日期
- 日期（date_to）：日期，说明 会员结束日期
- 日期取消：日期，说明 取消日期
- 日期（date）：日期，默认值 今日，说明 加入日期
- 成员价格：金额（必填），必须 ≥ 0（会费金额不能为负数），说明 会费金额
- 状态：枚举（必填），默认值 无，可选值：无 / 等待中 / 已开票 / 已付清 / free / 已取消 / 旧，说明 会员状态（none=非会员, waiting=等待中, invoiced=已开票, paid=已付费, free=免费, canceled=已取消, old=过期）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号，必填关系
- membership：多对一 -> MembershipProduct，必填关系

### Conduct（行为声明）

#### 操作
- 创建，可写字段：日期来源、日期、日期、成员价格、状态，参数：伙伴编号：唯一标识（必填）；membership_id：唯一标识（必填）
- 查询
- 更新，可写字段：日期来源、日期、日期取消、成员价格、状态
- 取消（类型：更新），说明：取消会员（设置 date_cancel 并更新状态为 canceled）
- renew（类型：更新），说明：续费（更新 date_to 并重置状态），可写字段：日期、成员价格

#### 校验
- 创建时，成员价格 不能为空

#### 策略
- 权限：创建 操作，当 操作者.角色 属于 membership_manager、管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=伙伴 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=伙伴 时允许

#### 变更
- 在 取消 时，将 状态 设为 已取消
- 在 取消 时，将 日期取消 设为 今日
- 在 创建 / 更新 / 取消 / renew 时，将 编号 设为 编号

#### 计算
- 计算字段 是否启用：布尔，规则 状态 属于 已付清、free 且 日期来源 ≤ 今日 且 日期 ≥ 今日

#### 事件
- 事件：创建 -> membership.行.创建
- 事件：取消 -> membership.行.已取消

#### 工作流
- 流程：membership_flow：创建 -> 取消 -> renew（会员状态流转）

## 实体：MembershipProduct

- 说明：会员产品，定义会员类型和有效期
- 来源：基于 产品；来源域 ofbiz/product；过滤条件 产品类型编号=SERVICE_MEMBERSHIP

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 会员产品名称
- 会员有效期起始（membership_date_from）：日期
- 会员有效期截止（membership_date_to）：日期
- 列表价格：金额，说明 标准会费
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- membership_lines：一对多 -> MembershipLine，外键 membership_id

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、membership_date_from、membership_date_to、列表价格
- 查询
- 更新，可写字段：名称、membership_date_from、membership_date_to、列表价格

#### 校验
- 创建时，名称 不能为空

#### 变更
- 在 创建 / 更新 时，将 编号 设为 编号

#### 工作流
- 流程：membership_product_maintain_flow：创建 -> 更新（会员产品维护）
