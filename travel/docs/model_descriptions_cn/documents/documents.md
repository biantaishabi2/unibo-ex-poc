# 模型业务说明

- 版本：1.0
- 领域：文档
- 领域说明：文档管理领域模型，涵盖文档、文件夹/工作区、标签体系、工作流动作、分享
- 实体数量：25

## 实体：文档（聚合根）

- 说明：文档记录，支持文件、链接、请求占位、文件夹四种类型
- 来源：基于 文档；来源域 文档

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 文档名称，上传时默认取文件名
- 类型：枚举（必填），可选值：二进制 / 链接 / 空 / 文件夹，说明 binary=文件, url=链接, empty=请求占位, folder=文件夹
- 链接：文本，说明 type=url 时的外部链接
- 锁定标识：唯一标识，说明 锁定用户，非空时其他用户不可编辑
- 启用：布尔（必填），默认值 是，说明 归档标志
- 资源模型：文本，说明 关联业务模型名称（如 account.move）
- 资源编号：整数，说明 关联业务记录 ID
- 说明：长文本，说明 文档描述/备注
- 校验和：文本，说明 文件校验和 SHA-256，用于去重与完整性校验（related → attachment）
- 文件类型：文本，说明 MIME 类型（related → attachment）
- 文件大小：整数，说明 文件大小（字节）（related → attachment）
- 原始文件名：文本，说明 原始上传文件名
- 存储路径：文本，说明 存储路径（S3/MinIO）
- 匹配算法：枚举，可选值：无 / 自动 / 手动，说明 预留自动分类策略
- 搜索向量：文本，说明 PostgreSQL 全文索引列（tsvector）
- 请求活动编号：唯一标识，说明 文档请求关联的活动
- 创建标识：唯一标识（自动生成），说明 创建者
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 文件夹：多对一 -> 文件夹，外键 文件夹编号，必填关系
- 所有者：多对一 -> 参与方，外键 所有者参与方编号
- 伙伴：多对一 -> 联系
- 附件：多对一 -> 附件
- 公司：多对一 -> 参与方，外键 公司参与方编号
- 标签：多对多 -> 标签，中间关系 文档标签链接
- 已收藏：多对多 -> 参与方，外键 已收藏参与方编号，中间关系 文档收藏链接
- 分组：多对多 -> 分组，中间关系 文档分组链接
- 版本：一对多 -> 文档版本
- 股份：多对多 -> 分享，中间关系 文档分享链接

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、类型、文件夹编号、所有者编号、伙伴编号、链接、说明、原始文件名、匹配算法
- 查询
- 更新，可写字段：名称、说明、伙伴编号、所有者编号、文件夹编号、链接
- 上传（类型：更新），说明：上传文件（将 request 转为 active），可写字段：附件编号、原始文件名
- 锁定（类型：更新），说明：锁定文档
- 解锁（类型：更新），说明：解锁文档
- 归档（类型：更新），说明：归档文档
- 恢复（类型：更新），说明：恢复归档
- 切换收藏（类型：更新），说明：切换收藏状态
- 删除

#### 校验
- 创建时，名称 不能为空
- 创建时，类型 不能为空
- 创建时，文件夹编号 不能为空（每个文档必须属于一个文件夹）
- 上传时，附件编号 不能为空（上传时必须提供附件）
- 上传时，只有请求占位文档可以执行上传
- 锁定时，文档已被锁定
- 解锁时，仅锁定用户和管理员可解锁
- 归档时，只有活跃文档可以归档
- 恢复时，只有已归档文档可以恢复

#### 策略
- 权限：创建 操作，当 操作者.角色 = 文档经理 或 操作者.角色 = 管理员 时允许
- 权限：查询 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=所有者 时允许
- 权限：更新 操作，当 操作者.角色 = 管理员 或 op=relates_to_actor_via，args=所有者 时允许

#### 变更
- 在 创建 时，将 所有者编号 设为当前操作人
- 在 创建 时，将 创建标识 设为当前操作人
- 在 上传 时，将 类型 设为 二进制
- 在 上传 / 恢复 时，将 启用 设为 是
- 在 锁定 时，将 锁定标识 设为当前操作人
- 在 解锁 时，设置 锁定标识
- 在 归档 时，将 启用 设为 否
- 在 创建 / 更新 / 上传 / 锁定 / 解锁 / 归档 / 恢复 / 切换收藏 / 删除 时，将 编号 设为 编号

#### 计算
- 计算字段 已收藏：布尔，规则 contains(已收藏, 操作者.编号)
- 计算字段 可用规则编号列表：列表
- 计算字段 缩略图：文本
- 计算字段 文件大小显示：文本
- 计算字段 校验和显示：文本
- 计算字段 文件类型显示：文本

#### 事件
- 事件：上传 -> 文档.文档.uploaded
- 事件：更新 -> 文档.文档.更新
- 事件：归档 -> 文档.文档.已归档
- 事件：锁定 -> 文档.文档.锁定
- 事件：解锁 -> 文档.文档.unlocked

#### 工作流
- 流程：document_lifecycle_flow：创建 -> 上传 -> 锁定 -> 解锁 -> 归档 -> 恢复 -> 更新 -> 切换收藏 -> 删除（文档从创建到上传、锁定、归档与恢复的完整生命周期）

## 实体：流程规则（聚合根）

- 说明：工作流动作规则，定义文档的自动化处理（条件匹配 + 执行动作）
- 来源：基于 流程规则；来源域 文档

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 动作名称（显示在 UI 按钮上）
- 备注：长文本，说明 内部备注
- 条件类型：枚举（必填），可选值：条件 / 域，说明 criteria=标准条件, domain=高级域表达式
- 域：文本，说明 condition_type=domain 时的高级过滤条件（JSON）
- 创建模型：枚举，可选值：链接记录 / 供应商账单 / 客户发票 / 供应商退款 / 客户退款 / 直接签署 / 签署请求 / 产品 / 项目任务，说明 创建业务记录类型

- 活动日期截止日范围：整数，说明 活动截止天数（从执行日起算）
- 活动备注：长文本，说明 活动备注
- 触发类型：枚举，默认值 手动，可选值：手动 / 上传时 / 更新时 / 已排期，说明 manual=手动, on_upload=上传自动, on_update=更新自动, scheduled=定时
- 序列：整数，说明 显示排序
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

- 文件夹：多对一 -> 文档，必填关系
- 必填标签：多对多 -> 标签，中间关系 流程规则必填标签链接

- 移除标签：多对多 -> 标签，中间关系 流程规则移除标签链接
- 伙伴：多对一 -> 联系
- 所有者：多对一 -> 参与方，外键 所有者参与方编号
- 文件夹操作：多对一 -> 文档
- 伙伴操作：多对一 -> 联系
- 所有者操作：多对一 -> 参与方，外键 所有者操作参与方编号
- 活动类型：多对一 -> 活动类型
- 活动用户：多对一 -> 参与方，外键 活动用户参与方编号

### Schema（数据模型）

- 日期截止日：日期，说明 分享链接过期日期
- 操作：枚举（必填），可选值：下载 / 下载上传，说明 download=仅下载, download_upload=下载+上传
- 邮箱放下：布尔，默认值 否，说明 是否启用邮件上传
- 活动选项：枚举，可选值：无 / 标记完成 / 排班，说明 上传文档时的活动处理
- 基础链接：文本，说明 网站根 URL（用于拼接分享链接）
- 创建标识：唯一标识（自动生成），说明 分享创建者
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 文件夹：多对一 -> 文档
- 文档：多对多 -> 文档，中间关系 文档分享链接
- 标签：多对多 -> 标签，中间关系 分享标签链接
- 伙伴：多对一 -> 联系
- 所有者：多对一 -> 参与方，外键 所有者参与方编号
- 别名：多对一 -> 邮件别名
- 创建人：多对一 -> 参与方，外键 创建人参与方编号

- 唯一约束 唯一访问令牌：访问令牌

### Conduct（行为声明）

- 创建，可写字段：名称、类型、文件夹编号、日期截止日、操作、伙伴编号、所有者编号、邮箱放下、活动选项，参数：文档编号列表：列表
- 查询
- 更新，可写字段：名称、日期截止日、操作、伙伴编号、所有者编号、邮箱放下、活动选项
- 访问（类型：查询），说明：通过 access_token 访问分享内容，参数：访问令牌：文本（必填）

#### 工作流
