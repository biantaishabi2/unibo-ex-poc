# 模型业务说明

- 版本：1.0
- 领域：活动
- 领域说明：活动管理领域模型，涵盖活动主数据、类型、报名、票务、展位、议程阶段
- 实体数量：8

## 实体：活动类型（聚合根）

- 说明：活动类型（会议/研讨会/展览/培训/网络研讨会）
- 来源：基于 工作任务类型；来源域 ofbiz/workeffort

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 类型名称（对应 description）
- 编码：文本（必填），可选值：CONFERENCE / WORKSHOP / EXHIBITION / 培训 / WEBINAR，说明 类型编码（对应 work_effort_type_id），预置值：CONFERENCE/WORKSHOP/EXHIBITION/TRAINING/WEBINAR
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 活动：一对多 -> 活动，外键 活动类型编号
- 子项：一对多 -> 活动类型，外键 上级类型编号
- 上级类型：多对一 -> 活动类型

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、编码、上级类型编号
- 查询
- 更新，可写字段：名称、上级类型编号
- 删除

#### 校验
- 创建时，名称 不能为空
- 创建时，编码 不能为空

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：event_type_lifecycle：创建 -> 更新 -> 删除（活动类型管理流程）

## 实体：活动（聚合根）

- 说明：活动主数据，管理线下/线上活动的完整生命周期
- 来源：基于 工作任务；来源域 ofbiz/workeffort；过滤条件 工作工作量类型编号=活动

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 活动名称（对应 work_effort_name）
- 说明：长文本，说明 活动描述
- 状态：枚举（必填），默认值 草稿，可选值：草稿 / 已发布 / 持续 / 已完成 / 已取消 / 已归档，说明 活动状态（对应 current_status_id）
- 开始日期：日期时间（必填），说明 活动开始时间（对应 estimated_start_date）
- 结束日期：日期时间（必填），说明 活动结束时间（对应 estimated_completion_date）
- 实际开始日期：日期时间，说明 实际开始时间
- 实际结束日期：日期时间，说明 实际结束时间
- 位置：文本，说明 活动地点描述（对应 location_desc）
- 容量：整数，说明 最大参与人数
- 注册截止日：日期时间，说明 报名截止时间
- 在线：布尔，默认值 否，说明 是否为线上活动
- 封面图片链接：文本，说明 活动封面图URL
- 明细链接：文本，说明 活动详情页/报名链接（外部落地页或内部详情路由）
- 线上活动直播/会议链接（仅 is_online=true 时有意义）（streaming_url）：文本
- 优先级：整数，默认值 0，说明 活动优先级
- 发送通知邮箱：布尔，默认值 是，说明 是否发送通知邮件
- 合计预算：金额，说明 活动预算上限（对应 total_money_allowed）
- 预算币种编号：文本，说明 预算币种（对应 money_uom_id）
- 特别条款：长文本，说明 参与条款/须知
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 活动类型：多对一 -> 活动类型，必填关系
- 注册：一对多 -> 活动注册，外键 活动编号
- 工单：一对多 -> 活动工单，外键 活动编号
- booths：一对多 -> EventBooth，外键 活动编号
- stages：一对多 -> 活动阶段，外键 活动编号
- 上级活动：多对一 -> 活动
- 子活动：一对多 -> 活动，外键 上级活动编号
- 场地：多对一 -> 设施
- 组织者：多对一 -> 参与方，外键 组织者参与方编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、说明、活动类型编号、开始日期、结束日期、位置、场地编号、容量、注册截止日、在线、封面图片链接、明细链接、streaming_url、优先级、上级活动编号、发送通知邮箱、合计预算、预算币种编号、特别条款、组织者编号
- 查询
- 更新，可写字段：名称、说明、活动类型编号、开始日期、结束日期、位置、场地编号、容量、注册截止日、在线、封面图片链接、明细链接、streaming_url、优先级、发送通知邮箱、合计预算、预算币种编号、特别条款、组织者编号
- 发布（类型：更新），说明：发布活动，开放报名通道（draft -> published）
- 开始（类型：更新），说明：开始活动（published -> ongoing）
- 完成（类型：更新），说明：完成活动（ongoing -> completed）
- 取消（类型：更新），说明：取消活动，通知所有报名者（published/ongoing -> cancelled）
- 归档（类型：更新），说明：归档活动（completed/cancelled -> archived）
- 删除，说明：删除活动（仅 draft 状态）

#### 校验
- 创建时，名称 不能为空
- 创建时，开始日期 不能为空
- 创建时，结束日期 不能为空
- 创建时，活动类型编号 不能为空
- 创建／更新时，结束日期 op 大于，且 其他字段 开始日期（结束时间必须晚于开始时间）
- 发布时，只有草稿状态的活动可以发布
- 开始时，只有已发布状态的活动可以开始
- 完成时，只有进行中状态的活动可以完成
- 取消时，只有已发布或进行中的活动可以取消
- 归档时，只有已完成或已取消的活动可以归档
- 删除时，只有草稿或已取消状态的活动可以删除

#### 变更
- 在 发布 时，将 状态 设为 已发布
- 在 开始 时，将 状态 设为 持续
- 在 开始 时，将 实际开始日期 设为 当前时间
- 在 完成 时，将 状态 设为 已完成
- 在 完成 时，将 实际结束日期 设为 当前时间
- 在 取消 时，将 状态 设为 已取消
- 在 取消 时，notify_registrants
- 在 归档 时，将 状态 设为 已归档
- 在 创建 / 更新 / 发布 / 开始 / 完成 / 取消 / 归档 / 删除 时，将 编号 设为 编号

#### 事件
- 事件：发布 -> 活动.活动.已发布
- 事件：取消 -> 活动.活动.已取消

#### 工作流
- 流程：event_lifecycle：创建 -> 发布 -> 开始 -> 完成 -> 取消 -> 归档 -> 删除（活动完整生命周期流程）

## 实体：活动注册（聚合根）

- 说明：活动报名记录，管理参与者的报名、确认、签到全流程
- 来源：基于 工作任务参与方分配；来源域 ofbiz/workeffort；过滤条件 工作工作量类型编号=活动，角色类型编号=参会者、讲师、组织者

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 角色：枚举（必填），默认值 参会者，可选值：参会者 / 讲师 / 组织者，说明 参与角色（对应 role_type_id）
- 状态：枚举（必填），默认值 待处理，可选值：待处理 / 已确认 / 已取消 / attended，说明 报名状态（对应 status_id）
- 报名时间（对应 from_date）（registered_at）：日期时间（必填）
- 状态变更：日期时间，说明 状态变更时间（对应 status_date_time）
- 检查包含时间：日期时间，说明 签到时间
- 付款状态：枚举，默认值 未付，可选值：未付 / 已付清 / 已退款，说明 付款状态
- 评论：长文本，说明 报名备注/留言
- 必须回复：布尔，默认值 否，说明 是否需要确认 RSVP
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 活动：多对一 -> 活动，必填关系
- 参会者：多对一 -> 参与方，外键 参会者参与方编号，必填关系
- 工单：多对一 -> 活动工单

#### 唯一约束
- 唯一约束 唯一活动参会者：活动编号、参会者编号

### Conduct（行为声明）

#### 操作
- register（类型：创建），说明：报名参加活动，可写字段：活动编号、参会者编号、角色、工单编号、评论、必须回复
- 查询
- 确认（类型：更新），说明：确认报名（pending -> confirmed）
- 签到（类型：更新），说明：现场签到（confirmed -> attended）
- 取消（类型：更新），说明：取消报名（pending/confirmed -> cancelled）

#### 校验
- register时，活动编号 不能为空
- register时，参会者编号 不能为空
- 确认时，只有待确认状态可以确认
- 签到时，只有已确认状态可以签到
- 取消时，只有待确认或已确认状态可以取消
- register时，活动名额已满，无法报名

#### 变更
- 在 register 时，将 registered_at 设为 当前时间
- 在 确认 时，将 状态 设为 已确认
- 在 确认 时，将 状态变更 设为 当前时间
- 在 签到 时，将 状态 设为 attended
- 在 签到 时，将 检查包含时间 设为 当前时间
- 在 取消 时，将 状态 设为 已取消
- 在 取消 时，将 状态变更 设为 当前时间
- 在 register / 确认 / 签到 / 取消 时，将 编号 设为 编号

#### 事件
- 事件：确认 -> 活动.注册.已确认
- 事件：签到 -> 活动注册已检查包含

#### 工作流
- 流程：registration_lifecycle：register -> 确认 -> 签到 -> 取消（报名完整生命周期流程）

### Schema（数据模型）

#### 字段

- 名称：文本（必填），说明 票种名称（如 VIP/普通/免费）

- 已售数量：整数，默认值 0，说明 已售数量
- 销售开始：日期时间，说明 开售时间
- 销售结束：日期时间，说明 停售时间
- 是否启用：布尔，默认值 是，说明 是否在售
- 最大每订单：整数，默认值 10，说明 单次最大购买数量
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 活动：多对一 -> 活动，必填关系
- 注册：一对多 -> 活动注册，外键 工单编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：活动编号、名称、说明、价格、币种编号、数量、销售开始、销售结束、最大每订单
- 查询
- 更新，可写字段：名称、说明、价格、数量、销售开始、销售结束、是否启用、最大每订单
- 关闭销售（类型：更新），说明：关闭售票
- 删除

#### 校验
- 创建时，活动编号 不能为空
- 创建时，名称 不能为空
- 创建时，价格 不能为空
- 创建／更新时，价格 op 大于等于，且 值 0（票价不能为负数）

#### 变更
- 在 关闭销售 时，将 是否启用 设为 否
- 在 创建 / 更新 / 关闭销售 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：ticket_lifecycle：创建 -> 更新 -> 关闭销售（票种管理流程）

## 实体：EventBooth

- 说明：活动展位，管理展览/博览会的展位分配

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 展位编号（booth_number）：文本（必填）
- 名称：文本，说明 展位名称
- 面积：金额，说明 展位面积（平方米）
- 租赁价格：金额，默认值 0，说明 租金
- 币种编号：文本，默认值 CNY，说明 币种
- 状态：枚举（必填），默认值 可用，可选值：可用 / 已预留 / occupied / 维护，说明 展位状态
- 已预留：日期时间，说明 预定时间
- 备注：长文本，说明 备注
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 活动：多对一 -> 活动，必填关系
- 租户：多对一 -> 参与方，外键 租户参与方编号

#### 唯一约束
- 唯一约束 unique_event_booth_number：活动编号、booth_number

### Conduct（行为声明）

#### 操作
- 创建，可写字段：活动编号、booth_number、名称、面积、租赁价格、币种编号、备注
- 查询
- 更新，可写字段：名称、面积、租赁价格、备注
- 储备（类型：更新），说明：预定展位（available -> reserved），可写字段：租户编号
- 发布（类型：更新），说明：释放展位（reserved/occupied -> available）
- 删除

#### 校验
- 创建时，活动编号 不能为空
- 创建时，booth_number 不能为空
- 储备时，只有可用状态的展位可以预定
- 储备时，租户编号 不能为空（预定展位必须指定承租方）
- 发布时，只有已预定或已占用的展位可以释放

#### 变更
- 在 储备 时，将 状态 设为 已预留
- 在 储备 时，将 已预留 设为 当前时间
- 在 发布 时，将 状态 设为 可用
- 在 发布 时，设置 租户编号
- 在 创建 / 更新 / 储备 / 发布 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：booth_lifecycle：创建 -> 储备 -> 发布（展位管理流程）
