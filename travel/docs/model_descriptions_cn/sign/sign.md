# 模型业务说明

- 版本：1.0
- 领域：签署
- 领域说明：电子签名领域模型，涵盖签名模板、签名字段、签名角色、签名请求、签署方、审计日志
- 实体数量：7

## 实体：签署模板（聚合根）

- 说明：签名模板，包含上传的 PDF 文件及签名字段定义
- 来源：基于 内容；来源域 ofbiz/content；过滤条件 内容类型编号=签署模板

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 模板名称
- 文档：二进制（必填），说明 上传的 PDF 文件（attachment）
- 状态：枚举，默认值 启用，可选值：启用 / 已归档，说明 模板状态
- 标签编号列表：列表，默认值 ，说明 分类标签列表
- 分享：布尔，默认值 否，说明 是否允许其他用户使用此模板
- 已授权编号列表：列表，默认值 ，说明 当 is_sharing=true 时限定可用用户列表
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 负责人：多对一 -> 参与方，外键 负责人参与方编号
- 签署项目：一对多 -> 签署项，外键 模板编号，管理模式 直接管理
- 签署请求：一对多 -> 签署请求，外键 模板编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、文档、标签编号列表、分享、已授权编号列表，参数：负责人编号：唯一标识；签署项目：列表
- 查询
- 更新，可写字段：名称、文档、标签编号列表、分享、已授权编号列表
- 归档（类型：更新），说明：归档模板
- 启用（类型：更新），说明：启用模板

#### 校验
- 创建时，名称 不能为空
- 创建时，文档 不能为空
- 归档时，只有活跃状态可以归档
- 启用时，只有已归档状态可以启用

#### 变更
- 在 归档 时，将 状态 设为 已归档
- 在 启用 时，将 状态 设为 启用
- 在 创建 / 更新 / 归档 / 启用 时，将 编号 设为 编号

#### 计算
- 计算字段 编号页面：整数，规则 pdf_page_count(文档)
- 计算字段 签署项数量：整数，规则 数量(签署项目)

#### 工作流
- 流程：sign_template_write_flow：创建 -> 更新 -> 归档 -> 启用（签名模板写操作覆盖流程）

## 实体：签署项

- 说明：签名字段定义，描述 PDF 上需要填写的区域（推荐 JSONB/embeds_many 存储）
- 来源：基于 内容关联；来源域 ofbiz/content；过滤条件 内容关联类型编号=签署字段

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 类型：枚举（必填），可选值：签名 / 初始 / 长文本 / 日期 / 复选框 / 选择，说明 字段类型
- 页面：整数（必填），必须大于 0（页码必须大于零），说明 PDF 页码
- X 坐标（百分比 0-100）（pos_x）：浮点（必填），必须 ≥ 0，且 必须 ≤ 100（X 坐标必须在 0-100 之间）
- Y 坐标（百分比 0-100）（pos_y）：浮点（必填），必须 ≥ 0，且 必须 ≤ 100（Y 坐标必须在 0-100 之间）
- 宽度：浮点（必填），必须大于 0（宽度必须大于零），说明 宽度（百分比）
- 高度：浮点（必填），必须大于 0（高度必须大于零），说明 高度（百分比）
- 必填：布尔，默认值 否，说明 是否必填
- 占位符：文本，说明 占位提示文字

#### 关系
- 模板：多对一 -> 签署模板，必填关系
- 角色：多对一 -> 签署角色，必填关系

### Conduct（行为声明）

#### 操作
- 创建，可写字段：类型、页面、pos_x、pos_y、宽度、高度、必填、占位符，参数：模板编号：唯一标识（必填）；角色编号：唯一标识（必填）
- 更新，可写字段：类型、页面、pos_x、pos_y、宽度、高度、必填、占位符、角色编号
- 删除

#### 变更
- 在 创建 / 更新 / 删除 时，将 编号 设为 编号

#### 工作流
- 流程：sign_item_write_flow：创建 -> 更新 -> 删除（签名字段写操作覆盖流程）

## 实体：签署请求（聚合根）

- 说明：签名请求，发起人基于模板创建并发送给签署方
- 来源：基于 工作任务；来源域 ofbiz/workeffort；过滤条件 工作工作量类型编号=签署请求

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 参考号：文本，说明 请求名称/编号
- 状态：枚举（必填），默认值 草稿，可选值：草稿 / 已发送 / 已签署 / 已取消 / 已过期，说明 请求状态
- 签署订单：布尔，默认值 否，说明 是否启用顺序签名
- 消息：长文本，说明 发送给签名人的附言
- 已完成文档：二进制，说明 签名完成后的最终 PDF
- 有效期天数：整数，说明 签名请求有效天数
- 过期：日期时间，说明 过期时间
- 访问令牌：文本（自动生成），说明 门户访问令牌（UUID），创建时自动生成
- 提醒启用：布尔，默认值 是，说明 是否启用自动提醒
- 最近提醒：日期时间，说明 上次提醒时间
- 完成度日期：日期时间，说明 全部签署完成的时间
- IP地址：文本，说明 发起人创建请求时的 IP 地址
- 资源模型：文本，说明 来源模块名称（跨模块回调用）
- 资源编号：整数，说明 来源记录 ID
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 模板：多对一 -> 签署模板，必填关系
- 请求人：多对一 -> 参与方，外键 请求人参与方编号，必填关系
- 请求项目：一对多 -> 签署请求项，外键 请求编号，管理模式 直接管理
- 日志：一对多 -> 签署日志，外键 请求编号

#### 唯一约束
- 唯一约束 唯一访问令牌：访问令牌

### Conduct（行为声明）

#### 操作
- 创建，可写字段：参考号、签署订单、消息、有效期天数、提醒启用、资源模型、资源编号，参数：模板编号：唯一标识（必填）；请求项目：列表（必填）
- 查询
- 发送（类型：更新），说明：发送签名请求给签署方
- 取消（类型：更新），说明：取消签名请求
- 召回（类型：更新），说明：撤回已发送的请求（重置所有 item 为 draft，使旧 token 失效）
- 过期（类型：更新），说明：过期处理（系统 cron 自动触发）
- 完成（类型：更新），说明：标记签署完成（所有签署方均已完成时自动触发）

#### 校验
- 发送时，只有草稿状态可以发送
- 取消时，只有草稿或已发送状态可以取消
- 召回时，只有已发送状态可以撤回
- 过期时，只有已发送状态可以过期
- 完成时，只有已发送状态可以完成
- 发送时，请求项目 最小长度 1（发送前必须至少有一个签署方）

#### 变更
- 在 创建 时，将 请求人 设为当前操作人
- 在 创建 时，将 访问令牌 设为 generate_uuid
- 在 创建 时，将 过期 设为 添加天数(创建时间, 有效期天数)
- 在 发送 时，将 状态 设为 已发送
- 在 取消 时，将 状态 设为 已取消
- 在 召回 时，将 状态 设为 草稿
- 在 过期 时，将 状态 设为 已过期
- 在 完成 时，将 状态 设为 已签署
- 在 完成 时，将 完成度日期 设为 当前时间
- 在 创建 / 发送 / 取消 / 召回 / 过期 / 完成 时，将 编号 设为 编号

#### 事件
- 事件：发送 -> 签署.请求.已发送
- 事件：完成 -> 签署请求已完成
- 事件：取消 -> 签署.请求.已取消
- 事件：过期 -> 签署.请求.已过期
- 事件：召回 -> 签署请求已召回

#### 工作流
- 流程：sign_flow：创建 -> 发送 -> 完成 -> 取消 -> 召回 -> 过期（签名全流程）

## 实体：签署请求项

- 说明：签名请求中的单个签署方，每人持有独立的访问令牌
- 来源：基于 工作任务参与方分配；来源域 ofbiz/workeffort

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 签署订单：整数，说明 签名顺序号（1, 2, 3...），顺序签名时使用
- 状态：枚举（必填），默认值 草稿，可选值：草稿 / 已发送 / 已完成 / 已拒绝，说明 单个签署方状态
- 访问令牌：文本（自动生成），说明 每人独立的访问令牌（UUID）
- 签署人邮箱：文本，说明 签名人邮箱（外部签名人使用）
- 已签署：日期时间，说明 签名完成时间
- 拒绝原因：长文本，说明 拒签原因
- 签署人IP：文本，说明 签名时 IP 地址
- 纬度：浮点，说明 签署时纬度（可选，GPS 定位）
- 经度：浮点，说明 签署时经度（可选，GPS 定位）
- 短信单号：文本，说明 短信验证手机号（二次认证）
- 短信令牌：文本，说明 短信验证码，有效期 10 分钟

#### 关系
- 请求：多对一 -> 签署请求，必填关系
- 角色：多对一 -> 签署角色，必填关系
- 签署人：多对一 -> 参与方，外键 签署人参与方编号

#### 唯一约束
- 唯一约束 唯一项访问令牌：访问令牌

### Conduct（行为声明）

#### 操作
- 创建，可写字段：签署订单、签署人邮箱、短信单号，参数：请求编号：唯一标识（必填）；角色编号：唯一标识（必填）；签署人编号：唯一标识
- 发送（类型：更新），说明：随 SignRequest 发送（状态 draft → sent）
- 签署（类型：更新），说明：签署完成，参数：签署人IP：文本；纬度：浮点；经度：浮点
- 拒绝（类型：更新），说明：拒签，参数：拒绝原因：文本（必填）
- 重置（类型：更新），说明：重置为草稿（随 SignRequest 撤回时触发，重新生成 token）

#### 校验
- 发送时，只有草稿状态可以发送
- 签署时，只有已发送状态可以签署
- 拒绝时，只有已发送状态可以拒签

#### 变更
- 在 创建 / 重置 时，将 访问令牌 设为 generate_uuid
- 在 发送 时，将 状态 设为 已发送
- 在 签署 时，将 状态 设为 已完成
- 在 签署 时，将 已签署 设为 当前时间
- 在 签署 时，将 签署人IP 设为 arguments.签署人IP
- 在 拒绝 时，将 状态 设为 已拒绝
- 在 拒绝 时，将 拒绝原因 设为 arguments.拒绝原因
- 在 重置 时，将 状态 设为 草稿
- 在 创建 / 发送 / 签署 / 拒绝 / 重置 时，将 编号 设为 编号

#### 工作流
- 流程：sign_request_item_write_flow：创建 -> 发送 -> 签署 -> 拒绝 -> 重置（签署方写操作覆盖流程）

## 实体：签署日志

- 说明：签名审计日志，记录一旦创建不可修改、不可删除，使用 SHA256 哈希链保证完整性
- 来源：基于 签署日志；来源域 签署

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 操作：枚举（必填），可选值：创建 / 已发送 / 打开 / 签署 / 拒绝 / 更新 / 重新分配 / 召回 / 已提醒 / 已取消，说明 操作类型
- IP地址：文本，说明 操作时 IP 地址
- 用户代理：文本，说明 浏览器 User-Agent
- 日志哈希：文本（必填），说明 SHA256 哈希链值，hash_n = SHA256(hash_{n-1} | action | timestamp | ip | ua)
- 时间戳：日期时间（必填），说明 操作时间（精确到毫秒）
- 备注：长文本，说明 附加说明（如拒签理由）
- 元数据：jsonb，说明 附加元数据

#### 关系
- 请求：多对一 -> 签署请求，必填关系
- 请求项：多对一 -> 签署请求项
- 操作者：多对一 -> 参与方，外键 操作者参与方编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：操作、IP地址、用户代理、备注、元数据，参数：请求编号：唯一标识（必填）；请求项编号：唯一标识；操作者编号：唯一标识
- 查询

#### 校验
- 创建时，操作 不能为空
- 创建时，时间戳 不能为空

#### 变更
- 在 创建 时，将 时间戳 设为 now_precise
- 在 创建 时，将 日志哈希 设为 sha256_chain(请求编号, 操作, 时间戳, IP地址, 用户代理)
- 在 创建 时，将 编号 设为 编号

#### 工作流
- 流程：sign_log_audit_flow：创建 -> 查询（审计日志创建与读取流程）
