# 模型业务说明

- 版本：1.0
- 领域：在线学习
- 领域说明：在线学习领域模型，涵盖课程、幻灯片内容、学员注册、学习进度
- 实体数量：5

## 实体：课程（聚合根）

- 说明：在线课程/频道，承载多个内容项（Slide），管理可见性与注册策略
- 来源：基于 课程；来源域 在线学习

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 课程名称
- 频道类型：枚举，默认值 培训，可选值：培训 / 文档，说明 课程类型
- 网站已发布：布尔，默认值 否，说明 是否上线发布
- 可见性：枚举，默认值 公开，可选值：公开 / 已连接 / 成员，说明 可见性（公开/登录可见/仅会员）
- 报名：枚举，默认值 公开，可选值：公开 / 邀请，说明 注册策略（自由注册/仅邀请）
- 序列：整数，默认值 0，说明 排序序号
- 说明：长文本，说明 课程简介
- 说明HTML：长文本，说明 课程详细描述（HTML）
- 推广策略：枚举，默认值 最新，可选值：最新 / 最多投票 / 最多浏览 / 特定 / 无，说明 推荐内容策略
- 合计幻灯片：整数，默认值 0，说明 已发布的非分类 Slide 数量（存储计算字段）
- 合计视图：整数，默认值 0，说明 总浏览次数
- 合计投票：整数，默认值 0，说明 总投票数
- 合计时间：金额，默认值 0，说明 总预计时长（小时）
- 成员数量：整数，默认值 0，说明 注册学员总数
- 成员已完成数量：整数，默认值 0，说明 已完课学员数
- 声望值生成频道完成：整数，默认值 10，说明 完课 Karma 奖励
- 测验首个尝试奖励：整数，默认值 10，说明 测验首次通过奖励
- 测验第二尝试奖励：整数，默认值 7，说明 测验第2次通过奖励
- 测验第三尝试奖励：整数，默认值 5，说明 测验第3次通过奖励
- 测验第四尝试奖励：整数，默认值 2，说明 测验第4次及以上通过奖励
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 幻灯片：一对多 -> 幻灯片，外键 频道编号
- 报名：一对多 -> 报名，外键 频道编号
- 已推广幻灯片：多对一 -> 幻灯片
- 创建人：多对一 -> 参与方，外键 创建参与方编号

#### 唯一约束
- 唯一约束 唯一课程名称：名称

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、频道类型、可见性、报名、说明、说明HTML、序列、推广策略、声望值生成频道完成、测验首个尝试奖励、测验第二尝试奖励、测验第三尝试奖励、测验第四尝试奖励
- 查询
- 更新，可写字段：名称、频道类型、可见性、报名、说明、说明HTML、序列、推广策略、网站已发布、声望值生成频道完成、测验首个尝试奖励、测验第二尝试奖励、测验第三尝试奖励、测验第四尝试奖励
- 发布（类型：更新），说明：上线发布课程
- 取消发布（类型：更新），说明：取消发布课程
- 归档（类型：更新），说明：归档课程（先归档所有 Slide，再归档课程）
- 恢复（类型：更新），说明：恢复课程（先恢复课程，再恢复 Slide）

#### 校验
- 创建时，名称 不能为空
- 创建／更新时，仅会员可见的课程必须设置为仅邀请注册
- 发布时，课程已处于发布状态
- 取消发布时，课程未发布，无法取消发布

#### 变更
- 在 创建 时，将 创建人 设为当前操作人
- 在 创建 时，创建关联，参数 成员状态=已加入
- 在 发布 时，将 网站已发布 设为 是
- 在 取消发布 时，将 网站已发布 设为 否
- 在 创建 / 更新 / 发布 / 取消发布 / 归档 / 恢复 时，将 编号 设为 编号

#### 事件
- 事件：发布 -> 在线课程已发布
- 事件：取消发布 -> 在线课程已取消发布
- 事件：归档 -> 在线学习.课程.已归档
- 事件：恢复 -> 在线课程已恢复

#### 工作流
- 流程：course_lifecycle：创建 -> 更新 -> 发布 -> 取消发布 -> 归档 -> 恢复（课程生命周期（创建→发布→归档/恢复））

## 实体：幻灯片

- 说明：课程内容项，支持文章、视频、文档、信息图、测验等类型
- 来源：基于 幻灯片；来源域 在线学习

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本（必填），说明 内容项名称
- 幻灯片分类：枚举（必填），可选值：信息图 / 文章 / 文档 / 视频 / 测验，说明 内容类别
- 分类：布尔，默认值 否，说明 是否为章节标题（分类头）
- 序列：整数，默认值 0，说明 排序序号
- 是否发布：布尔，默认值 否，说明 是否已发布
- 日期已发布：日期时间，说明 发布时间
- 预览：布尔，默认值 否，说明 非会员是否可预览
- HTML内容：长文本，说明 文章内容（article 类型专用）
- 链接：文本，说明 外部链接（video/document 类型专用）
- 完成度时间：金额，说明 预计完成时间（小时）
- 赞：整数，默认值 0，说明 点赞数
- 踩：整数，默认值 0，说明 踩数
- 合计视图：整数，默认值 0，说明 总浏览次数
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 频道：多对一 -> 课程，必填关系
- 分类：多对一 -> 幻灯片
- 下级幻灯片：一对多 -> 幻灯片，外键 分类编号
- 进度记录：一对多 -> 幻灯片进度

### Conduct（行为声明）

#### 操作
- 创建，可写字段：名称、幻灯片分类、分类、序列、预览、HTML内容、链接、完成度时间，参数：频道编号：唯一标识（必填）
- 查询
- 更新，可写字段：名称、序列、预览、HTML内容、链接、完成度时间
- 发布（类型：更新），说明：发布内容项，触发通知并设置发布时间
- 取消发布（类型：更新），说明：取消发布，触发所有 Enrollment 完成度重算（分母变化）
- 删除

#### 校验
- 创建时，名称 不能为空
- 创建／更新时，html_content 和 url 不能同时存在，article 类型使用 html_content，video/document 使用 url
- 发布时，内容项已处于发布状态
- 取消发布时，内容项未发布，无法取消发布

#### 变更
- 在 发布 时，将 是否发布 设为 是
- 在 发布 时，将 日期已发布 设为 当前时间
- 在 取消发布 时，将 是否发布 设为 否
- 在 发布 / 取消发布 / 删除 时，recompute_parent
- 在 创建 / 更新 / 发布 / 取消发布 / 删除 时，将 编号 设为 编号

#### 计算
- 计算字段 新幻灯片：布尔，规则 天数自(日期已发布) ≤ 7
- 计算字段 自身标记已完成：布尔，规则 ne（幻灯片分类，测验）

#### 事件
- 事件：发布 -> 在线学习.幻灯片.已发布
- 事件：取消发布 -> 在线学习.幻灯片.unpublished

#### 工作流
- 流程：slide_lifecycle：创建 -> 更新 -> 发布 -> 取消发布 -> 删除（内容项生命周期（创建→发布→取消发布/删除））

## 实体：报名

- 说明：学员与课程的注册关系，跟踪学习进度和完成状态
- 来源：基于 报名；来源域 在线学习

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 成员状态：枚举（必填），默认值 已加入，可选值：已邀请 / 已加入 / 持续 / 已完成，说明 注册状态
- 完成度：整数，默认值 0，说明 完成百分比（0-100）
- 已完成幻灯片数量：整数，默认值 0，说明 已完成的 Slide 数量
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 频道：多对一 -> 课程，必填关系
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号，必填关系
- 幻灯片进度：一对多 -> 幻灯片进度，外键 报名编号

#### 唯一约束
- 唯一约束 唯一报名：频道编号、伙伴编号

### Conduct（行为声明）

#### 操作
- 创建，可写字段：成员状态，参数：频道编号：唯一标识（必填）；伙伴编号：唯一标识（必填）
- 查询
- 加入（类型：更新），说明：接受邀请加入课程
- 重算完成度（类型：更新），说明：重新计算完成度（由 SlideProgress 变更触发）
- 删除，说明：清理过期邀请（GC 定时任务）

#### 校验
- 创建／加入时，必须完成所有前置课程才能加入
- 加入时，只有受邀状态可以执行加入操作

#### 变更
- 在 加入 时，将 成员状态 设为 已加入
- 在 重算完成度 时，将 完成度 设为 四舍五入(100.0 × 已完成幻灯片数量 ÷ 频道.合计幻灯片)
- 在 重算完成度 时，将 成员状态 设为 持续
- 在 重算完成度 时，将 成员状态 设为 已完成
- 在 创建 / 加入 / 重算完成度 / 删除 时，将 编号 设为 编号

#### 计算
- 计算字段 下一个幻灯片编号：唯一标识，规则 下一未完成幻灯片(频道编号, 伙伴编号)

#### 事件
- 事件：加入 -> 在线学习.报名.已加入
- 事件：重算完成度 -> 在线学习报名进度更新（条件 成员状态 = 已完成）

#### 工作流
- 流程：enrollment_lifecycle：创建 -> 加入 -> 重算完成度 -> 删除（学员注册生命周期（邀请→加入→学习中→完课））

## 实体：幻灯片进度

- 说明：用户对单个内容项的学习进度，包括完成状态、测验尝试、投票
- 来源：基于 幻灯片进度；来源域 在线学习

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 已完成：布尔，默认值 否，说明 是否完成该内容项
- 测验尝试数量：整数，默认值 0，说明 测验尝试次数
- 投票：整数，默认值 0，可选值：-1 / 0 / 1，说明 投票（-1=踩, 0=无, 1=赞）
- 创建时间：日期时间（自动生成）
- 更新时间：日期时间（自动生成）

#### 关系
- 幻灯片：多对一 -> 幻灯片，必填关系
- 频道：多对一 -> 课程，必填关系
- 报名：多对一 -> 报名，外键 报名编号
- 伙伴：多对一 -> 参与方，外键 伙伴参与方编号，必填关系

#### 唯一约束
- 唯一约束 唯一幻灯片进度：幻灯片编号、伙伴编号

### Conduct（行为声明）

#### 操作
- 创建，参数：幻灯片编号：唯一标识（必填）；频道编号：唯一标识（必填）；伙伴编号：唯一标识（必填）
- 查询
- 标记已完成（类型：更新），说明：手动标记完成（非测验类型）
- 标记未完成（类型：更新），说明：取消完成标记
- 完成测验（类型：更新），说明：测验答题完成（仅 quiz 类型）
- 点赞（类型：更新），说明：点赞/取消点赞（toggle 语义）
- 点踩（类型：更新），说明：踩/取消踩（toggle 语义）

#### 校验
- 标记已完成时，测验类型内容不能手动标记完成，必须通过答题完成
- 标记已完成／完成测验时，该内容项已标记为完成
- 标记未完成时，该内容项尚未完成
- 完成测验时，只有测验类型才能通过答题完成

#### 变更
- 在 标记已完成 / 完成测验 时，将 已完成 设为 是
- 在 标记未完成 时，将 已完成 设为 否
- 在 完成测验 时，increment 测验尝试数量：1
- 在 点赞 时，toggle_vote 投票：1
- 在 点踩 时，toggle_vote 投票：-1
- 在 标记已完成 / 标记未完成 / 完成测验 时，recompute_parent
- 在 点赞 / 点踩 时，recompute_parent
- 在 创建 / 标记已完成 / 标记未完成 / 完成测验 / 点赞 / 点踩 时，将 编号 设为 编号

#### 工作流
- 流程：进度追踪：创建 -> 标记已完成 -> 标记未完成 -> 完成测验 -> 点赞 -> 点踩（学习进度跟踪（创建→完成/取消完成 + 投票））

## 实体：参与方

- 说明：跨域引用 Organization.Party（统一主体）

### Schema（数据模型）

#### 字段
- 编号：唯一标识（主键、自动生成）
- 名称：文本

### Conduct（行为声明）

#### 操作
- 查询
