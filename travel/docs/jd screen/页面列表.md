## 说明

- **页面 1**：首页为同一页面，通过 **机票 / 火车票 / 酒店** 三个 Tab 切换，对应原效果图中的「机票首页」「火车票首页」「酒店首页」。
- **页面 9**：酒店详情为同一页面，「酒店详情」与「房间详情」为同一页内的不同内容/状态，对应原效果图中的「酒店详情页」「酒店详情页2（房间详情）」。

- **缺少页面 1：订单列表页**：用于展示用户全部机票 / 火车票 / 酒店订单，可按出行类型、出行时间、状态（待支付、已支付、已出行等）筛选。
- **缺少页面 2：订单详情页（3 种订单）**：机票订单详情页、火车票订单详情页、酒店订单详情页，各 1 个页面，展示乘客/入住人信息、出行/入住信息、价格与支付信息、退改规则等。
- **缺少页面 3：本人信息管理页**：集中管理用户常用出行人 / 入住人信息（姓名、证件、联系方式等），下单时可直接选择，提升预订效率。
- **缺少页面 4：预订结果确认页（3 种订单）**：机票 / 火车票 / 酒店预订结果确认页面（成功/失败状态），展示关键信息摘要（订单号、出行时间、金额）以及下一步操作入口（查看订单、回到首页等）。
