## 页面定位

这是艺龙开放平台首页，不是具体接口文档页。它更适合用来判断平台能力边界、公告节奏和合作方式，不适合直接提取字段定义。

## 页面关键信息

### 公告

页面顶部可见近期公告，例如：

- `2025/12/25`：关于预付及担保规则接口调整的公告
- `2025/03/18`：静态信息床型字段变更通知

这说明两件事：

1. 静态字段会变
2. 预付/担保规则也会调整

所以 adapter 设计不能假设供应商字段长期不变。

### 业务优势

页面给出的平台定位：

- 资源丰富：提供大量国内国际酒店内容，包含实时库存和价格
- 盈利模式清晰：提供询价和预订一条龙服务
- 合作模式多样：支持 API、白标、HBA 等模式
- 售后支持：平台提供售后能力

### 技术能力

页面给出的技术侧表述：

- 简单的 REST 协议
- 接口覆盖整个业务，可做深度集成
- 多 IDC / 多集群
- 有技术支持团队

## 对 `travel` POC 的直接启发

1. 酒店 adapter 可以先按 HTTP/REST 思路接，不必先假设专用 SDK
2. 供应商字段和规则会变，必须保留 adapter 隔离层
3. 平台覆盖的是“酒店供给 + 查询 + 预订 + 售后”全链路，不只是静态商品同步

## 不应从此页直接推出的结论

这页不能直接回答：

- 具体接口字段
- 下单参数
- 订单状态枚举
- 是否 webhook 推送

这些要看具体文档页，例如实时搜索流程页。
